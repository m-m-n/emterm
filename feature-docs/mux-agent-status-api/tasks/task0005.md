# Task Plan: task0005 — GUI AgentStatusModel + plain-tab OSC path + update ingestion

## Goal

The GUI holds one merged AgentStatusModel covering plain tabs (GUI parses
the OSC itself) and mux panes (daemon updates applied), with seen
tracking, aggregation, counts, and a transition-event queue — wired into
app state for the UI and notification layers to consume.

## Requirements

FR5 (GUI receive side), FR6, NFR3

## Scope

### Files to Create
- `src-tauri/src/agent_status_model.rs` — the model (contract in
  IMPLEMENTATION.md Shared Components)

### Files to Modify
- `src-tauri/src/lib.rs` — register the module (gui-gated)
- `src-tauri/src/callbacks.rs` — plain-tab path: recognize the
  `agent-status` kind in the OSC 777 emterm dispatcher and forward the
  parsed event to the model
- `src-tauri/src/mux/bridge.rs` — decode incoming AgentStatusUpdate and
  hand it to the model
- `src-tauri/src/tabs.rs` — tab/pane close discards model entries; foreground
  display hook for mark_seen
- `src-tauri/src/app.rs` — own the model in app state; expose it to
  ui/notifications; mark_seen on foreground tab display

## Design

- Model semantics are pinned in IMPLEMENTATION.md (aggregation priority,
  seen rules, transition queue, replay_derived silence). This task owns
  the wiring (integration owner).
- Plain-tab events go through the SAME shared core parser used by the
  daemon (no duplicate grammar); the model mints plain-tab revisions.
- Daemon updates are applied by pane key; replay_derived=true applies
  state without enqueuing transitions; seen flags are preserved when an
  update does not change semantic state, and reset to unseen on a real
  state change.
- mark_seen applies when the tab is displayed in the foreground OS window
  (reuse the existing focus/visibility signals available to the app).

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: A plain-tab set/clear OSC updates the model exactly like a
      daemon update would (state, name, revision minted, transition
      enqueued).
- [ ] AC-2: A daemon update with replay_derived=false enqueues a
      transition event only on real state change (same-state re-report:
      no event); replay_derived=true never enqueues.
- [ ] AC-3: aggregate() returns the highest-priority state per the fixed
      priority order, including the unseen flag distinction.
- [ ] AC-4: counts() reflects semantic states regardless of seen; empty
      model reports zero/none.
- [ ] AC-5: mark_seen clears unseen on that tab's panes without touching
      semantic state or revision.
- [ ] AC-6: Tab/pane close removes entries; aggregate/counts reflect the
      removal.
- [ ] AC-7: A real state change resets seen to unseen.
