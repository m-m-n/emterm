changes reliably produce a drawn (non-skipped) frame with correct row

## Design

Fix items (each maps to a round-1 finding; keep each fix in the smallest
matching site):

1. **Hover invalidation (finding 63c273cd4e0d66b1, high)**: when the hovered
   link cell-span changes (refresh_link_hover / invalidate_link_hover /
   pointer-move detection), the rows covered by the previous span union the
   new span must be repainted and must veto the frame skip. Acceptable
   implementations: union those rows into the frame's dirty set before the
   skip decision, or force a full redraw on span change (hover span changes
   are enter/leave events, not per-pixel). The hover underline is baked into
   grid instances, so the affected rows must actually rebuild in the row
   cache (a skipped-cache stale row is the bug being fixed).
2. **Search overlay liveness (finding 0a4db738aca57cbb, high)**: frames while
   the search UI is visible (interactive query editing, auto-research match
   movement) must not be skipped. Extend the overlay-work input of the skip
   decision with the search-visible state (and keep it false when the search
   UI is closed so idle skipping is preserved).
3. **SFTP producer wake (finding cd6820740f2c0769, high)**: every
   progress/result channel send in the SFTP service wakes the event loop via
   the global wake function, matching the snapshot-replay / scrollback-restore
   workers. A thin send+wake helper is acceptable to avoid missed sites.
4. **Bell final erase frame (finding 063320466ae233fe, medium)**: the frame
   that erases the expired bell overlay must not be skipped. The current gap:
   the deadline consumer clears the bell state in `about_to_wait`, so by
   render time the overlay-work probe reads inactive. Carry an explicit
   "overlay erase frame required" signal from the consumer to the render
   skip decision (or consume expiry on the render side). Optionally (finding
   b015db8a51facd0d): while the bell is active, pace wakeups like the toast
   poll so decay animates when idle — implementer's judgment, not required.
5. **Wide-char block cursor (finding c0732dd907681dc1, medium)**: when the
   cursor sits on a width-0 trailing cell, resolve the leading cell (glyph,
   style, column) and draw the 2-cell rect from the leading column. Clamp at
   screen edges as the existing geometry does.
6. **Perf counter zero overhead (finding 40edebb31f8f5e20, medium)**: when
   the env gate is off, no timestamp acquisition or counter-helper argument
   evaluation happens per frame — check the cached enabled flag first, then
   do the work inside that branch.

Constraints: preserve the honest-dirty-set property (a plain idle frame with
no hover/search/bell/toast activity still yields an empty dirty set and a
skipped frame) and the grid-independence invariant (IMPLEMENTATION.md).

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: A hover-span change (appear, move, disappear) produces a
  non-skipped frame and the affected rows (prev ∪ new) are rebuilt; a
  hover-stable idle frame still skips.
- [ ] AC-2: With the search UI visible, the skip decision never skips; with
  it closed and nothing else pending, idle frames skip as before.
- [ ] AC-3: Every SFTP progress/result send site is followed by a wake (unit
  test at the seam, or a structural test that the helper is used everywhere —
  no bare sends remain in the SFTP service).
- [ ] AC-4: The bell-expiry erase frame is not skipped (the erase signal
  reaches the skip decision); an idle frame after the erase completes skips
  again.
- [ ] AC-5: Block cursor on the trailing half of a wide glyph covers the full
  2-cell footprint anchored at the leading column, including at the right
  screen edge; existing cursor geometry tests keep passing.
- [ ] AC-6: With the perf env gate off, the drawn-frame and rebuilt-rows call
  sites evaluate no timestamps and mutate no counters (verifiable via the
  pure structure: gate check precedes all argument evaluation).
- [ ] AC-7: Existing `--lib` tests pass (tabs:: replay flake exempted per
  test/README.md).
