# Task Plan: task0001 — Remove the sidebar pane-ID copy affordance and its clipboard channel

## Goal

The mux sidebar's pane rows no longer render or hit-test a copy-to-clipboard
affordance, and no code remains whose only purpose was that affordance —
including the frame-event channel that carried its clipboard request to the
host layer.

## Requirements

FR1, FR2, FR3, FR4, NFR1, NFR2, NFR3, NFR4, NFR5

## Scope

### Files to Create

None.

### Files to Modify

- `src-tauri/src/ui/mux_sidebar.rs` — remove the copy affordance's painting,
  hit testing, hover text, geometry constants, geometry/painting helpers, the
  per-entry public-pane-id input, the outcome's copy field, and the locale
  parameter; update the module's tests.
- `src-tauri/src/render/mod.rs` — remove the per-entry public-pane-id
  attachment, the per-frame collection of the copy request, the frame-event
  field carrying it, that field's term in the "any event fired" predicate, and
  the locale argument at both sidebar call sites.
- `src-tauri/src/window_host.rs` — remove the post-frame application of the
  copy request.

## Design

### What disappears from the widget layer

The row-drawing routine currently does four extra things when an entry carries
a known public pane id: it computes a square region at the row's right edge,
registers that region as its own click target, paints a copy glyph into it,
and attaches localized hover text. It also records the click so the row's own
click does not additionally fire a window switch. All five behaviors are
removed, along with:

- the two geometry constants describing the icon's size and its gap,
- the helper that derives the icon region from a row rectangle,
- the helper that paints the glyph,
- the per-entry field carrying the pane's public id,
- the outcome field carrying the pane id to copy,
- the locale parameter threaded from the public draw entry point down to the
  row-drawing routine (its only use was the hover text).

### What the row looks like afterwards

Unchanged in every respect other than the missing icon: same height, gap,
corner radius, colors for the active / hovered / plain states, same
right-aligned number column, same optional agent-status badge with its
diameter and gap, same name text ellipsized to the remaining width. The
"remaining width" now ends at the row's own right padding, because no region
is reserved at the right edge.

### What disappears from the frame plumbing

The frame-aggregation layer stops attaching the public pane id to each entry
before drawing, stops collecting a copy request across the two placement
variants, and no longer carries such a request in its frame-event value; the
predicate that reports whether any event fired enumerates only the remaining
fields. The host layer's post-frame branch that wrote the request to the OS
clipboard is deleted.

### What must survive

- The application-level map from internal pane id to daemon-minted public
  pane id, its accessor, and its tests — agent-notification rate limiting
  still uses them.
- The host layer's clipboard-writing helper — the selection-copy keybinds use
  it.
- The agent-status badge attachment on each entry.
- Every other public item of the sidebar module: panel width derivation,
  hit-region test for the sidebar area, top-chrome inset, entry building.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: For an entry whose pane has a known public pane id, drawing the
      sidebar produces no copy affordance: no interaction region other than
      the row itself is registered, and no glyph is painted at the row's
      right edge.
- [ ] AC-2: A click positioned inside the region the icon used to occupy (the
      row's right edge, inset by the row's horizontal padding) reports that
      row's window switch.
- [ ] AC-3: The sidebar's per-frame outcome value exposes only the
      window-switch result; no field carrying a pane id to copy exists.
- [ ] AC-4: The frame-event value exposes no sidebar-originated clipboard
      field, and its "any event fired" predicate returns false for a default
      value and true when any remaining field is set.
- [ ] AC-5: Row layout is unchanged with and without an agent-status badge —
      the number's right-aligned position, the badge's position, and the name
      text's origin match what they are today — for both the persistent and
      the overlay placement.
- [ ] AC-6: The build command completes with exit code 0 and introduces no
      new warnings (in particular no unused constant, function, field, or
      parameter left by the removal).
- [ ] AC-7: The test command passes. The tests that pinned the copy
      affordance are gone; every other sidebar test still asserts what it
      asserts today.
- [ ] AC-8: The application-level public-pane-id accessor and its tests, and
      the host layer's clipboard-writing helper, are still present and
      unmodified.
- [ ] AC-9: No comment, test name, or documentation string in the three
      modified files still describes a copy-to-clipboard affordance in the
      sidebar.

## Test Notes

- AC-1 / AC-2 / AC-3 / AC-5 are unit tests in the sidebar module, using the
  module's existing test harness for driving a headless draw and for
  recovering the row rectangles it allocated. Write them first: start from the
  existing copy-affordance tests, invert them into assertions that the
  affordance is absent and that the right-edge click switches windows, then do
  the removal.
- AC-5 is best served by keeping the existing layout tests untouched and
  letting them act as the regression net; add nothing there unless a test has
  to change to compile.
- AC-4 is a unit test over the frame-event value's predicate — cheap, and it
  catches an incomplete field removal.
- AC-6 / AC-7 are the build and test commands from workflow.yaml
  `project.components.main`.
- AC-8 / AC-9 are verified by inspection over the touched files plus the
  surviving accessor's own tests; no new test is warranted for "code still
  exists".
- Edge cases worth an explicit assertion: an entry with no badge and no known
  public pane id (number + name only), an empty entry list, and the minimum
  panel width (the name ellipsizes against the row's right padding).

## Out of Scope

- The agent-status badge and every other sidebar visual.
- The application-level public-pane-id map, its accessor, and its tests.
- The host layer's clipboard-writing helper and the selection-copy keybinds.
- Anything the daemon does with public pane ids.
- Reformatting or refactoring beyond what the removal requires.
