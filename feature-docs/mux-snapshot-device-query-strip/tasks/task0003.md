## Design

The normative reference is term_core's CSI handling, verified by the orchestrator (read `crates/term_core/src/parser/csi.rs` and `csi_dispatch.rs` before writing tests):

### Fix 1: DSR u8 truncation (864ff69541b6bcf8)

term_core truncates the clamped first parameter to u8 before the DSR 5/6 match. Mirror it: compare the parameter after clamping to term_core's max (9999) and truncating to u8, so `ESC[261n` (261 mod 256 = 5) is stripped. The same dispatch site is the only one with a u8 truncation — DA / XTWINOPS / DECRPM comparisons stay as they are.

### Fix 2: digits after intermediates are accepted (445cfc21db4c4741)

term_core's CsiParam state accepts parameter digits and `;`/`:` separators after intermediate bytes (they keep accumulating into the parameter parser), so `ESC[?$1c` dispatches DA1 with intermediates [?, $]. Mirror it: after the first intermediate byte, the scanner keeps accepting digits and separators (feeding the same first-param accumulation rules) as well as further intermediates, instead of invalidating the candidate.

Digit-accumulation semantics for the mirror: term_core's first parameter is whatever `get_first_or_zero` sees at dispatch — digits accumulate into the current parameter regardless of when intermediates appeared, and `;`/`:` finishes a parameter. Preserve the existing "first parameter only" tracking (digits arriving after the first separator do not change the first parameter).

### Fix 3: non-leading private marker cancels the candidate (ed8f3f3e4759734b)

In term_core, a private marker byte (0x3C..=0x3F) is only valid as the leading byte(s) in CsiEntry; in CsiParam it hits the invalid arm and cancels the whole CSI (no dispatch, no response; parsing resumes at Ground). Mirror it: a private marker seen after any digit, separator, or intermediate invalidates the candidate (scanner returns no-match; the caller preserves the bytes byte-for-byte).

Leading private markers keep today's semantics (they set the private prefix; term_core's CsiEntry collects `? > < =` — and space — as intermediates and moves to CsiParam).

### Consistency constraint

All three fixes preserve the invariants already established: single O(n) pass, non-overlapping scan regions (bare ESC aborts a candidate), unterminated candidates preserved, embedded C0 bytes re-emitted on strip, saturating parameter accumulation. Update the predicate's doc-comment table if its stated conditions change.
