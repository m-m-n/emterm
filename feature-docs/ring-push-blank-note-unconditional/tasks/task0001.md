## Design

### What the NOTE must express

IMPLEMENTATION.md pins the canonical claim set C1-C4. This task's NOTE must
express all four, in English, in the wording the implementer authors:

1. **C1 (kept from the current NOTE)** — removing only ONE of the two
   clearing sites inside `ring_push_blank` still leaves this test green.
2. **C2** — the coincidence is unconditional: the new bottom absolute row
   equals the evicted absolute row on every push with at least one row,
   independent of viewport height and of scrollback capacity, so no fixture
   can pin the two sites independently.
3. **C3** — the reason is evaluation order: the evicted absolute row is read
   from the ring head before the rotation, the new bottom absolute row is
   computed after the ring head advances by one, and modulo the row count the
   two denote the same ring slot.
4. **C4** — the consequence: the new-bottom-row clear is therefore always a
   no-op within a single push, because whichever eviction-time clear branch
   ran has already emptied that same absolute row.

The reasoning is verifiable by reading `ring_push_blank` in
`crates/term_core/src/ring_buffer.rs`: the evicted row is captured at the top
of the function (line 129 in the current file), exactly one of the three
eviction-time clear branches runs (lines 146-149, 177-180, 196-199), the ring
head then rotates (line 204), the new bottom row is derived from the rotated
head (line 207), and the second clear fires on that derived row (lines
221-224). Confirm these positions before relying on them; per
IMPLEMENTATION.md D3 the NOTE names identifiers and the function's own `Step`
labels rather than embedding line numbers.

### What must not move

- The NOTE stays a `// ` line-comment block at its current position inside
  the inline `#[cfg(test)]` module, immediately above the survivor assertion
  block. No promotion to a doc comment, an assertion, or a separate document.
- No fixture-scoped qualifier survives anywhere in it. The two current
  offenders are the phrases `in this 2-row, zero-scrollback fixture` and
  `for this fixture, not independently pinned by it`; the criterion is the
  absence of *any* such qualifier, not just of those two.
- The separate explanatory comment block that sits ABOVE the `#[test]`
  attribute (the one describing what the test proves) is a different block
  and is not touched.
- Every assertion, the fixture construction, the fixture dimensions and the
  test name stay exactly as they are.
