# Task Plan: task0002 — Select options rework with grandfathered kitty_csi_u

## Goal

The settings-panel select offers `alt_enter` / `none` / `lf`, shows
`kitty_csi_u` only while it is the current value, and has ja/en labels
for the new option.

## Requirements

FR2, FR3, FR5

## Scope

### Files to Create

- (none)

### Files to Modify

- `src-tauri/web-shared/settings/types.ts` — extend the union with
  `"lf"` (keeping `"kitty_csi_u"`).
- `src-tauri/web-shared/settings/sections/terminal-behavior-section.ts`
  — options computed per the IMPLEMENTATION.md UI option policy
  (decision D2).
- `src-tauri/web-shared/settings/sections/terminal-behavior-section.test.ts`
  — update/extend section tests for the new option set and
  grandfathering.
- `src-tauri/web-shared/i18n/locales/ja.json` — `lf` label
  「改行 (LF) として送信」+ description (Claude Code では改行、シェルでは
  Enter と同じ扱い、の内容を既存文体で).
- `src-tauri/web-shared/i18n/locales/en.json` — `lf` label
  "Send as newline (LF)" + corresponding description.

## Design

- Offered options: `alt_enter`, `none`, `lf` in this order; when the
  loaded value is `kitty_csi_u`, append it as a fourth option using its
  existing label/description keys (which are kept).
- Grandfathering is render-time only (no persisted state): after saving a
  different value, subsequent renders offer three options.
- Saving continues through the section's existing save mechanism with the
  wire values.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: `AppSettings` union is
      `"none" | "alt_enter" | "kitty_csi_u" | "lf"`.
- [ ] AC-2: With current value ≠ `kitty_csi_u`, the select renders
      exactly three options in the order `alt_enter`, `none`, `lf`.
- [ ] AC-3: With current value `kitty_csi_u`, the select renders four
      options including `kitty_csi_u`, with it selected.
- [ ] AC-4: Selecting the LF option saves `"lf"`.
- [ ] AC-5: ja/en locales contain the `lf` label and description; the
      existing `kitty_csi_u` keys remain.
- [ ] AC-6: `bun run typecheck` and `bun test` pass.

## Test Notes

- AC-2/AC-3/AC-4 map to section tests (happy-dom) — extend the existing
  co-located suite; keep its current cases as regression.
- AC-5 is covered by typecheck plus the section test's label lookups
  where feasible.

## Out of Scope

- Rust enum/behavior changes (task0001).
- Removing the `kitty_csi_u` locale keys or its wire support.
