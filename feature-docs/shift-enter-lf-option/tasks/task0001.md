# Task Plan: task0001 — lf variant across the Rust settings layers and key rewrite

## Goal

`shift_enter_behavior` accepts `lf` in both Rust settings layers, and a
bare Shift+Enter under `lf` sends the single byte 0x0a; `kitty_csi_u`
behavior is untouched.

## Requirements

FR1, FR4, NFR1

## Scope

### Files to Create

- (none)

### Files to Modify

- `src-tauri/src/settings.rs` — add the `lf` variant to the native enum
  and its parsing (wire value per the IMPLEMENTATION.md contract).
- `src-tauri/src/window_host.rs` — extend the rewrite decision with the
  `lf` case emitting the single byte 0x0a via the existing raw-byte path
  (decision D1).
- `crates/app_settings/src/types.rs` — add the `lf` variant to the shared
  schema enum.
- `crates/app_settings/src/settings.rs` — cover `lf` in the schema's
  tests where variants are enumerated (migration/sentinel semantics
  unchanged).
- `src-tauri/src/settings_store.rs` — round-trip coverage for `lf`.
- `src-tauri/src/settings_window/commands.rs` — settings-window boundary
  round-trip coverage for `lf`.

## Design

- The `lf` variant mirrors `kitty_csi_u` structurally everywhere the
  enum exists; only the emitted bytes differ (0x0a, one byte).
- Rewrite applies only to Enter with modifier state exactly Shift (the
  existing decision function's guard); Ctrl/Alt combinations stay
  untouched under `lf` (NFR1).
- No changes to defaults, legacy-boolean migration, null precedence, or
  the presence-sentinel mechanism.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: Under `lf`, bare Shift+Enter yields exactly the byte 0x0a for
      both host-PTY and mux encode targets; Ctrl+Enter / Alt+Enter /
      Ctrl+Shift+Enter are not rewritten.
- [ ] AC-2: `"lf"` deserializes in the native settings and the
      app_settings schema; unknown strings still resolve to the default.
- [ ] AC-3: `lf` survives the settings-store round-trip and the
      settings-window load/save boundary.
- [ ] AC-4: All existing shift_enter tests (byte behavior of the three
      prior values, migration, null precedence, sentinel) pass unchanged.
- [ ] AC-5: Build and `--lib` test commands pass.

## Test Notes

- AC-1 extends the existing decision-function/byte tests with the new
  variant's row.
- AC-2/AC-3 mirror the predecessor feature's `kitty_csi_u` fixtures with
  the `lf` wire value.
- AC-4 is a pure regression gate — existing tests must not be modified
  (weakening them is out of bounds).

## Out of Scope

- Settings-panel UI, TS types, locales (task0002).
- Removing or altering `kitty_csi_u` behavior.
