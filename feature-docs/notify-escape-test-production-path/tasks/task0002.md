# Task Plan: task0002 — Route the body_markup_escape tests through escape_for_send

## Goal

The three tests in `mod body_markup_escape` that re-implement the production
escape branch call `escape_for_send` instead, so they verify the production
decision rather than a copy of it.

## Requirements

FR1, FR3, FR6, NFR2, NFR3, NFR4

## Scope

### Files to Create

None.

### Files to Modify

- `src-tauri/src/callbacks/tests.rs` — inside mod body_markup_escape only, the three inline branches become escape_for_send calls and the related comments are corrected

## Design

The `escape_for_send` contract, the `tests.rs` region ownership (D2) and the
behavior-preservation list (D3) are in IMPLEMENTATION.md and are not restated
here.

### Replacement contract

- Each site passes a title, the existing body fixture and the existing
  capability fixture to `escape_for_send`, and feeds the returned body into the
  existing assertion.
- The title argument is a plain fixed text; it does not affect the returned
  body. Use a title value the test already builds, if one exists.
- Input fixtures (`sanitize_title` + `notification_body` for tab-activity,
  `agent_notification_body` for agent-status, the literal body for the
  unchanged case) and assertions stay as they are.
- After the change, no code in `tests.rs` branches on the result of
  `body_markup_absence_confirmed` to decide whether to call
  `escape_body_markup`. The direct unit tests of `body_markup_absence_confirmed`
  (around lines 703-773) and of `escape_body_markup` (around lines 1099-1107)
  stay unchanged.

## Test Notes

- The three tests already exist. The change swaps where their value comes from,
  so the TDD red step is shown by mutation (AC-4): with the branch copies
  removed, inverting the condition in `escape_for_send` must now turn a test
  red, which the copied branch never did.
- AC-1 is checkable by searching `tests.rs` for any remaining call pattern that
  selects between the unescaped value and `escape_body_markup` based on
  `body_markup_absence_confirmed`.
- A title-only escape mutation is not expected to be caught by these three
  tests (they assert the body only); other tests in the `--lib` suite cover it.
- If an unrelated suite (tabs replay, tmux socket discovery) fails in the
  parallel `--lib` run, re-run it with a single test thread before treating it
  as a regression.
