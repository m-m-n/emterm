# Task Plan: task0002 — Drop the status-bar summary from the agent-status document

## Goal

`doc/AGENT-STATUS.md` describes only the visual surfaces that actually exist
after the status-bar summary is removed, so the documentation no longer promises
a status-bar indicator.

## Requirements

FR9, NFR4

## Scope

### Files to Create

None.

### Files to Modify

- `doc/AGENT-STATUS.md` — reword the passages that name a status-bar summary as
  one of the surfaces agent-status reports feed.

## Design

Two passages currently name the status-bar summary:

1. The document's opening description of what eMterm does with agent reports,
   which lists tab/window badges *and* a status-bar summary among the
   aggregation targets.
2. The security note about forged state, which enumerates the badge, the
   status-bar summary, and the other surfaces a forged report can mislead.

Both must be reworded so that the visual surfaces named are the tab badge and
the mux window/sidebar badge only. Keep every other claim in the document
intact — notifications, the OSC reporting protocol, the mux agent API, and the
security reasoning itself are unaffected by this feature. Prefer minimal
edits that remove the status-bar clause rather than rewriting the surrounding
prose.

Search the whole document for further mentions of the status bar before
finishing; the two passages above are the known occurrences, not a guaranteed
exhaustive list.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: `doc/AGENT-STATUS.md` contains no statement that agent status is
      shown in, aggregated into, or capable of misleading the status bar.
- [ ] AC-2: The document still describes the tab badge, the mux window/sidebar
      badge, desktop notifications, the OSC reporting protocol, and the mux
      agent API with their existing meaning; no section other than the two
      status-bar passages is materially altered.

## Test Notes

This task changes documentation only; it has no automated test. Verification is
a read-through of the modified passages plus a whole-file search confirming no
remaining status-bar claim. No build or test command needs to run for this task,
though running the project's format check does no harm.

## Out of Scope

- Any source code change (owned by task0001).
- Restructuring, retitling, or expanding `doc/AGENT-STATUS.md` beyond removing
  the status-bar claims.
- Other documents under `doc/`, including the UI design guidelines and the
  status-bar feature documents.
