### What the cited tests actually drive

Establish this by reading the tests before writing a word of the rows. As the
tree stands, the cited end-to-end test composes the window-free state core and
the recording sink in the same order the adapter composes them, over plain
values: it constructs no window host, does not call the adapter
`publish_local_drag`, does not run the focus-loss event-loop arm, and resolves
no selection — the published text is supplied directly as a value. The cited
truth-table tests cover the destination decision over its inputs and likewise
touch none of the adapter.

Consequence the rows must carry: the adapter's own gather-and-adapt wiring is
not exercised by these tests. What pins it is the pair of call-site literals
the source-scanning test compares against the event-loop file's text. That is
verification at the seam and at the call site, not through the production entry
point.

This shape is what the prior feature's own non-functional requirement asks for
(no window host may be constructed), so the rows describe a deliberate bound,
not a defect. Say what is covered and by what; do not editorialize about the
bound.

### What each corrected row must say

1. The cited test drives the window-free state core plus the recording sink,
   composed as the adapter composes them, with no window host and no resolved
   selection.
2. It asserts the three effects it does assert: the drag flag cleared, the
   pending anchor consumed and returned, and the publish requested with the
   expected destinations and payload.
3. The adapter's own wiring remains covered only by the call-site literals the
   source-scanning test checks.
4. The already-present caveat stands unchanged in meaning: a recorded sink call
   is evidence that the publish path requested the write, not evidence of an
   OS-level primary-selection or clipboard update.
5. That feature's real-hardware acceptance criterion stays mapped to its manual
   scenario and is nowhere presented as unit-verified.

This is a correction of existing rows, not a rewrite. Keep each document's
