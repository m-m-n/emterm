# Task Plan: task0002 — Settings-panel select UI and TS mirror

## Goal

The settings panel offers the Shift+Enter behavior as a three-option
select in the Terminal Behavior section, backed by the mirrored
`AppSettings` field and ja/en locale strings.

## Requirements

FR6, FR7

## Scope

### Files to Create

- `src-tauri/web-shared/settings/sections/terminal-behavior-section.test.ts`
  — co-located test for the new select control (project convention:
  co-located `*.test.ts`).

### Files to Modify

- `src-tauri/web-shared/settings/types.ts` — replace
  `shift_enter_as_alt_enter: boolean` with `shift_enter_behavior` typed as
  the string union from the IMPLEMENTATION.md wire contract.
- `src-tauri/web-shared/settings/sections/terminal-behavior-section.ts` —
  replace the existing toggle with a select following the section's
  existing select pattern (Cursor Style / Bell Action), option order per
  decision D2.
- `src-tauri/web-shared/i18n/locales/ja.json` — replace the
  `shiftEnterAsAltEnter` label/description keys with keys for the new
  setting: label, description, and one label per option.
- `src-tauri/web-shared/i18n/locales/en.json` — same as ja.json in
  English.

## Design

- The select binds to `shift_enter_behavior` and saves via the section
  context's save mechanism, exactly like the section's existing selects.
- Option labels describe the delivered behavior; the `kitty_csi_u` option
  description states that applications not understanding the sequence
  receive stray characters.
- Locale key naming follows the section's existing
  `settings.terminal.*` namespace.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: `AppSettings` has `shift_enter_behavior` as the union of the
      three wire values and no `shift_enter_as_alt_enter` field.
- [ ] AC-2: The Terminal Behavior section renders a select with exactly
      the three options in the D2 order and the current value selected.
- [ ] AC-3: Changing the select saves `shift_enter_behavior` with the
      chosen wire value.
- [ ] AC-4: ja and en locales contain the label, description, and option
      strings; no locale key for the removed toggle remains.
- [ ] AC-5: `bun run typecheck` and `bun test` pass.

## Test Notes

- AC-2 / AC-3 → the new co-located section test (happy-dom via
  test-setup.ts) renders the section and asserts option values and the
  save callback payload.
- AC-4 → covered by typecheck plus a locale-key assertion in the section
  test if the framework exposes it; otherwise manual JSON review during
  the task.

## Out of Scope

- Rust settings struct, migration, and key rewrite (task0001).
- Any styling beyond the section's existing select pattern.
