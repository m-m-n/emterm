# Task Plan: task0001 — Clamp the post-relocation cursor to the grid and pin the contract with tests

## Goal

The cursor left behind by the last-column VS16 widening relocation always points inside the grid, so
the character printed immediately afterwards is carried to the next row instead of being silently
dropped on 1- and 2-column terminals, with the resulting cursor contract pinned by unit tests.

## Requirements

FR1, FR2, FR3, FR4, FR5, FR6, FR7, NFR1, NFR2, NFR3, NFR4

## Scope

### Files to Create

None.

  the tail of `relocate_widened_base_via_wrap` with the column-count boundary clamp described below.
  Nothing else in the file changes.
- `crates/term_core/src/print_handler/tests.rs` — extend the existing 1-column relocation test with

## Design

See IMPLEMENTATION.md for the cross-task decisions this task implements: D2 (mirror the
non-final-column path's branch structure including its inner auto-wrap guard), D3 (the in-range
branch keeps clearing the wrap-pending flag), D4 (scope fence) and the cursor contract in Shared
Components.

### Behaviour to implement

The tail of the relocation path currently assigns the cursor column unconditionally and then lowers
the wrap-pending flag. Replace that with a boundary decision:

1. Form the prospective cursor column as the relocated base cell's column (always 0 after
   relocation) plus the widened cell's width (2).
2. If the prospective column is at or past the grid's column count — true exactly when the grid has
   1 or 2 columns — then, inside the auto-wrap mode guard, place the cursor on the last column and
   raise the wrap-pending flag.
3. Otherwise (3 or more columns) place the cursor on the prospective column and lower the
   wrap-pending flag, which is what happens today.
4. Leave the row, the last-write bookkeeping, and every non-cursor post-step of the relocation
   exactly as they are.

The branch structure, including the nested auto-wrap guard, is written to match the non-final-column
widening path in the same file line-for-line in shape. That guard's false side is unreachable from
the relocation path's sole call site; this is a deliberate, recorded trade-off (IMPLEMENTATION.md
D2), not an oversight.

### Resulting observable contract

| Grid width | Cursor row | Cursor column | Wrap-pending | Next printed character lands at |
|---|---|---|---|---|
| 1 column | row below the original (or the last row after a scroll) | 0 (last column) | raised | column 0 of the following row |
| 2 columns | same | 1 (last column) | raised | column 0 of the following row |
| 3+ columns | same | 2 | lowered | column 2 of the same row (unchanged from today) |
