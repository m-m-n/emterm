# Task Plan: task0002 — Plain-tab half of the SC-1y parity corpus

## Goal

The plain tab processes every SC-1y row (K38-K57) in one bulk call from the
S-W seed and ends in the row's final OSC 7501 table, OSC 777 state and, where
given, table-change count. This pins the reference outcome that the mux half
is asserted against.

## Requirements

FR6, FR7, FR8, NFR5

## Scope

### Files to Create

None.

### Files to Modify

- `src-tauri/src/tabs/tests/output_pipeline.rs` — a K38-K57 list of its own, with the same row shape as the existing K16-K37 list, and the test that runs it; the existing lists and tests stay unchanged.

## Design

- The rows, their notation, their streams, their lengths and their expected
  outcomes are SC-1y in IMPLEMENTATION.md (Shared Components). Build each
  stream from that notation exactly, and assert each stream's length against
  the table.
- Delivery follows IMPLEMENTATION.md D3. Each row starts on a plain tab
  seeded with S-W (`seeded_plain_tab`) and is processed in one
  `process_combined` call. The plain side ignores the "Mux deliveries"
  column.
- What is asserted per row, in the same way as the existing K16-K37 list:
  - the final OSC 7501 table
  - the final OSC 777 state
  - where the row gives one, the number of pending summary changes, which is
    the plain side's measure of table changes
- The plain tab is the oracle (IMPLEMENTATION.md D1). No production file
  changes. If a row's outcome differs from SC-1y, report the row as a plan
  deviation. Do not change term_core, the plain-tab path or the expectation.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1 (FR6, FR7; TM-2): each of K38-K57, processed in one
  `process_combined` call on a plain tab seeded with S-W, ends in the row's
  final OSC 7501 table and final OSC 777 state. Where the row gives a
  table-change count, the number of pending summary changes equals it.
- [ ] AC-2 (FR7): the rows form a list of their own that holds exactly
  K38-K57 in order. Each stream is built from the SC-1y notation and has the
  length the table lists. The K1-K15 and K16-K37 lists and the test that
  pins the K1-K15 names are unchanged.
- [ ] AC-3 (FR8, NFR5): no production file and no file under
  `crates/term_core/` changes. Every existing test in `output_pipeline.rs`
  passes unchanged, and the src-tauri `--lib` suite passes.

## Test Notes

- These are integration-style tests on the plain tab (GUI build, default
  features). They pass on the unmodified code base, because the plain tab
  is the reference. TDD here means writing the rows and confirming they hold
  the SC-1y outcomes. The rows never need a red phase.
- Rows that matter most as oracle checks:
  - K38 (reproduction 1): empty after RIS, W and a live mark.
  - K42 and K43: an `ESC c` in a designator slot is not a RIS and causes 0
    table changes.
  - K47 and K53: ?1047-only compounds that leave term_core on the screen it
    was already on, while the shadow parser stays on the other screen. These
    are two of the combinations that IMPLEMENTATION.md Open Questions names.
  - K49 cut at 10 is reproduction 2. The plain side runs the stream in one
    call.
- Name the new test (or tests) with the `altmismatch_` prefix and the AC
  labels above (IMPLEMENTATION.md Conventions).

## Out of Scope

- The mux half of SC-1y and any change to the mux reader.
- Any change to term_core, to the plain-tab callbacks or to existing rows.
