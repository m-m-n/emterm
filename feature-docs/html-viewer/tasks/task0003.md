# Task Plan: task0003 — basedir resource resolver

## Goal

A standalone resolver module safely serves basedir-relative local resources (images / CSS / JS / fonts) for the HTML viewer, denying every path that escapes the basedir subtree.

## Requirements

FR5, NFR1

## Scope

### Files to Create
- `src-tauri/src/viewer/html_resolver.rs` — resolver: relative-URL → (bytes, MIME) inside the basedir subtree, with traversal/symlink protection, MIME allowlist, and size cap

### Files to Modify
- （なし — module registration in `viewer/mod.rs` is deliberately left to task0004, which already modifies that file, to keep this task conflict-free in wave 1）

## Design

- Contract (IMPLEMENTATION.md shared component): input is a basedir and a percent-decoded relative path from the custom-protocol request; output is file bytes plus MIME type, or a denial.
- Protection mirrors the existing image resolver's layered checks: reject absolute paths; lexically normalize and reject `..` escapes; verify the normalized result stays under basedir; canonicalize and re-verify to defeat symlink escapes; apply a size cap.
- MIME allowlist extends the image resolver's raster set with text/css, JavaScript, and common font types (woff/woff2/ttf/otf). SVG remains excluded (existing XSS posture). Disallowed extensions are denied, not sniffed.
- The module is self-contained (no dependency on window or webview code) so it is fully unit-testable and usable from the task0004 protocol handler. Registration in the module roster happens in task0004.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: A relative path to an existing allowed file under basedir returns its bytes and the correct MIME type for images, CSS, JS, and font extensions.
- [ ] AC-2: Absolute paths are denied.
- [ ] AC-3: `..` traversal that lexically escapes basedir is denied; `..` segments that stay inside basedir resolve correctly.
- [ ] AC-4: A symlink inside basedir pointing outside the basedir subtree is denied (canonicalization re-check).
- [ ] AC-5: Files over the size cap are denied; a file exactly at the cap is served.
- [ ] AC-6: Disallowed types (including `.svg` and extensionless files) are denied.

## Test Notes

- All criteria are pure unit tests with temp directories (same approach as the existing image resolver tests — reuse their structure).
- Symlink tests are Unix-gated (`cfg(all(test, unix))` per project platform rules); Windows behavior is covered by the canonicalization check itself.

## Out of Scope

- Wiring into the custom protocol handler and CSP (task0004).
- Any modification to the existing image resolver or markdown viewer.
