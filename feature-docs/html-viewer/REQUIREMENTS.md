# HTMLビューアー - 要件定義書

## 1. 概要

### 1.1 背景
eMterm には Markdown / JSON / YAML / 画像を子 WebView ウィンドウで表示する仕組み（CLI サブコマンド → OSC 777 シーケンス → 子ビューアープロセス）がある。AI が生成した HTML ドキュメントをターミナルから直接確認する手段が無い。

### 1.2 目的
`emterm html PATH` で HTML ファイルを子 WebView ウィンドウにそのまま描画できるようにする。

### 1.3 スコープ
- CLI サブコマンド `html` の追加（OSC シーケンス出力）
- GUI 側での HTML ビューアー起動・描画
- フルブラウザ機能（URL バー、履歴、タブ等）はスコープ外

## 2. ビジネス要件

### 2.1 ビジネス目標
AI が生成した HTML ドキュメントをターミナルワークフローの中で確認できるようにする。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| eMterm 利用者 | AI コーディングツールで HTML を生成し、その場で確認したい開発者 |

### 2.3 期待される効果
- 生成された HTML をブラウザへ切り替えずに確認できる

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | HTML ファイルを表示する | 利用者 / AI ツール | 高 |

### 3.2 ユースケース詳細

#### UC01: HTML ファイルを表示する

**アクター**: 利用者（または AI ツールがコマンドを実行）

**事前条件**:
- eMterm（GUI）上のシェルで作業している
- 表示したい HTML ファイルが存在する

**基本フロー**:
1. `emterm html path/to/file.html` を実行する
2. CLI が OSC シーケンスを stdout に出力する
3. eMterm がシーケンスを受信し、子 WebView ウィンドウを開く
4. HTML がそのまま（eMterm のスタイルを当てずに）描画される

**代替フロー**:
- ファイルが存在しない / ディレクトリ / 10MB 超 / 拡張子が `.html`・`.htm` 以外 → エラーメッセージを stderr に出力し、非 0 で終了する
- tmux 内で実行 → DCS passthrough でラップして出力する（既存サブコマンドと同じ）

**事後条件**:
- HTML が子 WebView ウィンドウに表示されている

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | `html` CLI サブコマンド | HTML ファイルを読み込み OSC シーケンスを出力する | 高 |
| F02 | HTML ビューアーウィンドウ | 受信した HTML を子 WebView でそのまま描画する | 高 |
| F03 | JavaScript 実行 | HTML 内の JavaScript を実行する | 高 |
| F04 | ネットワーク遮断 | 外部リソースの読み込みを禁止する | 高 |
| F05 | 相対パス解決 | basedir を基準にローカルの画像・CSS・JS を読み込む | 高 |
| F06 | リンクの外部ブラウザ委譲 | http(s) リンクはシステム既定ブラウザで開く | 中 |

### 4.2 機能詳細

#### F01: `html` CLI サブコマンド

**説明**: `emterm html <file>` で HTML ファイルを読み込み、base64 チャンク化した OSC 777 シーケンス（kind: html、basedir 付き）を stdout に出力する。既存の `markdown` サブコマンドと同じ経路。

**入力**:
- file: パス - 表示する HTML ファイル

**バリデーション**:
| 項目 | ルール | エラー時の対応 |
|------|--------|------------------|
| 拡張子 | `.html` または `.htm`（大文字小文字を区別しない） | エラーメッセージ + 非 0 終了 |
| 存在 | ファイルが存在し通常ファイルであること | エラーメッセージ + 非 0 終了 |
| サイズ | 10MB 以下 | エラーメッセージ + 非 0 終了 |

**エラーケース**:
| エラー | 条件 | 対応 |
|--------|------|------|
| FileNotFound | ファイルが存在しない | stderr へメッセージ、非 0 終了 |
| NotAFile | ディレクトリ等 | stderr へメッセージ、非 0 終了 |
| FileTooLarge | 10MB 超 | stderr へメッセージ、非 0 終了 |
| InvalidExtension | `.html`/`.htm` 以外 | stderr へメッセージ、非 0 終了 |

#### F02: HTML ビューアーウィンドウ

**説明**: GUI 側で OSC 777（kind: html）を受信したら子 WebView ウィンドウを開き、HTML を素のまま描画する。eMterm 側の CSS・テーマ（MD3 等）は一切当てない。

#### F03: JavaScript 実行

**説明**: HTML 内のインライン / ローカル参照の JavaScript を実行する。

#### F04: ネットワーク遮断

**説明**: CDN の JS/CSS、Web 上の画像など、ネットワーク経由のリソース読み込みを CSP で禁止する。

#### F05: 相対パス解決

**説明**: HTML ファイルのあるディレクトリを basedir とし、相対パスで参照される画像・CSS・JS を読み込めるようにする（markdown ビューアーの basedir と同じ仕組み）。

#### F06: リンクの外部ブラウザ委譲

**説明**: `<a href>` の http(s) リンクはシステム既定ブラウザで開き、WebView 内では遷移しない。ページ内アンカー（`#`）は WebView 内で動作する。

## 5. 非機能要件

### 5.1 セキュリティ要件
- ネットワークアクセス: CSP で遮断する
- ナビゲーション: WebView 内でのドキュメント外への遷移を禁止する
- ローカルファイルアクセス: basedir 配下の解決に限る（markdown ビューアーと同等）

### 5.2 互換性要件
- Linux（WebKitGTK）と Windows（WebView2）の両方で動作する
- CLI-only ビルド（`--no-default-features`）でも `html` サブコマンドが動作する
- tmux 内では DCS passthrough でラップする（既存サブコマンドと同じ）
- mux の snapshot リプレイで HTML ビューアーが再起動しないこと（既存の rich-content 除去対象に含める）

## 6. UI/UX要件

### 6.1 画面設計要件
- HTML ファイル自身のスタイルのみで描画する（eMterm テーマを重ねない）
- ウィンドウ管理（サイズ・クローズ等）は既存 markdown ビューアーと同じ

## 7. データ要件

該当なし（表示のみ。データの永続化は行わない）

## 8. 外部連携

該当なし

## 9. 制約条件

### 9.1 技術的制約
- 既存の CLI → OSC 777 → 子 WebView（wry）アーキテクチャに従う
- viewer kind の SSOT（`REPLAYABLE_VIEWER_KINDS`）に `html` を追加する

### 10.1 技術的課題
| 課題 | 影響度 | 対応策 |
|------|--------|--------|

## 11. 成功基準

### 11.1 受け入れ基準
- [ ] `emterm html file.html` で子 WebView ウィンドウに HTML が表示される
- [ ] HTML 内の JavaScript が実行される
- [ ] 外部リソース（http/https）は読み込まれない
- [ ] 相対パスのローカル画像・CSS が表示される
- [ ] http(s) リンククリックで外部ブラウザが開き、WebView 内では遷移しない
- [ ] バリデーションエラー（拡張子・サイズ・存在）で非 0 終了する

## 12. テストシナリオ

### 12.1 テスト観点
- [ ] 正常系: `.html` ファイルの表示シーケンス生成
- [ ] 異常系: 存在しないファイル / ディレクトリ / 10MB 超 / 拡張子違い
- [ ] 境界値: ちょうど 10MB のファイル / 空ファイル
- [ ] セキュリティ: 外部リソース遮断、basedir 外アクセス不可、リンクの外部委譲

## 13. 用語定義

| 用語 | 定義 |
|------|------|
| OSC 777 | eMterm のカスタム表示シーケンス（markdown/json/yaml/image で使用中） |
| basedir | 表示対象ファイルの親ディレクトリ。相対パス解決の基準 |
