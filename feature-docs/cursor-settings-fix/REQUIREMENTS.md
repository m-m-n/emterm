# カーソル設定反映バグ修正 - 要件定義書

## 1. 概要

### 1.1 背景

ターミナル動作設定画面のカーソル関連設定が描画に正しく反映されない不具合が3件報告された。

1. カーソルスタイルを変更してもブロックのまま変わらない
2. カーソル点滅をオフにしても別タブに切り替えると点滅が復活する
3. カーソルの色がフォアグラウンドテキストの色と同じになる（カラースキームには別の cursor 色が定義されている）

### 1.2 目的

カーソルのスタイル・点滅・色が、設定値およびカラースキーム定義どおりに描画されるようにする。

### 1.3 スコープ

- 対象: GUI ターミナルのカーソル描画（`src-tauri`、必要に応じて `crates/term_core`）
- 対象外: 子 WebView（ビューア・設定パネル）側の変更、新しい設定項目の追加

## 2. 現象と原因構造（調査済み）

| # | 現象 | 原因構造 |
|---|------|----------|
| 1 | スタイル変更が効かない | レンダラー（`src-tauri/src/render/mod.rs` カーソルオーバーレイ）は `core.get_cursor_style()` を読むが、`TerminalCore::set_cursor_style` の呼び出し元が存在しない。設定値は `theme.cursor_style` にのみ反映され、描画に届かない |
| 2 | 点滅オフがタブ切り替えで復活 | `blink` が `CursorState`（DECSC/DECRC の save/restore 対象）に同居しており、save/restore・リセット経路で設定前の値や既定値に戻る |
| 3 | カーソル色が fg と同じ | レンダラーが `core.get_cursor_fg()`（SGR のペン色 = テキスト fg）をカーソル色として使用し、`theme.cursor_fg`（カラースキームの cursor 色）を参照していない |

## 3. 機能要件

### 3.1 機能一覧

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | カーソルスタイルの反映 | 設定画面のカーソルスタイル（block / underline / bar）が描画に反映される | 高 |
| F02 | カーソル点滅設定の維持 | 点滅オフがタブ切り替え・save/restore・リセットを跨いで維持される | 高 |
| F03 | カーソル色の反映 | カラースキーム定義の cursor 色でカーソルを描画する | 高 |
| F04 | エスケープシーケンス優先 | DECSCUSR / OSC 22 / OSC 12 による明示指定は設定より優先し、リセットで設定値に戻る | 高 |
| F05 | 全タブへの即時適用 | 設定変更は既存の全タブへ即時反映される | 高 |

### 3.2 機能詳細

#### F01: カーソルスタイルの反映

- 設定値（block / underline / bar）がカーソルオーバーレイの形状として描画される
- タブ切り替え・新規タブでも設定値が維持される

#### F02: カーソル点滅設定の維持

- `cursor_blink: false` のとき、タブ切り替え・DECSC/DECRC・端末リセットのいずれを経ても点滅しない
- `cursor_blink: true` のときは従来どおり点滅する

#### F03: カーソル色の反映

- 選択中カラースキームが定義する cursor 色でカーソルを描画する
- テキストのフォアグラウンド色（SGR ペン色）をカーソル色として使用しない

#### F04: エスケープシーケンス優先

- DECSCUSR / OSC 22 でアプリがカーソルスタイル（点滅指定を含む）を明示指定した場合はそれが勝つ
- OSC 12 でアプリがカーソル色を指定した場合はそれが勝つ
- リセット（DECSCUSR デフォルト指定、OSC 112、端末リセット）で設定値／カラースキーム色に戻る

#### F05: 全タブへの即時適用

- 設定画面での変更は保存時に既存の全タブへ反映される

## 4. 非機能要件

- 描画パフォーマンスを劣化させない（レンダリングホットパスに重い処理を追加しない）
- CLI ビルド（`--no-default-features`）のコンパイルを壊さない

## 5. 制約条件

- 新しい設定項目は追加しない（既存の `cursor_style` / `cursor_blink` とカラースキーム定義のみ）
- ベンチマーク参照方針: 挙動判断で迷う場合は Alacritty / WezTerm の方針を先に調査する（コード転用は禁止）

## 6. 成功基準

- [ ] 設定画面でカーソルスタイルを変更すると、全タブのカーソル形状が変わる
- [ ] 点滅オフにした後、タブを切り替えても点滅しない
- [ ] カーソルがカラースキーム定義の cursor 色で描画される
- [ ] vim 等の DECSCUSR 指定が設定より優先され、終了後に設定値へ戻る
- [ ] 既存テストが全て通る

## 7. 確認事項

### 7.1 確認済み事項

- [x] エスケープシーケンス（DECSCUSR / OSC 22 / OSC 12）と設定の優先関係: シーケンス優先。設定はデフォルト値で、リセット時に設定値へ戻る
- [x] 適用タイミング: 設定変更は既存の全タブへ即時適用
- [x] カーソル色: カラースキーム（テーマ）定義の cursor 色を使用。カスタム色設定項目の新設は不要。OSC 12/112 の動的上書きは維持

- なし
