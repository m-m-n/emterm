# Task Plan: task0004 — OSC 12 cursor-color override lifecycle (rework)

## Goal

An app-set OSC 12 cursor-color override survives a settings apply and is
cleared back to the scheme cursor color by terminal reset (RIS), closing the
two review round-1 spec gaps (findings c6ef2f448279d56e, 247075b264053ce9).

## Requirements

FR4, FR5

## Scope

### Files to Create
- (none)

### Files to Modify
- `src-tauri/src/render/theme.rs` — track whether `cursor_fg` currently
  carries an active OSC 12 override (set by the OSC 12 handler, cleared by
  the OSC 112 handler); add the authority-clarification comment on
  `cursor_style` (see Design)
- `src-tauri/src/app.rs` — settings-apply theme rebuild preserves an active
  OSC 12 cursor-color override while taking the new scheme's cursor color as
  the reset target
- `crates/term_core/src/terminal_core.rs` — surface a consumable "full reset
  (RIS) occurred" signal at the terminal level
- `crates/term_core/src/esc_handler.rs` — RIS path raises that signal (if the
  raise does not already fall out of the reset routine)
- `src-tauri/src/tabs.rs` — tab pump consumes the reset signal and restores
  `theme.cursor_fg` to the scheme cursor color (equivalent to the OSC 112
  handler), marking the theme dirty
- `src-tauri/src/callbacks.rs` — only if the reset signal is delivered
  through the existing callback mechanism instead of a polled flag (choose
  ONE delivery path; include this file in the set so either choice stays
  in-scope)

## Design

- Override tracking: the theme knows whether `cursor_fg` is scheme-derived
  or OSC-12-overridden. OSC 12 sets the override state; OSC 112 and the RIS
  restore path clear it and set `cursor_fg` to the scheme cursor color.
- Settings apply (FR5): after rebuilding a tab's theme from new settings,
  when the old theme carried an active OSC 12 override, carry the overridden
  `cursor_fg` (and the override state) into the new theme; `scheme_cursor_fg`
  always reflects the NEW settings' scheme. Shape/blink need no change (they
  already survive via terminal-level overrides).
- RIS (FR4): term_core stays GUI-agnostic — it only exposes the fact that a
  full reset happened (flag consumed on read, or an action through the
  existing parser-callback channel; implementer picks the one that matches
  existing patterns). The GUI layer performs the theme-side color restore.
  RIS must also continue to clear the shape/blink overrides (existing
  behavior, do not regress).
- Authority comment (round-1 deferred finding 9c2cd5aa4b85533e): document on
  `Theme.cursor_style` that the terminal cursor's rendered shape is owned by
  `TerminalCore::get_cursor_style()` and that `Theme.cursor_style` is not a
  renderer input.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: OSC 12 sets an override: after it, the theme reports the OSC
      color and an active override state; OSC 112 clears the state and
      restores the scheme cursor color (existing behavior preserved).
- [ ] AC-2: With an active OSC 12 override, a settings apply that does not
      change the color scheme leaves the resolved cursor color at the OSC
      value.
- [ ] AC-3: With an active OSC 12 override, a settings apply that changes
      the color scheme updates `scheme_cursor_fg` to the new scheme's cursor
      color while the resolved cursor color stays at the OSC value; a
      subsequent OSC 112 restores the NEW scheme's cursor color.
- [ ] AC-4: With no active override, a settings apply resolves the cursor
      color to the (possibly new) scheme cursor color — same as today.
- [ ] AC-5: Feeding RIS bytes after OSC 12 restores the resolved cursor
      color to the scheme cursor color and clears the override state.
- [ ] AC-6: RIS continues to clear shape/blink overrides (no regression of
      task0001 AC-8).
- [ ] AC-7: `Theme.cursor_style` carries the authority-clarification comment.

## Test Notes

- AC-1..AC-4 are unit tests in `render/theme.rs` / `app.rs` following the
  existing settings-apply and OSC 12/112 test patterns.
- AC-5/AC-6 split naturally: a term_core test that RIS raises the signal +
  clears overrides, and a GUI test that the tab consumes the signal and
  restores the theme color (same pattern as existing tab pump tests).
- AC-7 is verified by inspection (no test).
