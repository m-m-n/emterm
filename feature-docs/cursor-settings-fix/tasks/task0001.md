# Task Plan: task0001 — term_core effective cursor state + DECSCUSR / OSC 22

## Goal

`crates/term_core` becomes the single authority for the effective cursor
shape and blink: settings-derived defaults survive save/restore and reset,
and DECSCUSR / OSC 22 overrides take precedence until explicitly reset.

## Requirements

FR1, FR2, FR4, FR5, NFR2

## Scope

### Files to Create
- (none)

### Files to Modify
- `crates/term_core/src/terminal_core.rs` — terminal-level cursor
  default/override state; remove shape/blink from per-cursor saved state
- `crates/term_core/src/terminal_cursor.rs` — getter/setter semantics
  (defaults vs effective), save/restore no longer touches shape/blink
- `crates/term_core/src/csi_dispatch.rs` — route `CSI Ps SP q` (DECSCUSR)
- `crates/term_core/src/csi_cursor.rs` — DECSCUSR handler (if handlers for
  cursor CSI live here per existing layout)
- `crates/term_core/src/osc_handler.rs` — OSC 22 sets/clears the shape
  override inside the core (existing theme-bound emission stays)
- `crates/term_core/src/esc_handler.rs` — full reset (RIS) clears overrides
- `crates/term_core/src/snapshot.rs` — audit: snapshot/restore consistency
  with the relocated shape/blink state

## Design

State model (D1 in IMPLEMENTATION.md):

- Terminal-level fields: default shape, default blink, optional shape
  override, optional blink override. None of them live in `CursorState`, so
  DECSC/DECRC (`save_cursor` / `restore_cursor`) and the no-saved-state reset
  path cannot alter them.
- `get_cursor_style()` / `get_cursor_blink()` → override when present, else
  default (contract pinned in IMPLEMENTATION.md Shared Components).
- `set_cursor_style(u8)` / `set_cursor_blink(bool)` → update the default
  only; active overrides are preserved (FR5).
- Defaults initialize to shape 0 (block) / blink true, matching current
  `CursorState::new` behavior for un-seeded cores.

Sequence handling:

- DECSCUSR (`CSI Ps SP q`, intermediate = space, final = `q`): Ps 1/2 →
  block, 3/4 → underline, 5/6 → bar; odd Ps blinks, even Ps steady; Ps 0 or
  absent clears both overrides. Values above 6 are ignored (no state change),
  matching lenient terminal behavior.
- OSC 22: a recognized style name ("block" / "underline" / "bar") sets the
  shape override; an empty payload clears the shape override. Blink override
  untouched. Unrecognized names are ignored. The existing action emission to
  the GUI theme layer is preserved unchanged (D2).
- RIS / full reset: clears both overrides; defaults survive (they are
  configuration, not terminal state).
- Alt-screen enter/leave (mode 1049 save/restore paths) must round-trip
  without altering effective shape/blink.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: After `set_cursor_blink(false)`, a `save_cursor` →
      `restore_cursor` round-trip leaves `get_cursor_blink()` false.
- [ ] AC-2: After `set_cursor_blink(false)`, `restore_cursor` with NO saved
      state (reset path) leaves `get_cursor_blink()` false.
- [ ] AC-3: `set_cursor_style(2)` (bar) makes `get_cursor_style()` return 2,
      and it stays 2 across save/restore and the no-saved-state reset path.
- [ ] AC-4: Feeding the DECSCUSR bytes for Ps=3 (blinking underline) makes
      `get_cursor_style()` = 1 and `get_cursor_blink()` = true regardless of
      defaults; feeding Ps=0 afterwards restores both getters to the
      settings-derived defaults.
- [ ] AC-5: Feeding DECSCUSR Ps=4 (steady underline) with default blink true
      yields `get_cursor_blink()` = false while the override is active.
- [ ] AC-6: Feeding OSC 22 "underline" bytes makes `get_cursor_style()` = 1
      with defaults intact underneath; feeding OSC 22 with an empty payload
      restores the default shape. Blink is unaffected in both steps.
- [ ] AC-7: With a DECSCUSR override active, calling `set_cursor_style` /
      `set_cursor_blink` (settings apply) changes only the defaults — the
      effective getters keep returning the override until it is cleared.
- [ ] AC-8: Full terminal reset (RIS) clears active overrides and the
      effective getters return the defaults.
- [ ] AC-9: Alt-screen enter → leave (mode 1049 sequence bytes) does not
      change the effective shape or blink.
- [ ] AC-10: Existing term_core test suite passes unmodified except where a
      test asserted the old (CursorState-resident) semantics directly.

## Test Notes

- All criteria are unit-testable inside `term_core` by feeding raw byte
  sequences through the existing parser entry point and asserting getters —
  same pattern as existing dispatch tests.
- AC-4/AC-5 exercise the parser path (intermediate byte handling), not just
  the handler function.
- Snapshot audit: if `snapshot.rs` serializes cursor shape/blink, add a
  round-trip assertion; if it never did, record that as a test note, not new
  scope.
