# mux-agent-tab-cycle - 要件定義書

## 1. 概要

### 1.1 背景

どのタブで何のエージェントが動いているか分からない状態がある。

### 1.2 目的

- キー操作で、エージェントが起動している mux タブだけを順次辿れるようにする
- どのタブで何のエージェントが動いているか分からない状態を、巡回操作で解消する

### 1.3 スコープ

既存のタブ切り替え・キー入力機構への挙動追加。新規 UI 表面は持たない。

## 2. ビジネス要件

### 2.1 ビジネス目標

- キー操作で、エージェントが起動している mux タブだけを順次辿れるようにする
- どのタブで何のエージェントが動いているか分からない状態を、巡回操作で解消する

### 2.2 対象ユーザー

| ユーザータイプ | 説明 |
|----------------|------|
| mux 利用者 | 複数の mux タブでエージェントを動かす eMterm ユーザー |

### 2.3 期待される効果

- エージェントが起動している mux タブだけをキー操作で順次辿れる
- どのタブで何のエージェントが動いているか分からない状態が、巡回操作で解消される

## 3. ユースケース

### 3.1 ユースケース一覧

| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | エージェントタブ巡回 | mux 利用者 | 高 |

### 3.2 ユースケース詳細

#### UC01: エージェントタブ巡回

**アクター**: mux 利用者

**事前条件**:
- 現在のタブが mux タブである
- エージェントが起動しているタブが 1 つ以上存在する

**基本フロー**:
1. 利用者が巡回キー操作を行う
2. エージェントが起動しているタブのみを対象に、タブバーの表示順で次の対象タブを決定する
3. 決定した対象タブへ切り替える

**代替フロー**:
- 末尾の対象タブから操作した場合、先頭の対象タブへラップアラウンドする
- 現在のタブが mux タブでない場合、何も行わない（noop）
- エージェントが起動しているタブが 1 つも存在しない場合、何も行わない（noop）

**事後条件**:
- 対象タブがアクティブになっている（noop の場合はアクティブタブが変化しない）

## 13. 用語定義

| 用語 | 定義 |
|------|------|
| mux タブ | mux（ターミナル内蔵のマルチプレクサ）のタブ |
| エージェントが起動しているタブ | 巡回対象とするタブ。対象となるエージェント状態集合は FR6 で未確定 |
| 巡回 | 対象タブへ順次切り替える操作 |
| ラップアラウンド | 末尾の対象タブの次を先頭の対象タブとする挙動 |
