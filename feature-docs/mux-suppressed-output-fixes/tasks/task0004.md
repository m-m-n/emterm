# Task Plan: task0004 — Remove the ResumeWithSnapshot branch

## Goal

`evaluate_output_target` never moves a pane from Detached to Connected. Only `resume_pane_with_permit` makes a pane visible, and that production path is proven to deliver the snapshot before a suppressed chunk's replacement and the next chunk.

## Requirements

FR10, NFR2, NFR6

### Files to Create

### Files to Modify

- `src-tauri/src/mux/session/pane/tests.rs` — delete the variant-matching tests, port the poison and hide/show-roundtrip tests to the production resume path, add the ordering regression test
- `src-tauri/src/mux/snapshot_bytes.rs` — documentation only: drop references to the removed branch

## Design

### The would-be resume case

This is a Detached pane whose owner matches the caller and whose reasons would all clear: visible, and no network detach. In that case `evaluate_output_target`:
- leaves the target and its reason exactly as they were;
- returns the unchanged result;
- sends and records nothing (no boundary).

Every other transition stays as today:
- Connected to Detached on hide.
- Reason combining.
- Owner assignment.
- Owner-mismatch no-op.

The only production caller, the hidden side of the visibility handler (visible = false), is unaffected.

### Test changes

- **Deleted.** The tests that match the removed variant, i.e. the resume-branch tests in pane/tests.rs that expect the variant.
- **Ported.** Their still-relevant properties are re-established through `resume_pane_with_permit`:
  - poisoned shadow parser recovery (ported from the variant-based poison test);
  - hide then show on the same connection (hide via `evaluate_output_target` with visible = false, show via `resume_pane_with_permit`).
- **Already covered.** Two properties already have production-path tests, which must stay unmodified: the wrapped-ring header row and the oversize snapshot.

### Ordering regression (TS-12)

Use a Detached (hidden) pane and a reader paused at P2 on a chunk whose only special content is one main-buffer CSI device query, e.g. text, ESC [ 6 n, text. This is an input covered by the IMPLEMENTATION.md "Suppressed-chunk delivery contract".
1. Drive the production visible path: the visibility handler's visible side, or the resume helper it uses, down to `resume_pane_with_permit`.
2. Release the reader.
3. The destination must receive, in order: the Snapshot-kind chunk, then the replacement (the query bytes), then the next reader chunk.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1 (FR10): The ResumeWithSnapshot variant no longer exists. For a Detached pane with a matching owner, calling `evaluate_output_target` with visible = true and no network detach leaves the target (state, reason and owner) unchanged, returns the unchanged result, and puts nothing on the destination channel (test evaluate_output_target_never_resumes_a_detached_pane).
- [ ] AC-2 (FR10): The existing hide-side tests of `evaluate_output_target` pass unmodified. These cover Connected to Detached, reason combining and owner mismatch.
- [ ] AC-3 (FR10, NFR2; TS-12): On the production visible path with a paused reader, the destination receives the Snapshot-kind chunk first, then the suppressed chunk's replacement, then the next reader chunk, and nothing else (test production_visible_resume_delivers_snapshot_before_replacement_and_next_chunk).
- [ ] AC-4 (FR10; TS-12): Through `resume_pane_with_permit`:
  - A pane whose shadow parser was poisoned resumes successfully with a decodable Snapshot-kind chunk (test resume_pane_with_permit_recovers_a_poisoned_shadow_parser).
  - Hide then show on the same connection ends Connected to that connection with one Snapshot-kind chunk delivered (test resume_pane_with_permit_hide_show_roundtrip_on_same_connection).
- [ ] AC-5 (FR10): The existing resume tests for the wrapped-ring header row and the oversize snapshot pass unmodified. No documentation in the four files above still refers to the removed branch.
- [ ] AC-6 (NFR6, AC-8 of SPEC): `CARGO_TARGET_DIR=src-tauri/target cargo test --manifest-path src-tauri/Cargo.toml --lib` and `CARGO_TARGET_DIR=src-tauri/target cargo check --manifest-path src-tauri/Cargo.toml --no-default-features` both pass. Every deleted or ported test is listed with its reason, and all other existing tests pass unmodified.

## Test Notes

- **Where the tests go.** All tests are integration-level in pane/tests.rs, next to the existing resume tests, reusing the existing poison and snapshot-decode helpers.
- **Reader for AC-3.** Mirror the existing paused-reader production-resume test.
- **Payload assertions.** Assert order and kinds. Assert the replacement's bytes only for the single main-buffer query input. Do not assert alternate-screen resume payload bytes, since the alt layout may change in parallel.
