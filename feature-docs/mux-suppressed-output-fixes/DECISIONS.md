## 既知の欠落レジスタ（IMPLEMENTATION.md D6）

- 抑止したチャンクのインライン画像（Kitty APC・SIXEL DCS）は届けず、既知の欠落として残す（FR7）。
- 保持した末尾（上限 N = 256 バイト）の中に未完了シーケンスの開始が無いときは、通常状態から走査する。リングに書かない区間（代替画面側）で N を超える文字列の途中から続く場合は、既知の欠落として記録する（FR6、as-05）。ただし、リング区間の文字列は pending が覆う。
- term_core の OSC 番号累積で起きる u16 のあふれ（osc.rs:22、as-06）は、このフィーチャーでは直さない。分類器はそのような OSC を問い合わせではないものとして扱うため、見落としが起きるだけで誤った応答は生じない。
