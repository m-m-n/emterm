## Design

### The pinned shape and contract

Shape: a bypass-requested snapshot whose entire pre-suffix region is a
single uniform run at `(target_cols, R)` with `R` strictly greater than
the caller's target rows (if `R` equaled the target, the suffix scan would
already start at offset zero and no fold question arises), followed by a
qualifying stable target-dims suffix. For this input,
`leading_uniform_run_len` reports a candidate covering the whole pre-suffix
region (`candidate_h == k`), and the guard abandons the fold, taking the
pre-D7 path.

Contract to pin (IMPLEMENTATION.md Shared Components, Empty-MIDDLE
degradation contract): the built core comes out at the caller-requested
`(cols, rows)` — not at the HEAD run's `R` — and `scrollback_populated`
matches a reference non-bypass build of the same payload/segments. The
round-2 finding's empirically-confirmed failure (requested (80, 24), got
(80, 30), `scrollback_populated` false vs the reference's true) is the
fixture basis: the test must be one that would have FAILED against the
pre-auto-fix code.

### Failure handling

If the pin fails against the current code, the auto-fix is wrong — report
that as a deviation to the orchestrator instead of changing gate code
(D-A: the gate region is task0001's exclusive surface, and the two tasks
run in parallel).
