# ステータスバー App Line 1 の自動非表示 - 要件定義書

## 1. 概要

### 1.1 背景
ステータスバーのトグル（`statusbar_enabled`）を有効にすると、App Line 1 は表示対象（テンプレート）が設定されていなくても常に描画される。mux の OSC 行だけを使いたい構成では、内容のない空行が 1 行表示され続けてしまう。

### 1.2 目的
表示する内容がない行を描画しないようにし、mux ステータスバー（OSC 行）のみの運用で空行が出ないようにする。

### 1.3 スコープ
- `src-tauri/src/ui/status_bar.rs` の行可視判定（`visible_row_count` / `draw`）
- App Line 1 の可視判定の変更のみ。App Line 2 / OSC 行の既存 auto-hide ルールと `statusbar_enabled` の挙動は変更しない

## 2. ビジネス要件

### 2.1 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| eMterm 利用者 | ステータスバーを mux OSC 行のみで使いたい利用者を含む |

### 2.2 期待される効果
- 表示対象未設定時に空行が出ず、ターミナル表示領域が無駄にならない

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | mux OSC 行のみを表示する | 利用者 | 高 |
| UC02 | App Line 1 に内容がある通常利用 | 利用者 | 高 |

### 3.2 ユースケース詳細

#### UC01: mux OSC 行のみを表示する

**アクター**: 利用者

**事前条件**:
- `statusbar_enabled: true`
- `statusbar_app_line1_left` / `statusbar_app_line1_right` / App Line 2 の設定が空（または解決結果が空）

**基本フロー**:
1. mux 未接続（OSC 行も非表示）の間はステータスバー自体が表示されず、高さ 0 で領域がターミナルに返る
2. mux daemon から StatusUpdateMsg が届くと OSC 行のみが表示される

**事後条件**:
- 空の App Line 1 行が表示されない

#### UC02: App Line 1 に内容がある通常利用

**基本フロー**:
1. テンプレートの解決結果が空でない場合、従来どおり App Line 1 が表示される

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | App Line 1 auto-hide | 解決後の内容が空なら App Line 1 を非表示にする | 高 |
| F02 | 全行非表示時のバー消滅 | 表示行が 0 のときバー自体を描画せず高さを 0 にする | 高 |

### 4.2 機能詳細

#### F01: App Line 1 auto-hide

**説明**: App Line 1 の可視判定を「常に表示」から「解決後の内容（`AppRow::has_content()`）が空なら非表示」に変更する。App Line 2 と同じ判定基準に統一する。

**ビジネスルール**:
- 判定は設定文字列ではなく解決後の内容で行う（テンプレートが設定されていても実行時に空文字へ解決された場合は非表示）
- App Line 2 / OSC 行の既存ルールは変更しない

#### F02: 全行非表示時のバー消滅

**説明**: OSC 行・App Line 1・App Line 2 のすべてが非表示のとき、ステータスバーのパネルを挿入せず、高さ分の領域をターミナル表示に返す。

## 5. 非機能要件

### 5.1 保守性要件
- 既存のフレーム間 view model 比較（PartialEq によるダーティ判定）と両立すること

### 5.2 互換性要件
- CLI ビルド（`--no-default-features`）のコンパイルに影響しないこと

## 9. 制約条件

### 9.1 技術的制約
- `statusbar_enabled: false` の短絡（描画スキップ）は現状維持

## 11. 成功基準

### 11.1 受け入れ基準
- [ ] `statusbar_enabled: true` かつ全行の内容が空のとき、ステータスバーが表示されない（高さ 0）
- [ ] App Line 1 の内容が空で OSC 行に内容があるとき、OSC 行のみが表示される
- [ ] App Line 1 に内容があるとき、従来どおり表示される
- [ ] App Line 2 / OSC 行の既存 auto-hide 挙動が変化しない

### 12.1 テスト観点
- [ ] 正常系: App Line 1 に内容あり → 表示される

- [ ] 境界値: テンプレートは設定済みだが解決結果が空 → 非表示
