# Task Plan: task0001 — emterm --version flag

## Goal

`emterm --version` prints the crate version to stdout and exits 0, in both
the GUI build and the CLI-only build, with no side effects.

## Requirements

FR1, FR2, NFR1

## Scope

### Files to Create

- (none)

### Files to Modify

- `src-tauri/src/main.rs` — add `--version` handling to the pre-logging
  argument dispatch block
- `src-tauri/tests/cli_subcommands.rs` — add integration test coverage for
  the flag (existing integration-test file for CLI entry behavior)

## Design

Per IMPLEMENTATION.md D1: in `main()`, before `logging::init()` and before
any GUI-feature-gated code, when the first argument equals `--version`:

- write the compile-time crate version (the `CARGO_PKG_VERSION` environment
  value baked in at build time) plus a trailing newline to stdout
- terminate the process with exit status 0

Behavioral conditions:

- Only the first argument position is inspected; `emterm --version anything`
  still prints the version and exits 0 (later arguments ignored).
- Any argument other than `--version` in that position leaves existing
  behavior completely unchanged (out-of-scope issue in D1's note).
- No logger initialization, no settings read, no window/event-loop creation
  on the `--version` path.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: Running the built binary with `--version` writes exactly the
  crate version string followed by one newline to stdout and exits with
  status 0.
- [ ] AC-2: On the `--version` path, stderr output is empty.
- [ ] AC-3: `--version` followed by extra arguments behaves identically to
  AC-1.
- [ ] AC-4: The crate compiles with default features and with
  `--no-default-features` (flag handling sits outside all feature gates).
- [ ] AC-5: All pre-existing tests keep passing.

## Test Notes

- AC-1..AC-3 translate to integration tests that spawn the built binary
  (same technique the existing `cli_subcommands.rs` tests use) and assert
  stdout/stderr/exit status.
- AC-4 is verified by the two approved check commands (default features and
  `--no-default-features`).
- Version-string equality can be asserted against the same compile-time
  version value from the test crate.

## Out of Scope

- `-V` short alias, `version` bare-word subcommand.
- Fixing the "unknown flags fall through to GUI startup" issue.
- Any change to the settings-panel IPC version reporting.
