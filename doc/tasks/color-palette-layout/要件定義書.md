# カラーパレットエディタのレイアウト変更 - 要件定義書

## 1. 概要

### 1.1 背景
設定画面のカラースキームエディタにおいて、色の編集UIが縦に長くなり視認性が低下している。

### 1.2 目的
カラーパレットエディタのレイアウトを横並びに変更し、コンパクトで視認性の高いUIを実現する。

### 1.3 スコープ
- カラーパレットエディタのCSSおよびHTML構造の変更
- 対象：特殊色（前景色、背景色、カーソル、選択）
- 対象：ANSI 16色（標準色0-7、高輝度色8-15）

## 2. ビジネス要件

### 2.1 ビジネス目標
ユーザーが色設定を効率的に行えるUI

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 一般ユーザー | ターミナルの色をカスタマイズしたいユーザー |

### 2.3 期待される効果
- カラーパレット全体を一度に視認できる
- 縦スクロールの削減

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | カラーパレット閲覧 | ユーザー | 高 |
| UC02 | 色の編集 | ユーザー | 高 |

### 3.2 ユースケース詳細

#### UC01: カラーパレット閲覧

**アクター**: ユーザー

**事前条件**:
- 設定画面でカラースキームエディタが表示されている

**基本フロー**:
1. ユーザーがカラーパレット領域を確認する
2. 特殊色4色と標準色8色、高輝度色8色が表示されている
3. 各色のラベル、カラーピッカー、HEX値が横に並んでいる

**事後条件**:
- 全ての色設定が一覧で確認できる

#### UC02: 色の編集

**アクター**: ユーザー

**基本フロー**:
1. カラーピッカーをクリックして色を選択
2. またはHEX入力欄に直接値を入力
3. 変更がリアルタイムで適用される

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 特殊色の横並びレイアウト | 前景色、背景色、カーソル、選択を1行に並べる | 高 |
| F02 | 標準色の横並びレイアウト | ANSI色0-7をラベル付きで1行に並べる | 高 |
| F03 | 高輝度色の横並びレイアウト | ANSI色8-15をラベル付きで1行に並べる | 高 |

### 4.2 機能詳細

#### F01: 特殊色の横並びレイアウト

**説明**: 前景色、背景色、カーソル、選択の4色を横1行に並べる

**レイアウト仕様**:
```
前景色 ■ HEX    背景色 ■ HEX    カーソル ■ HEX    選択 ■ HEX
```

**構成要素**:
- ラベル（色の名前）
- カラーピッカー（■の視覚的表現）
- HEX入力欄（#RRGGBB形式）

#### F02: 標準色の横並びレイアウト

**説明**: ANSI標準色（0-7）を横1行に並べる

**レイアウト仕様**:
```
標準色
0 ■ HEX    1 ■ HEX    2 ■ HEX    3 ■ HEX    4 ■ HEX    5 ■ HEX    6 ■ HEX    7 ■ HEX
```

**構成要素**:
- セクションラベル（「標準色」）
- 各色にナンバリング（0-7）
- カラーピッカー
- HEX入力欄

#### F03: 高輝度色の横並びレイアウト

**説明**: ANSI高輝度色（8-15）を横1行に並べる

**レイアウト仕様**:
```
高輝度色
8 ■ HEX    9 ■ HEX    10 ■ HEX   11 ■ HEX   12 ■ HEX   13 ■ HEX   14 ■ HEX   15 ■ HEX
```

**構成要素**:
- セクションラベル（「高輝度色」）
- 各色にナンバリング（8-15）
- カラーピッカー
- HEX入力欄

## 5. 非機能要件

### 5.1 パフォーマンス要件
- 既存の動作速度を維持

### 5.2 レスポンシブ対応
- 狭い画面幅では適切に折り返す（CSSグリッドで対応）

### 5.3 互換性要件
- 既存の機能（色変更、自動コピー、保存）は変更なし

## 6. UI/UX要件

### 6.1 レイアウト設計

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ [カラースキームセレクトボックス]                                                │
│ [複製] [削除] [リネーム]                                                        │
├────────────────────────────────────────────────────────────────────────────────┤
│ 前景色    背景色    カーソル    選択                                           │
│ ■ #HEX   ■ #HEX   ■ #HEX     ■ #HEX                                           │
├────────────────────────────────────────────────────────────────────────────────┤
│ 標準色                                                                         │
│  0       1       2       3       4       5       6       7                     │
│ ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX                        │
├────────────────────────────────────────────────────────────────────────────────┤
│ 高輝度色                                                                       │
│  8       9      10      11      12      13      14      15                     │
│ ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX  ■ HEX                        │
└────────────────────────────────────────────────────────────────────────────────┘
```

### 6.2 色入力コンポーネント詳細

各色の入力要素は以下で構成：
1. **ラベル**: 色名または番号（特殊色は名前、ANSI色は番号）
2. **カラーピッカー**: ブラウザネイティブの`<input type="color">`
3. **HEX入力欄**: `#RRGGBB`形式のテキスト入力

### 6.3 レスポンシブ対応

- 十分な幅: 8色が1行に収まる
- 狭い幅: CSSグリッドの`auto-fit`で自動折り返し
