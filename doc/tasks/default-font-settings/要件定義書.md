# デフォルトフォント設定 - 要件定義書

## 1. 概要

### 1.1 背景
eMtermターミナルエミュレータは現在、CSS で `"Menlo", "Monaco", "Courier New", monospace` をデフォルトフォントとして使用している。しかし、以下の問題がある：
- 日本語フォントの明示的な指定がなく、システムのフォールバックに依存
- 絵文字フォントの指定がなく、表示が環境依存
- タイポグラフィの標準単位であるpt単位でフォントサイズを指定したい（13pt ≈ 17.33px）

### 1.2 目的
- 等幅フォント（Inconsolata）をプライマリフォントとして設定
- 日本語表示用に Noto Sans JP を明示的に指定
- 絵文字表示用に Noto Color Emoji を明示的に指定
- フォントサイズを13pt（約17.33px）に変更
- 将来の設定ファイルによるカスタマイズに備えた構造にする

### 1.3 スコープ
- `src/styles.css` のフォント設定変更
- CSS変数 `--terminal-font-size` の値変更
- 関連するline-height調整

## 2. ビジネス要件

### 2.1 ビジネス目標
- ターミナル表示の一貫性向上
- 日本語・絵文字の表示品質改善
- 開発者体験の向上

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 開発者 | 日常的にターミナルを使用する開発者 |
| 日本語ユーザー | 日本語ファイル名やコメントを扱うユーザー |

### 2.3 期待される効果
- ASCII文字の視認性向上（Inconsolata の採用）
- 日本語テキストの一貫した表示
- 絵文字の正確な表示

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | ASCII文字の表示 | ユーザー | 高 |
| UC02 | 日本語テキストの表示 | ユーザー | 高 |
| UC03 | 絵文字の表示 | ユーザー | 中 |

### 3.2 ユースケース詳細

#### UC01: ASCII文字の表示

**アクター**: ユーザー

**事前条件**:
- eMtermが起動している
- Inconsolataフォントがシステムにインストールされている

**基本フロー**:
1. ユーザーがASCII文字を入力または表示
2. システムがInconsolataフォントで文字をレンダリング
3. 等幅で視認性の高い表示が行われる

**代替フロー**:
- Inconsolataがインストールされていない場合、次のフォールバックフォントが使用される

**事後条件**:
- ASCII文字が等幅で正しく表示される

#### UC02: 日本語テキストの表示

**アクター**: ユーザー

**事前条件**:
- eMtermが起動している
- Noto Sans JPフォントがシステムにインストールされている

**基本フロー**:
1. ユーザーが日本語テキストを入力または表示
2. システムがNoto Sans JPフォントで文字をレンダリング
3. 日本語が正しく表示される

**代替フロー**:
- Noto Sans JPがインストールされていない場合、システムのデフォルト日本語フォントが使用される

**事後条件**:
- 日本語テキストが正しく表示される

#### UC03: 絵文字の表示

**アクター**: ユーザー

**事前条件**:
- eMtermが起動している
- Noto Color Emojiフォントがシステムにインストールされている

**基本フロー**:
1. ユーザーが絵文字を入力または表示
2. システムがNoto Color Emojiフォントで絵文字をレンダリング
3. カラー絵文字が正しく表示される

**代替フロー**:
- Noto Color Emojiがインストールされていない場合、システムのデフォルト絵文字フォントが使用される

**事後条件**:
- 絵文字がカラーで正しく表示される

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | フォントファミリー設定 | CSSのfont-familyを指定されたフォントスタックに変更 | 高 |
| F02 | フォントサイズ設定 | CSS変数を13pt（約17.33px）に変更 | 高 |
| F03 | 行高さ調整 | フォントサイズ変更に伴うline-heightを15ptに調整 | 高 |

### 4.2 機能詳細

#### F01: フォントファミリー設定

**説明**: ターミナル表示用のフォントスタックを変更

**現在の設定**:
```css
font-family: "Menlo", "Monaco", "Courier New", monospace;
```

**新しい設定**:
```css
font-family: "Inconsolata", "Noto Sans JP", "Noto Color Emoji", monospace;
```

**フォントフォールバック順序**:
1. **Inconsolata** - プライマリ等幅フォント（ASCII文字）
2. **Noto Sans JP** - 日本語フォント（ひらがな、カタカナ、漢字）
3. **Noto Color Emoji** - カラー絵文字
4. **monospace** - 最終フォールバック（システムデフォルト等幅フォント）

**変更対象箇所**:
- `body` の font-family
- `.markdown-content code` の font-family
- `.markdown-fullscreen-content pre code` の font-family（必要に応じて）

#### F02: フォントサイズ設定

**説明**: CSS変数でターミナルのフォントサイズを管理。pt単位はタイポグラフィの標準単位であり、他のターミナルアプリとの設定互換性が高いため採用する。

**現在の設定**:
```css
:root {
  --terminal-font-size: 14px;
}
```

**新しい設定**:
```css
:root {
  --terminal-font-size: 13pt;  /* approximately 17.33px */
}
```

#### F03: 行高さ調整

**説明**: フォントサイズ変更に伴い、適切な行間を維持

**現在の設定**:
```css
:root {
  --terminal-line-height: 16px;
}
```

**新しい設定**:
フォントサイズ13pt（約17.33px）に対して適切な行高さを設定。
- 推奨比率: 1.15〜1.2
- 設定値: 15pt（13pt × 1.15 ≈ 15pt）

```css
:root {
  --terminal-line-height: 15pt;
}
```

## 5. 非機能要件

### 5.1 パフォーマンス要件
- フォント変更によるレンダリング性能への影響なし
- 初回フォント読み込み時のレイアウトシフト最小化

### 5.2 互換性要件
- Linux環境での動作確認
- フォントがインストールされていない環境でも適切なフォールバック

### 5.3 保守性要件
- 将来の設定ファイル対応に備え、CSS変数を活用
- フォント設定は一箇所で管理

## 6. 制約条件

### 6.1 技術的制約
- 現時点ではCSS直接編集（ハードコード）
- 将来的に設定ファイルからの読み込みに対応予定
- ユーザーのシステムにフォントがインストールされている必要がある

### 6.2 設計制約
- 既存のフォント設定構造を大幅に変更しない
- Markdown表示部分のフォントは変更しない（サンセリフのまま）
