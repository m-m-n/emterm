# コマンド出力の折りたたみ - 要件定義書

## 1. 概要

### 1.1 背景

Claude Codeなどのツールは `git diff`, `cargo test` などの長大な出力を生成する。
過去のコマンド結果を確認する際、大量の出力がスクロールバックを占有し、目的のコマンドやその出力を探すのが困難になる。

### 1.2 目的

OSC 133のゾーン情報を活用し、コマンド出力をユーザー操作で折りたたみ可能にする。
また、CLI側からOSC拡張で折りたたみ区間を明示指定できる仕組みも提供する。

### 1.3 スコープ

- OSC 133ゾーン（C: output start〜D: output end）を折りたたみ対象として認識
- カスタムOSC拡張（OSC 777;emterm;fold）による任意区間の折りたたみ指定
- Canvas上でのサマリー行描画と折りたたみ状態の管理
- 折りたたみ機能のON/OFF設定

**スコープ外:**
- 自動折りたたみ（閾値ベースの自動トリガー）
- キーバインドでの折りたたみ操作
- 折りたたみ状態のセッション間永続化

## 2. ビジネス要件

### 2.1 ビジネス目標

ターミナル出力の視認性を向上し、長大な出力をコンパクトに表示可能にする。

### 2.2 対象ユーザー

| ユーザータイプ | 説明 |
|----------------|------|
| Claude Codeユーザー | AIツールの大量出力を効率的に閲覧したいユーザー |
| 開発者 | テスト・ビルド結果などの長い出力を扱うユーザー |
| CLIツール開発者 | 自作CLIツールの出力を折りたたみ対応したいユーザー |

### 2.3 期待される効果

- スクロールバック内の情報密度の向上
- 目的のコマンド出力への到達時間の短縮
- CLIツールとの連携による構造化された出力表示

## 3. ユースケース

### 3.1 ユースケース一覧

| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | コマンド出力を折りたたむ | ユーザー | 高 |
| UC02 | 折りたたんだ出力を展開する | ユーザー | 高 |
| UC03 | CLIからの折りたたみ区間指定 | CLIツール | 高 |
| UC04 | 折りたたみ機能のON/OFF | ユーザー | 中 |

### 3.2 ユースケース詳細

#### UC01: コマンド出力を折りたたむ

**アクター**: ユーザー

**事前条件**:
- 折りたたみ機能が有効（設定ON）
- OSC 133ゾーン情報、またはカスタムOSCで折りたたみ可能な区間が存在する

**基本フロー**:
1. ユーザーがスクロールバックを閲覧中に出力ゾーン（C〜D区間）を確認する
2. 出力ゾーンの先頭行付近をクリックする
3. 出力が折りたたまれ、サマリー行（1行）に置き換わる
4. サマリー行に「▶ {コマンド名} — {行数} lines (exit {code})」が表示される

**代替フロー**:
- OSC 133ゾーン情報がない出力: 折りたたみ不可（クリックしても何も起きない）

**事後条件**:
- 出力ゾーンが1行のサマリー行に置き換わっている
- スクロール位置が適切に調整される
- 折りたたみ状態はセッション終了まで保持される

#### UC02: 折りたたんだ出力を展開する

**アクター**: ユーザー

**事前条件**:
- 折りたたまれたサマリー行が存在する

**基本フロー**:
1. ユーザーがサマリー行をクリックする
2. 折りたたみが解除され、元の出力が表示される
3. スクロール位置が適切に調整される

**事後条件**:
- 元の出力内容が再表示される

#### UC03: CLIからの折りたたみ区間指定

**アクター**: CLIツール

**事前条件**:
- eMtermが折りたたみ機能を有効にしている

**基本フロー**:
1. CLIツールが `ESC ] 777 ; emterm ; fold ; begin ; {label} ST` を出力する
2. 折りたたみ対象のコンテンツが出力される
3. CLIツールが `ESC ] 777 ; emterm ; fold ; end ST` を出力する
4. begin〜end区間が折りたたみ可能として認識される

**代替フロー**:
- endなしにbeginが再度来た場合: 前のbeginは無視される
- beginなしにendが来た場合: 無視される

**事後条件**:
- 指定された区間が折りたたみ可能として表示される

#### UC04: 折りたたみ機能のON/OFF

**アクター**: ユーザー

**事前条件**:
- なし

**基本フロー**:
1. ユーザーが設定画面で折りたたみ機能のON/OFFを切り替える
2. OFF時は折りたたみ操作が無効化される

**事後条件**:
- 設定が保存される
- OFFにした場合、折りたたまれていた区間は展開される

## 4. 機能要件

### 4.1 機能一覧

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | OSC 133ベースの折りたたみ | C〜D区間の出力を折りたたみ可能にする | 高 |
| F02 | カスタムOSC折りたたみ | OSC 777;emterm;fold による任意区間指定 | 高 |
| F03 | サマリー行表示 | 折りたたみ時のサマリー行をCanvas上に描画 | 高 |
| F04 | クリックトグル | サマリー行/出力ゾーンのクリックで折りたたみ/展開 | 高 |
| F05 | 折りたたみ状態管理 | セッション中の折りたたみ状態の永続化 | 高 |
| F06 | スクロール位置調整 | 折りたたみ/展開時のスクロール位置の適切な調整 | 高 |
| F07 | 設定: 機能ON/OFF | 折りたたみ機能のグローバルON/OFF | 中 |

### 4.2 機能詳細

#### F01: OSC 133ベースの折りたたみ

**説明**: OSC 133ゾーンマーカー（C: output start、D: output end）で囲まれた出力区間を折りたたみ可能にする。

**入力**:
- SemanticZoneTrackerに記録されたC/Dマーカー

**出力**:
- 折りたたみ可能な出力ゾーンの識別

**ビジネスルール**:
- C〜D区間のみが折りたたみ対象
- B（command start）マーカーの行テキストをコマンド名として抽出
- D（output end）のexit codeをサマリー行に表示
- alternate buffer（viなど）内のゾーンは折りたたみ対象外

#### F02: カスタムOSC折りたたみ

**説明**: OSC 777;emterm;fold;begin/end シーケンスで任意の区間を折りたたみ可能にする。

**シーケンスフォーマット**:
- begin: `ESC ] 777 ; emterm ; fold ; begin ; {label} ST`
- end: `ESC ] 777 ; emterm ; fold ; end ST`

**ビジネスルール**:
- labelはサマリー行で「コマンド名」の代わりに使用される
- カスタムOSC折りたたみの場合、exit codeは表示しない（情報がないため）
- ネストは非対応。最も近いbegin-endペアが1つの折りたたみ区間
- beginが連続した場合、前のbeginは無効になり最新のbeginが使用される
- endが先に来た場合は無視

#### F03: サマリー行表示

**説明**: 折りたたみ時にCanvasにサマリー行を描画する。

**表示フォーマット**:
- OSC 133由来: `▶ {コマンド名} — {行数} lines (exit {code})`
- カスタムOSC由来: `▶ {label} — {行数} lines`

**デザイン**:
- 半透明バー背景（ターミナル背景に薄い色のオーバーレイ）
- exit 0: 通常テキスト色（dim/muted）
- exit 非0: 赤系テキスト色
- ▶ アイコンは折りたたみ時、▼ は展開時（クリック可能であることを示す）
- サマリー行は1行分の高さ

#### F04: クリックトグル

**説明**: マウスクリックで折りたたみ/展開を切り替える。

**クリック対象**:
- 折りたたみ時: サマリー行全体がクリック領域
- 展開時: 出力ゾーンの先頭行（C マーカーの行）がクリック領域

**ビジネスルール**:
- クリック領域の判定はCanvas座標からの逆算で行う
- 折りたたみ可能な領域にマウスオーバー時、カーソルをpointerに変更

#### F05: 折りたたみ状態管理

**説明**: 折りたたみ状態をセッション中保持する。

**データ構造**:
- 折りたたみ区間のID（ゾーンの開始行インデックスなど）
- 折りたたみ状態（collapsed/expanded）

**ビジネスルール**:
- スクロールバックの刈り取り（pruning）時に、刈り取られた区間の折りたたみ状態を削除
- タブ切り替え時に折りたたみ状態を保持
- alternate buffer切り替え時に折りたたみ状態を保持

#### F06: スクロール位置調整

**説明**: 折りたたみ/展開時にスクロール位置を適切に調整する。

**ビジネスルール**:
- 折りたたみ時: 折りたたまれた行数分スクロールオフセットを調整し、ユーザーの視点がジャンプしないようにする
- 展開時: 展開された行数分スクロールオフセットを調整する
- 現在の表示範囲より上の区間が折りたたまれた場合、表示行がずれないよう調整

#### F07: 設定: 機能ON/OFF

**説明**: 折りたたみ機能のグローバルON/OFF。

**デフォルト値**: ON（有効）

**ビジネスルール**:
- OFFに切り替えた場合、全ての折りたたみ状態が解除（展開）される
- ONに戻しても自動で折りたたまれない（手動トリガーのため）

## 5. 非機能要件

### 5.1 パフォーマンス要件

- 折りたたみ/展開操作: < 16ms（1フレーム内で完了）
- サマリー行描画: 既存のCanvas描画パイプラインに統合し、追加コスト最小
- 折りたたみ状態の管理: O(1)で特定区間の状態を取得

### 5.2 セキュリティ要件

- OSC入力による折りたたみラベル: Canvas描画のためXSSリスクなし
- ラベル文字列の長さ制限: 表示時に適切にトランケート

### 5.3 保守性要件

- ログ出力: 折りたたみ/展開操作をDEBUGレベルでログ出力
- 既存のSemanticZoneTrackerを拡張する形で実装

### 5.4 互換性要件

- OSC 133対応シェル（bash, zsh, fish）との互換性
- OSC 777;emterm;fold は非対応ターミナルで無視される（標準的なOSCフォールバック）

## 6. UI/UX要件

### 6.1 サマリー行デザイン

- 半透明バー背景（例: rgba(60, 60, 80, 0.3)）
- テキスト: 通常のターミナルフォント、やや小さめ or 同サイズ
- 成功時テキスト色: ターミナルのdim色
- 失敗時テキスト色: 赤系（例: #ff6b6b）
- 左端に ▶（折りたたみ時）/ ▼（展開時）アイコン
- 右端に行数表示

### 6.2 インタラクション

- マウスオーバー: カーソルがpointerに変化
- クリック: 即座に折りたたみ/展開
- アニメーション: なし（即座に切り替え）

## 7. データ要件

### 7.1 折りたたみ区間データ

| 項目 | 型 | 必須 | 説明 |
|------|-----|------|------|
| startLine | number | ○ | 折りたたみ区間の開始行（絶対行インデックス） |
| endLine | number | ○ | 折りたたみ区間の終了行（絶対行インデックス） |
| collapsed | boolean | ○ | 折りたたみ状態 |
| source | "osc133" \| "custom" | ○ | 折りたたみの由来 |
| label | string | × | カスタムOSCのラベル（source=customの場合） |
| commandText | string | × | コマンドテキスト（source=osc133の場合） |
| exitCode | number | × | exit code（source=osc133の場合） |
| lineCount | number | ○ | 折りたたまれる行数 |

## 8. 外部連携

### 8.1 連携システム

| システム名 | 連携方法 | データ |
|------------|----------|--------|
| シェル（bash/zsh/fish） | OSC 133 | ゾーン情報（A/B/C/D） |
| CLIツール | OSC 777;emterm;fold | 折りたたみ区間とラベル |

### 8.2 OSCシーケンス仕様

**OSC 133（既存）:**
- `ESC ] 133 ; A ST` - Prompt start
- `ESC ] 133 ; B ST` - Command start
- `ESC ] 133 ; C ST` - Output start
- `ESC ] 133 ; D [; exit_code] ST` - Output end

**OSC 777;emterm;fold（新規）:**
- `ESC ] 777 ; emterm ; fold ; begin ; {label} ST` - 折りたたみ区間開始
- `ESC ] 777 ; emterm ; fold ; end ST` - 折りたたみ区間終了

## 9. 制約条件

### 9.1 技術的制約

- Canvas描画ベースのため、折りたたみサマリー行はDOM要素ではなくCanvasで描画する
- 折りたたみにより仮想的な行数が変わるため、スクロール計算にオフセット調整が必要
- 既存のSemanticZoneTracker、Canvas rendererとの密結合を避ける設計が必要

### 9.2 ビジネス上の制約

- 折りたたみ機能は既存のターミナル機能（検索、プロンプトジャンプ）と干渉してはならない
- 検索は折りたたまれたコンテンツ内も対象にする（ただし折りたたまれている場合はスキップ or 展開して表示）

## 10. 想定される課題とリスク

### 10.1 技術的課題

| 課題 | 影響度 | 対応策 |
|------|--------|--------|
| スクロール計算の複雑化 | 高 | 折りたたみオフセットを別管理し、既存のスクロール計算に加算 |
| 折りたたみ行と検索の衝突 | 中 | 折りたたまれたコンテンツ内のマッチは展開して表示 |
| プロンプトジャンプとの整合性 | 中 | ジャンプ先が折りたたまれた区間内の場合は展開する |
| Canvas上のクリック判定 | 低 | 既存のクリックイベント座標変換を拡張 |

### 11.1 受け入れ基準

- [ ] exit code非0の場合、サマリー行が赤系で表示される
- [ ] OSC 777;emterm;fold;begin/end で任意区間を折りたたみ指定できる
- [ ] 折りたたみ状態がセッション中保持される

## 12. テストシナリオ

### 12.1 テスト観点

- [ ] 正常系: OSC 133のC〜D区間を折りたたんで展開
- [ ] 正常系: カスタムOSC fold;begin/endで折りたたんで展開
- [ ] 正常系: exit code 0のサマリー行表示
- [ ] 正常系: exit code非0のサマリー行表示（赤系）
- [ ] 異常系: beginなしにend → 無視される
- [ ] 異常系: endなしにbeginが再度 → 前のbeginは無効化
- [ ] 異常系: OSC 133でCはあるがDがない → 折りたたみ不可
- [ ] 境界値: 0行の出力区間 → 折りたたみ不可
- [ ] 境界値: 1行の出力区間 → 折りたたみ可能
- [ ] 境界値: スクロールバック刈り取りで消えた区間
- [ ] セキュリティ: ラベル文字列に長い文字列 → トランケート
- [ ] パフォーマンス: 多数の折りたたみ区間（100以上）でのレンダリング性能

## 13. 用語定義

| 用語 | 定義 |
|------|------|
| 折りたたみ (fold) | 複数行の出力を1行のサマリー行に圧縮して表示すること |
| サマリー行 | 折りたたまれた区間の概要を表示する1行 |
| ゾーン | OSC 133で定義されるプロンプト/コマンド/出力の区間 |
| 出力ゾーン | OSC 133のCマーカー（output start）からDマーカー（output end）までの区間 |
