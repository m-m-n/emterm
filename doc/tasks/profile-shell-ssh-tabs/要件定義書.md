# プロファイルエディタ SHELL/SSH タブUI - 要件定義書

## 1. 概要

### 1.1 背景
現在、プロファイルエディタモーダルではシェル設定フィールド（シェルパス、引数、環境変数、作業ディレクトリ）とSSH接続ドロップダウンがフラットに並んでいる。プロファイルはローカルシェルかSSH接続のどちらか一方を使うものであり、UIでその排他性を明確にする必要がある。

### 1.2 目的
プロファイルエディタモーダル内に SHELL | SSH タブを設け、ローカルシェル設定とSSH接続選択を排他的に切り替えられるUIにする。

### 1.3 スコープ
- プロファイルエディタモーダル（`profile-editor.ts`）のUI変更
- 関連CSS追加
- i18nキー追加

スコープ外:
- 左ナビゲーションのカテゴリ構造変更
- SSHセクション（settings-sections.ts renderSshSection）の変更
- バックエンド（Rust）の変更
- Profile データモデルの変更

## 2. ビジネス要件

### 2.1 ビジネス目標
プロファイル設定における「ローカルシェル」と「SSH接続」の選択をUIで直感的に表現する。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| eMtermユーザー | プロファイルを作成・編集するユーザー |

### 2.3 期待される効果
- プロファイルがローカルシェルかSSH接続のどちらかであることが視覚的に明確になる
- SSH接続選択時に不要なシェル設定フィールドが非表示になり混乱を防ぐ

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | ローカルシェルプロファイルの作成/編集 | ユーザー | 高 |
| UC02 | SSHプロファイルの作成/編集 | ユーザー | 高 |
| UC03 | SSH未登録時のSSHタブ表示 | ユーザー | 中 |

### 3.2 ユースケース詳細

#### UC01: ローカルシェルプロファイルの作成/編集

**アクター**: ユーザー

**事前条件**:
- 設定パネルのProfilesカテゴリが表示されている

**基本フロー**:
1. ユーザーが「プロファイル追加」または既存プロファイルの「編集」をクリック
2. プロファイルエディタモーダルが開く
3. SHELLタブがデフォルトで選択されている
4. プロファイル名を入力
5. シェルパス、シェル引数、環境変数、作業ディレクトリを設定
6. 保存をクリック

**事後条件**:
- `ssh_connection_name` が空文字のプロファイルが保存される

#### UC02: SSHプロファイルの作成/編集

**アクター**: ユーザー

**事前条件**:
- SSH接続が1つ以上登録されている

**基本フロー**:
1. ユーザーがプロファイルエディタモーダルを開く
2. SSHタブをクリック
3. ドロップダウンから登録済みSSH接続を選択
4. 保存をクリック

**事後条件**:
- `ssh_connection_name` に選択したSSH接続名が設定され、`shell_path`・`shell_args` が空のプロファイルが保存される

#### UC03: SSH未登録時のSSHタブ表示

**アクター**: ユーザー

**事前条件**:
- SSH接続が1つも登録されていない

**基本フロー**:
1. ユーザーがプロファイルエディタモーダルを開く
2. SSHタブがdisabled状態で表示されている
3. SSHタブをクリックしても反応しない

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | SHELL/SSHタブ表示 | プロファイルエディタモーダル内にタブUIを表示 | 高 |
| F02 | タブ切り替え | SHELLタブとSSHタブの排他的切り替え | 高 |
| F03 | SSHタブdisable | SSH接続未登録時にSSHタブを非活性化 | 高 |
| F04 | 既存プロファイル編集時のタブ初期選択 | ssh_connection_nameの有無でタブを自動選択 | 高 |

### 4.2 機能詳細

#### F01: SHELL/SSHタブ表示

プロファイル名フィールドの下、フォームフィールドの上にタブバーを配置する。

- タブ: SHELL, SSH
- デフォルト選択: SHELL

#### F02: タブ切り替え

- SHELLタブ選択時: シェルパス、シェル引数、環境変数、作業ディレクトリの各フィールドを表示
- SSHタブ選択時: SSH接続ドロップダウンのみ表示
- タブ切り替え時に他方の値をクリアする
  - SHELL → SSH: shell_path, shell_args, env_vars, working_directory をクリア
  - SSH → SHELL: ssh_connection_name をクリア

#### F03: SSHタブdisable

- SSH接続が0件の場合、SSHタブをdisabled状態にする
- disabled状態のタブはクリック不可、視覚的に非活性を示す

#### F04: 既存プロファイル編集時のタブ初期選択

- `ssh_connection_name` が空でない場合: SSHタブを初期選択
- `ssh_connection_name` が空の場合: SHELLタブを初期選択

## 5. 非機能要件

### 5.1 UI/UX要件
- タブスタイルは `doc/UI-DESIGN-GUIDELINES.yaml` に準拠
- 既存のプロファイルエディタモーダルのデザインとの一貫性を保つ

### 5.2 アクセシビリティ要件
- タブにARIAロール（role="tablist", role="tab", role="tabpanel"）を付与
- キーボードナビゲーション対応（左右矢印キーでタブ切り替え）
- disabledタブに aria-disabled="true" を付与

### 5.3 i18n要件
- タブラベル（SHELL, SSH）のi18nキーを追加
- 英語・日本語の両言語ファイルに追加

## 7. 制約条件

### 7.1 技術的制約
- Profileデータモデル（Rust側）は変更しない
- 既存のssh_connection_nameフィールドをそのまま使用する
- プロファイルエディタの既存インターフェース（ProfileEditorOptions）は変更しない
