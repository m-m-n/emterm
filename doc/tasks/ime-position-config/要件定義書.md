# IME表示位置の自動調整 - 要件定義書

## 1. 概要

### 1.1 背景
TUIアプリケーション（Claude Code等）はターミナルの実カーソルを非表示 (`\x1b[?25l`) にし、ANSIスタイルで視覚的カーソルを独自に描画する。この時、実カーソルは入力位置と無関係な場所（最下行左端等）に残される。eMtermのIME入力エリアは実カーソル位置に配置されるため、IME候補ウィンドウがユーザーの入力位置から離れた場所に表示され、変換中テキストの確認が困難になる。

デバッグ調査により、Claude Code実行時のカーソル状態は `cursor=(0,51) visible=false` であることが確認された。カーソルはターミナル最下行左端に配置され、非表示状態である。

### 1.2 目的
カーソルが非表示の時（TUIアプリ使用時を意味する）、IME入力エリアとコンポジションビューをターミナルエリアの左下に自動的に固定配置し、IME候補ウィンドウを画面内の確認しやすい位置に表示する。

### 1.3 スコープ
- IME入力エリアの配置ロジック変更（カーソル可視性に基づく自動切り替え）
- コンポジションビューの配置ロジック変更
- Linux（WebKitGTK）とWindows（WebView2）の両プラットフォーム対応

## 2. ユースケース

### 2.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | TUIアプリでのIME入力 | ユーザー | 高 |
| UC02 | 通常シェルでのIME入力（既存動作維持） | ユーザー | 高 |

### 2.2 ユースケース詳細

#### UC01: TUIアプリでのIME入力

**事前条件**:
- TUIアプリ（Claude Code等）が実行中
- ターミナルカーソルが非表示状態

**基本フロー**:
1. ユーザーがIME入力を開始する
2. eMtermがカーソル非表示を検出する
3. hidden textarea / EditContextをターミナルエリア左下に配置する
4. コンポジションビューもターミナルエリア左下に表示する
5. IME候補ウィンドウがターミナル左下付近に表示される
6. ユーザーが変換候補を確認・選択し、確定する
7. 確定テキストがPTYに送信される

**事後条件**:
- 入力テキストがPTYに正しく送信される

#### UC02: 通常シェルでのIME入力（既存動作維持）

**事前条件**:
- 通常のシェル（bash等）が実行中
- ターミナルカーソルが表示状態

**基本フロー**:
1. ユーザーがIME入力を開始する
2. eMtermがカーソル表示を検出する
3. hidden textarea / EditContextをカーソル位置に配置する（現行動作と同一）

**事後条件**:
- 現行動作と同一

## 3. 機能要件

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | カーソル可視性に基づくIME位置自動切り替え | `cursorVisible=false` 時は左下固定、`true` 時はカーソル追従 | 高 |
| F02 | 左下固定配置ロジック | ターミナルエリアの左下隅にIME入力エリアを配置 | 高 |
| F03 | コンポジションビュー連動 | カーソル可視性に応じてコンポジションビューも配置変更 | 高 |

## 4. 非機能要件

- カーソル追従モード（`visible=true`）は現行動作と完全に同一
- Linux（WebKitGTK）とWindows（WebView2）の両プラットフォームで動作
- 設定項目の追加は不要（自動判定のみ）

## 5. 成功基準

- [ ] カーソル非表示時にIME候補ウィンドウがターミナル左下付近に表示される
- [ ] カーソル非表示時にコンポジションビューがターミナル左下に表示される
- [ ] カーソル表示時は現行動作（カーソル追従）と同一
- [ ] Linux・Windows両環境で動作する

## 6. 確認事項

### 6.1 確認済み事項
- [x] 根本原因: TUIアプリ（Claude Code）がカーソルを非表示にし、実カーソルを入力位置に設定しない
- [x] Claude Code実行時のカーソル状態: `cursor=(0,51) visible=false`
- [x] 判定基準: `terminalState.cursorVisible` を使用
- [x] 固定位置: ターミナルエリアの左下
- [x] 設定追加: 不要（自動判定）
- [x] コンポジションビュー: IME位置と連動して左下に表示
