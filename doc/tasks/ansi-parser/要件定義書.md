# ANSI 制御シーケンス パース・レンダリング機能 要件定義書

## 1. 概要

### 1.1 目的

eMterm に ANSI 制御シーケンスのパース機能とレンダリング機能を実装し、現代的なターミナルエミュレータとして動作可能にする。これにより、カラー表示、カーソル制御、画面操作などの標準的なターミナル機能を提供する。

### 1.2 背景

現在の eMterm は PTY からの出力を単純なテキストとして表示しているのみで、ANSI エスケープシーケンスを解釈していない。本機能の実装により、vim、less、htop などのフルスクリーンアプリケーションが正常に動作するようになる。

### 1.3 スコープ

- **対象**: VT100/VT220 互換の制御シーケンス + xterm 拡張
- **実装方式**: Rust でパース、TypeScript でレンダリング（ハイブリッド方式）
- **対象外**: Kitty Graphics Protocol、SIXEL、独自 OSC 拡張（Markdown 表示）は本スコープ外

## 2. 機能要件

### 2.1 制御シーケンス対応

#### 2.1.1 CSI (Control Sequence Introducer) シーケンス

| カテゴリ | シーケンス | 説明 |
|---------|-----------|------|
| カーソル移動 | CUU, CUD, CUF, CUB | 上下左右移動 |
| カーソル位置 | CUP, HVP | 絶対位置指定 |
| カーソル保存/復元 | DECSC, DECRC | 位置の保存と復元 |
| 消去 | ED, EL | 画面/行の消去 |
| 挿入/削除 | ICH, DCH, IL, DL | 文字/行の挿入・削除 |
| スクロール | SU, SD | 上下スクロール |
| SGR | 0-109 | テキスト装飾（色、太字、下線等） |
| モード設定 | SM, RM | 各種モードの設定/解除 |
| デバイス状態 | DSR | ステータスレポート |

#### 2.1.2 SGR (Select Graphic Rendition) パラメータ

| パラメータ | 説明 |
|-----------|------|
| 0 | リセット |
| 1, 2, 3, 4, 5, 7, 8, 9 | 太字、暗色、斜体、下線、点滅、反転、非表示、取り消し線 |
| 21, 22, 23, 24, 25, 27, 28, 29 | 各属性の解除 |
| 30-37, 90-97 | 前景色（標準8色 + 高輝度8色） |
| 40-47, 100-107 | 背景色（標準8色 + 高輝度8色） |
| 38;5;n, 48;5;n | 256色パレット |
| 38;2;r;g;b, 48;2;r;g;b | 24ビットトゥルーカラー |
| 39, 49 | デフォルト色 |

#### 2.1.3 DEC Private Modes

| モード | 説明 |
|--------|------|
| DECCKM (1) | カーソルキーモード |
| DECCOLM (3) | 132/80 カラムモード |
| DECSCLM (4) | スムーススクロール |
| DECSCNM (5) | 画面反転 |
| DECOM (6) | オリジンモード |
| DECAWM (7) | 自動改行 |
| DECTCEM (25) | カーソル表示/非表示 |
| DECALTSCR (47/1047) | 代替画面バッファ |
| DECPBM (1049) | 代替画面 + カーソル保存 |
| マウストラッキング (1000-1006) | マウスイベント報告 |
| Bracketed Paste (2004) | ペースト検出 |

#### 2.1.4 OSC (Operating System Command)

| OSC 番号 | 説明 |
|----------|------|
| 0, 1, 2 | ウィンドウタイトル/アイコン設定 |
| 4 | カラーパレット設定 |
| 7 | 現在のディレクトリ通知 |
| 8 | ハイパーリンク |
| 10, 11 | 前景/背景色設定 |
| 777 | eMterm 独自拡張（骨格のみ） |

### 2.2 画面バッファ管理

#### 2.2.1 メインバッファ
- スクロールバック履歴: 10,000 行
- グリッドサイズ: 動的（ウィンドウサイズに追従）

#### 2.2.2 代替画面バッファ
- vim, less, htop などのフルスクリーンアプリケーション用
- スクロールバックなし
- 切り替え時にメインバッファの状態を保存

### 2.3 文字処理

#### 2.3.1 エンコーディング
- UTF-8 のみ対応
- 不正な UTF-8 シーケンスは置換文字 (U+FFFD) に変換

#### 2.3.2 文字幅
- East Asian Width に基づく幅計算
- 全角文字（CJK）: 2 セル
- 半角文字: 1 セル
- ゼロ幅文字（結合文字等）: 0 セル

## 3. 非機能要件

### 3.1 性能要件

| 項目 | 目標値 |
|------|--------|
| 入力遅延 | 16ms 以下（60fps 相当） |
| スループット | 10MB/s 以上 |
| メモリ使用量 | スクロールバック 10,000 行で 50MB 以下 |

### 3.2 互換性要件

- 主要シェル (bash, zsh, fish) が正常動作
- フルスクリーンアプリケーション (vim, less, htop, top) が正常動作
- tmux, screen のネスト動作

## 4. アーキテクチャ要件

### 4.1 コンポーネント構成

```
+------------------+     IPC Events     +-------------------+
|   Rust Backend   | -----------------> | TypeScript        |
|                  |                    | Frontend          |
|  +------------+  |                    |  +-------------+  |
|  | PTY Reader |  |                    |  | Event       |  |
|  +-----+------+  |                    |  | Handler     |  |
|        |         |                    |  +------+------+  |
|        v         |                    |         |         |
|  +------------+  |                    |         v         |
|  | ANSI       |  |                    |  +-------------+  |
|  | Parser     |  |                    |  | Terminal    |  |
|  +-----+------+  |                    |  | State       |  |
|        |         |                    |  +------+------+  |
|        v         |                    |         |         |
|  +------------+  |                    |         v         |
|  | Event      |  |                    |  +-------------+  |
|  | Emitter    |  |                    |  | Renderer    |  |
|  +------------+  |                    |  +-------------+  |
+------------------+                    +-------------------+
```

### 4.2 Rust パーサー要件

- ステートマシンベースの実装
- ストリーミング処理（バッファ分断に対応）
- 構造化されたイベントを出力
- ゼロコピー最適化を考慮

### 4.3 TypeScript レンダラー要件

- グリッドベースの画面モデル
- 差分描画による効率化
- requestAnimationFrame によるフレーム同期

### 4.4 IPC 要件

- イベント駆動方式
- JSON 形式でのデータ転送
- バッチ処理によるオーバーヘッド削減

## 5. テスト要件

### 5.1 ユニットテスト

- Rust パーサーの各シーケンス解析
- TypeScript レンダラーの状態管理
- 文字幅計算

### 5.2 統合テスト

- パーサーからレンダラーへのイベント伝播
- 代替画面バッファの切り替え

### 5.3 互換性テスト

- vttest による VT100 互換性検証
- 主要アプリケーション動作確認

### 5.4 性能テスト

- 大量出力時のスループット測定
- 入力レイテンシ測定

## 6. 受け入れ条件

### 6.1 必須条件

1. [ ] SGR による 256 色およびトゥルーカラー表示が動作する
2. [ ] vim でファイル編集が正常に動作する
3. [ ] less でページスクロールが正常に動作する
4. [ ] htop が正常に表示される
5. [ ] 入力遅延が 16ms 以下である
6. [ ] 10MB/s 以上のスループットを達成する

### 6.2 推奨条件

1. [ ] tmux/screen 内での動作が正常
2. [ ] マウストラッキングが動作する
3. [ ] ハイパーリンク (OSC 8) が動作する
4. [ ] Bracketed Paste Mode が動作する
