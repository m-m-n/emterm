# カラースキーム設定機能 - 要件定義書

## 1. 概要

### 1.1 背景
eMtermターミナルエミュレータは現在、ハードコードされた色設定を使用している。ユーザーは自分の好みの色設定（特にWezTermなど他のターミナルエミュレータで使用している設定）をeMtermで再現したいというニーズがある。

### 1.2 目的
- WezTermの色設定をデフォルトとしてeMtermに適用する
- 将来的なカスタマイズ機能追加の基盤を整備する
- 一貫した色テーマをターミナル全体に適用する

### 1.3 スコープ
- ANSI 16色パレットの変更
- フォアグラウンド/バックグラウンド/カーソル色の設定
- ハードコードによる初期実装（設定ファイル対応は将来フェーズ）

## 2. ビジネス要件

### 2.1 ビジネス目標
- ユーザーが慣れ親しんだ色環境でターミナルを使用できるようにする
- WezTermからの移行ユーザーに一貫した体験を提供する

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 開発者 | ターミナルを日常的に使用し、色設定にこだわりを持つユーザー |
| WezTermユーザー | 既存のWezTerm色設定を維持したいユーザー |

### 2.3 期待される効果
- ユーザー満足度の向上（慣れた色環境での作業）
- 視認性の向上（ユーザーに最適化された色設定）
- 将来のカスタマイズ機能への拡張基盤

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |

### 3.2 ユースケース詳細

#### UC01: WezTerm色でターミナル表示

**アクター**: ユーザー

**事前条件**:
- eMtermがインストールされている
- アプリケーションが起動可能な状態

**基本フロー**:
1. ユーザーがeMtermを起動する
2. ターミナルがWezTermの色設定で表示される
3. ANSI色、フォアグラウンド、バックグラウンド、カーソルがすべてWezTerm設定に従う

**代替フロー**:
- なし（設定変更機能は将来フェーズ）

**事後条件**:
- ターミナルがWezTerm色で一貫して表示される

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | ANSI 16色パレット更新 | colors.tsのPALETTE_16をWezTerm色に変更 | 高 |
| F02 | デフォルト色更新 | フォアグラウンド/バックグラウンド色を更新 | 高 |
| F03 | CSS色更新 | styles.cssのハードコード色を更新 | 高 |
| F04 | カーソル色更新 | カーソル色をWezTerm設定に合わせる | 高 |

### 4.2 機能詳細

#### F01: ANSI 16色パレット更新

**説明**: src/terminal/colors.tsのPALETTE_16定数をWezTermの色設定に更新する

**入力**:
- なし（ハードコード値）

**出力**:
- 更新されたPALETTE_16定数

**変更対象**:
```typescript
// 変更前（現在の値）
{ r: 0, g: 0, b: 0 },       // 0: Black
{ r: 205, g: 49, b: 49 },   // 1: Red
...

// 変更後（WezTerm色）
{ r: 0x00, g: 0x00, b: 0x00 },   // 0: #000000
{ r: 0xff, g: 0x00, b: 0x00 },   // 1: #ff0000
{ r: 0x00, g: 0xdd, b: 0x00 },   // 2: #00dd00
{ r: 0xee, g: 0xee, b: 0x00 },   // 3: #eeee00
{ r: 0x40, g: 0x40, b: 0xff },   // 4: #4040ff
{ r: 0xff, g: 0x00, b: 0xff },   // 5: #ff00ff
{ r: 0x00, g: 0xdd, b: 0xdd },   // 6: #00dddd
{ r: 0xde, g: 0xda, b: 0xcf },   // 7: #dedacf
{ r: 0x55, g: 0x55, b: 0x55 },   // 8: #555555
{ r: 0xff, g: 0x60, b: 0x60 },   // 9: #ff6060
{ r: 0x60, g: 0xff, b: 0x60 },   // 10: #60ff60
{ r: 0xff, g: 0xff, b: 0x60 },   // 11: #ffff60
{ r: 0x60, g: 0x60, b: 0xff },   // 12: #6060ff
{ r: 0xff, g: 0x60, b: 0xff },   // 13: #ff60ff
{ r: 0x60, g: 0xff, b: 0xff },   // 14: #60ffff
{ r: 0xff, g: 0xff, b: 0xff },   // 15: #ffffff
```

**ビジネスルール**:
- 256色パレットのインデックス0-15は自動的にPALETTE_16を参照するため、PALETTE_16の更新で両方が更新される

#### F02: デフォルト色更新

**説明**: DEFAULT_FOREGROUNDとDEFAULT_BACKGROUNDをWezTerm設定に更新

**変更対象**:
```typescript
// 変更前
export const DEFAULT_FOREGROUND: Rgb = { r: 229, g: 229, b: 229 };
export const DEFAULT_BACKGROUND: Rgb = { r: 0, g: 0, b: 0 };

// 変更後（WezTerm色）
export const DEFAULT_FOREGROUND: Rgb = { r: 0x40, g: 0xff, b: 0x40 }; // #40ff40
export const DEFAULT_BACKGROUND: Rgb = { r: 0x00, g: 0x00, b: 0x00 }; // #000000
```

#### F03: CSS色更新

**説明**: styles.cssのハードコードされた色をWezTerm設定またはCSS変数に更新

**変更対象ファイル**: src/styles.css

**更新が必要な箇所**:
- `body { background-color: #1e1e1e; }` → `#000000`
- `body { color: #d4d4d4; }` → `#40ff40`
- `#terminal { background-color: #1e1e1e; }` → `#000000`
- IME関連の背景色

#### F04: カーソル色更新

**説明**: カーソル色をWezTerm設定（#008000、暗い緑）に更新

**変更対象ファイル**: src/terminal/renderer.ts

**変更内容**:
```css
/* 変更前 */
.terminal-cursor.block { background-color: #c0c0c0; }
.terminal-cursor.underline { border-bottom: 2px solid #c0c0c0; }
.terminal-cursor.bar { border-left: 2px solid #c0c0c0; }

/* 変更後 */
.terminal-cursor.block { background-color: #008000; }
.terminal-cursor.underline { border-bottom: 2px solid #008000; }
.terminal-cursor.bar { border-left: 2px solid #008000; }
```

## 5. 非機能要件

### 5.1 パフォーマンス要件
- 色の変更は起動時に一度だけ適用される（ランタイムオーバーヘッドなし）
- レンダリングパフォーマンスに影響なし

### 5.2 セキュリティ要件
- 該当なし（ハードコード値のみ、外部入力なし）

### 5.3 可用性要件
- 該当なし

### 5.4 保守性要件
- 色定数は一箇所（colors.ts）に集約
- 将来のカスタマイズ機能追加を考慮した構造

### 5.5 互換性要件
- 既存のANSI色指定（SGR シーケンス）との互換性維持
- 256色、True Colorの既存動作維持

## 6. UI/UX要件

### 6.1 画面設計要件
- ターミナル全体がWezTermの色設定で表示される
- 緑系のフォアグラウンド（#40ff40）に黒背景（#000000）

### 6.2 視覚的一貫性
- ANSI色、デフォルト色、カーソル色が調和したカラースキーム
- コントラスト比の確保（緑文字と黒背景）
