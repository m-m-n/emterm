## 機能検証

### 1. キーボードショートカットの簡素化

- [ ] `f` キーで Pixel/Fit モードがトグルされる
- [ ] `Escape` キーでビューアーが閉じる
- [ ] `0` キーを押してもモードが変わらない
- [ ] `1` キーを押してもモードが変わらない
- [ ] その他のキー（`a`, `z`, スペース等）がターミナルに伝播しない
- [ ] ヘルプテキストに `1:100%` / `0:fit` が表示されない

### 2. ホイールスクロール

#### 2.1 縦スクロール

- [ ] Pixelモードでビューポートより大きい画像を表示
- [ ] ホイールダウンで画像が上にスクロール（コンテンツが下に進む）
- [ ] ホイールアップで画像が下にスクロール（コンテンツが上に戻る）
- [ ] 画像の端でスクロールが止まる（バウンド制限）

#### 2.2 横スクロール

- [ ] Shift+ホイールで画像が横にスクロール
- [ ] 画像の端でスクロールが止まる（バウンド制限）

#### 2.3 エッジケース

- [ ] Fitモード時にホイールスクロールが無視される
- [ ] ビューポートより小さい画像でホイールスクロールが無視される
- [ ] Ctrl+ホイールでブラウザズームが発生しない
- [ ] ドラッグパンとホイールスクロールが同じオフセットを共有する（ホイールで移動後、ドラッグでさらに移動可能）
