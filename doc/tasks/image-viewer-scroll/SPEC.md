# SPEC: 画像ビューアー キーボードショートカット簡素化 & ホイールスクロール

## 概要

画像ビューアーのキーボードショートカットを簡素化し、マウスホイールによるスクロール操作を追加する。

## 変更点

### 1. キーボードショートカットの簡素化

#### 廃止するキー

| キー | 現在の動作 | 変更後 |
|------|-----------|--------|
| `0` | Fitモードに切り替え | **廃止** (他のキーと同様ブロック) |
| `1` | Pixelモード(100%)に切り替え | **廃止** (他のキーと同様ブロック) |

#### 残すキー

| キー | 動作 |
|------|------|
| `f` | Pixel/Fitモードをトグル |
| `Escape` | ビューアーを閉じる |

- `0`, `1` のケースを `handleKeydown()` から削除する
- `default` ブロックの `preventDefault()`/`stopPropagation()` により、他のキー同様にターミナルへの伝播はブロックされる

### 2. マウスホイールスクロール

Pixelモードで画像がビューポートより大きい場合に、ホイールスクロールで画像をパンする。

#### 操作マッピング

| 操作 | 動作 |
|------|------|
| ホイールスクロール | 縦スクロール（パン） |
| Shift + ホイールスクロール | 横スクロール（パン） |

#### 動作仕様

- スクロール方向は自然スクロール（スクロールダウンでコンテンツが下に進む）。オフセットから `deltaY` を減算する
- Shift+スクロール時は横方向パンオフセットから delta を減算する（OSのShift+ホイール変換による `deltaX` にも対応する）
- パン範囲は既存の PanController のバウンド計算に従い、画像がビューポートをはみ出す範囲に制限する
- Fitモード時（画像がビューポート内に収まっている場合）はスクロール操作を無視する
- `Ctrl+ホイール` はズーム操作として予約し、今回は実装しない（`preventDefault()` でブラウザのズームをブロックする）

### 3. ドラッグパン（既存）

PanController によるマウスドラッグパンは引き続き使用可能とする。ホイールスクロールとドラッグパンは同じパンオフセットを共有する。

## 対象ファイル

| ファイル | 変更内容 |
|---------|---------|
| `src/image-viewer/display-mode.ts` | `handleKeydown()` から `0`, `1` のケースを削除 |
| `src/image-viewer/index.ts` | ホイールイベントリスナーを追加、パンオフセット更新ロジック |
| `src/i18n/locales/en.json` | `helpText` から `1:100% 0:fit` を削除 |
| `src/i18n/locales/ja.json` | `helpText` から `1:100% 0:フィット` を削除 |

## テスト方針

- DisplayModeController: `0`, `1` キーでモード変更されないことを検証
- ホイールスクロール: 縦・横パンが正しく動作することを検証
- バウンド制限: パンがはみ出し範囲を超えないことを検証
- Fitモード時にスクロールが無視されることを検証
