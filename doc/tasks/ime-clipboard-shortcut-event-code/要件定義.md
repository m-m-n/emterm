# IME ON状態でのクリップボードショートカット修正 - 要件定義書

## 1. 背景・課題

### 1.1 現状の問題

eMtermにおいて、日本語入力（IME）がONの状態でCtrl+Shift+C（コピー）およびCtrl+Shift+V（ペースト）のキーボードショートカットが動作しない。

### 1.2 原因

JavaScriptのKeyboardEventにおいて、IME ON時に`event.key`プロパティが実際のキー名（"c", "v"）ではなく`"Process"`という値を返すため、現在の実装では正しくキーを検出できない。

**現在の問題コード:**
```typescript
private handleClipboardShortcut(event: KeyboardEvent): void {
  if (!event.ctrlKey || !event.shiftKey) {
    return;
  }

  const key = event.key.toLowerCase();  // IME ON時: "process"

  if (key === "c") {  // マッチしない
    // ...
  }

  if (key === "v") {  // マッチしない
    // ...
  }
}
```

### 1.3 影響

- 日本語入力中にテキストのコピー・ペーストができない
- 日本語環境のユーザーの作業効率が低下する
- ターミナルエミュレータとしての基本的なUXが損なわれる

## 2. 要件

### 2.1 機能要件

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-01 | IME ON状態でCtrl+Shift+Cによるコピーが動作すること | 必須 |
| FR-02 | IME ON状態でCtrl+Shift+Vによるペーストが動作すること | 必須 |
| FR-03 | IME OFF状態での既存動作が維持されること | 必須 |

### 2.2 非機能要件

| ID | 要件 | 優先度 |
|----|------|--------|
| NFR-01 | 修正による他のキーボード機能への影響がないこと | 必須 |
| NFR-02 | キャプチャフェーズでのイベント処理を維持すること | 必須 |

## 3. 解決策

### 3.1 アプローチ

`event.code`プロパティを使用して物理キーを検出する。`event.code`はIMEの状態に関係なく、物理的に押されたキーを表す。

### 3.2 技術的詳細

| プロパティ | IME OFF時 | IME ON時 | 用途 |
|-----------|-----------|----------|------|
| `event.key` | "c", "v" | "Process" | 論理キー（IME影響を受ける） |
| `event.code` | "KeyC", "KeyV" | "KeyC", "KeyV" | 物理キー（IME影響を受けない） |

### 3.3 実装方針

1. `event.code`を優先的にチェック（IME ON対応）
2. `event.key`へのフォールバックを残す（互換性確保）
3. 既存のキャプチャフェーズ処理は維持

## 4. 対象ファイル

| ファイルパス | 変更内容 |

| `src/terminal-app/handlers/keyboard.ts` | `handleClipboardShortcut`メソッドの修正 |
