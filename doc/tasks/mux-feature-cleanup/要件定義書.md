# mux 機能クリーンアップ - 要件定義書

## 1. 概要

### 1.1 背景
`doc/tasks/terminal-multiplexer/` で定義された mux 機能のうち、以下が現状正しく動作していない、または不要である。

- 垂直分割・水平分割
- 次のペイン / 前のペインへの移動
- ペインを閉じる操作
- ズームトグル
- コピーモード (ターミナルのスクロールバック機能で代替可能)

### 1.2 目的
動作していない / 不要な mux 機能を削除し、残す機能だけからなる構成へ整理する。

### 1.3 スコープ
- TypeScript フロントエンド (ペイン管理・レイアウト・コピーモード・ドラッグリサイズ) の削除
- Rust バックエンド (mux IPC の SplitPane ハンドラ) の削除
- 設定 (`mux.keybinds.*`) の不要キー削除
- i18n (`settings.mux.keybind.*`) の不要キー削除
- `doc/tasks/terminal-multiplexer/SPEC.md` の現状反映
- 関連する E2E スペックの削除方針の記載

スコープ外:
- `Pane` 構造体そのものの撤廃 (1 ウィンドウ = 1 ペイン固定として残す)
- `settings.json` に過去書かれた不要キーの移行コード (Serde デフォルトで未知フィールドを無視する挙動に任せる)
- 残存機能の動作変更・機能追加

## 2. 前提

### 2.1 残す mux 機能
| カテゴリ | 機能 | prefix key |
|---|---|---|
| セッション | デタッチ | `prefix + d` |
| ウィンドウ | 新規ウィンドウ | `prefix + c` |
| ウィンドウ | 次のウィンドウ | `prefix + n` |
| ウィンドウ | 前のウィンドウ | `prefix + p` |
| ウィンドウ | ウィンドウ名変更 | `prefix + ,` |
| クリップボード | 貼り付け | `prefix + ]` |
| 特殊 | prefix そのものを PTY へ送る (passthrough) | `prefix + prefix` |

Prefix キーの既定は `Ctrl+B`。

### 2.2 残す mux General 設定
`mux-section.ts` の "General" サブセクションの以下はすべて残す。ペイン概念に依存しない。

- prefix (prefix キー)
- base_index
- mouse
- status_position

## 3. 削除対象

### 3.1 削除するアクション
prefix-key.ts の `MuxAction` 型および `DEFAULT_ACTION_BINDINGS` から以下を除去する。

- `split-vertical`
- `split-horizontal`
- `next-pane`
- `prev-pane`
- `close-pane`
- `zoom-toggle`
- `copy-mode`

### 3.2 削除するファイル (全削除)

TypeScript 側:

- `src/terminal-app/mux/mux-multi-pane.ts`
- `src/terminal-app/mux/mux-drag-resize.ts`
- `src/terminal-app/mux/mux-copy-mode.ts`
- `src/terminal/mux/layout.ts`
- `src/terminal/mux/layout.test.ts`
- `src/terminal/mux/pane-manager.ts`
- `src/terminal/mux/pane-border.ts`
- `src/terminal/mux-copy-mode/index.ts`
- `src/terminal/mux-copy-mode/index.test.ts`
- `src/terminal/mux-copy-mode/emacs-keybinds.ts`
- `src/terminal/mux-copy-mode/vi-keybinds.ts`

### 3.3 縮小対象ファイル

TypeScript 側:

- `src/terminal-app/mux/mux-action-handler.ts` — 削除アクションに対応する case 節を除去 (`split-vertical`, `split-horizontal`, `next-pane`, `prev-pane`, `close-pane`, `zoom-toggle`, `copy-mode`)。`MuxActionContext` からも対応する関数参照 (`getMuxLayoutRoot`, `setActiveMuxPane`, `toggleMuxZoom`, `enterCopyMode`, `setMuxPendingSplitCount`, `setMuxPendingSplitDirection` 等) を除去。
- `src/terminal-app/mux/mux-session.ts`, `src/terminal-app/mux/mux-window-manager.ts` — ペイン関連参照の除去。
- `src/terminal/mux/mux-client.ts` — `MuxMessageType.SplitPane` を削除。関連 IPC 呼び出しを除去。
- `src/terminal/mux/prefix-key.ts` — `MuxAction` 型および `DEFAULT_ACTION_BINDINGS` から削除アクションを除去。
- `src/terminal/mux/mux-client.test.ts`, `src/terminal/mux/prefix-key.test.ts` — 残すアクションのみ検証に縮小。
- `src/settings/sections/mux-section.ts` — `ACTION_I18N_KEYS` から削除アクションのキーを除去。
- `src/i18n/locales/en.json`, `src/i18n/locales/ja.json` — `settings.mux.keybind.splitVertical` / `splitHorizontal` / `nextPane` / `prevPane` / `closePane` / `zoomToggle` / `copyMode` を削除。

Rust 側 (`src-tauri/`):

- `src-tauri/src/mux/ipc/protocol.rs` — `MessageType::SplitPane = 0x11` と `SplitPaneMsg` 構造体を削除。`from_u8` の `0x11` 分岐を削除。関連テスト (`test_apc_round_trip_all_message_types` のレンジ等) を調整。
- `src-tauri/src/mux/ipc/handlers.rs` — `handle_split_pane` 関数を削除。呼び出し元 (`connection.rs` 等) の SplitPane 分岐を削除。
- `src-tauri/src/mux/session/pane.rs` — `Pane` 構造体は残す。1 ウィンドウ = 1 ペイン固定となる前提を前段 (handler/manager) が保証する。大規模リファクタは行わない。

### 3.4 E2E テスト方針
実装時に個別判断対象の spec:

- `e2e-tests/specs/mux.e2e.js`
- `e2e-tests/specs/mux-multi-session.e2e.js`
- `e2e-tests/specs/mux-reattach.e2e.js`
- `e2e-tests/specs/viewer-tab-switch-keyboard.e2e.js`

削除方針:

- ペイン分割 / ズーム / コピーモードを検証しているテストケース → 削除
- ウィンドウ (タブ) 操作 / デタッチ / 再アタッチを検証しているテストケース → 維持

- US3 (Split Panes) を削除

## 5. 設定マイグレーション方針

Serde のデフォルト挙動で未知フィールドを無視することに任せる。ユーザーの既存 `settings.json` に残っている `mux.keybinds.split-vertical` 等のキーは、次回ロード時に未知フィールドとして黙って捨てられる。

明示的な移行コードは書かない。

## 6. 想定される課題

| 課題 | 対応 |
|---|---|
| Rust 側 `Pane` 構造体が複数ペイン前提のデータ (`panes: HashMap<PaneId, Pane>`) を保持している | 構造体自体は残す。ペインを作成するコードパスがウィンドウあたり 1 個に限定されることで実質的に単一ペインとして運用する。|
| `MessageType::SplitPane = 0x11` の削除により `from_u8` のテスト `test_message_type_round_trip` が `0x01..=0x19` を回していて 0x11 で失敗する | テスト側も 0x11 を除外するよう修正する (具体対応は実装計画で確定)。|
| 既存ユーザーの `~/.tmux.conf` インポート結果に split キーが含まれる | 削除したアクションは `DEFAULT_ACTION_BINDINGS` に存在しないため、インポート時点で無視される。追加対応不要。|
| E2E spec を削除した結果、`./scripts/run-e2e-docker.sh` のテスト総数が減る | 削除後のテスト総数で pass することを以て合格とする。数値は固定しない。|
