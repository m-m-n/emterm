# 設定項目の説明テキスト追加 - 要件定義書

## 1. 概要

### 1.1 背景
設定画面の各項目にはラベルとヒント（範囲やフォーマット情報）が表示されているが、その設定を変更すると何が起こるかを説明するテキストがない。

### 1.2 目的
各設定項目に説明テキスト（description）を追加し、ユーザーが設定変更の効果を理解できるようにする。

### 1.3 スコープ
- Appearance カテゴリの全設定項目に説明テキストを追加
- Terminal カテゴリの全設定項目に説明テキストを追加
- Keybinds カテゴリは対象外（自明なため）
- 英語・日本語の両方の説明テキストを用意（i18n対応）
- Material Design 3 に準拠した表示

## 2. ビジネス要件

### 2.1 ビジネス目標
ユーザーが設定画面を直感的に理解し、迷わず設定を変更できるようにする。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 一般ユーザー | ターミナルの設定を初めて変更する |
| 経験者 | 各設定の正確な効果を確認したい |

### 2.3 期待される効果
- 設定変更時の不安の軽減
- サポート問い合わせの削減
- 設定画面の使いやすさ向上

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | 設定項目の説明を読む | ユーザー | 高 |

### 3.2 ユースケース詳細

#### UC01: 設定項目の説明を読む

**アクター**: ユーザー

**事前条件**:
- 設定画面が開いている

**基本フロー**:
1. ユーザーが設定項目を見る
2. ラベルの下に説明テキストが表示されている
3. ユーザーが設定変更の効果を理解する
4. ユーザーが設定を変更する

**事後条件**:
- ユーザーが設定の効果を理解した上で変更できる

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 説明テキスト表示 | 各設定項目のラベル下に説明テキストを表示 | 高 |
| F02 | i18n対応 | 英語・日本語の説明テキスト | 高 |

### 4.2 機能詳細

#### F01: 説明テキスト表示

**説明**: 各設定項目のラベルと入力コントロールの間に、設定変更の効果を説明するテキストを表示する。

**表示位置**: ラベルの直下、入力コントロールの上

**表示スタイル**: MD3 Body Small（12px）、on-surface-variant カラー

**対象項目**:

Appearance カテゴリ:
- Language
- Font Size
- Font Family
- Line Height
- UI Theme
- Terminal Color Scheme
- Opacity
- Padding
- Scrollback Lines
- Show Scrollbar
- Inline Images
- Markdown Rendering

Terminal カテゴリ:
- Cursor Style
- Cursor Blink
- Shell Path
- Shell Arguments
- Scroll Speed
- Bell Action
- URL Detection
- Copy on Select

#### F02: i18n対応

**説明**: 説明テキストは既存のi18nシステムを使用し、英語と日本語の両方を提供する。

**i18nキーパターン**: `settings.{category}.{settingKey}Desc`

## 5. 非機能要件

### 5.1 デザイン要件
- Material Design 3 の supporting text パターンに準拠
- 既存の hint テキストとは視覚的に区別可能

### 5.2 アクセシビリティ要件
- 説明テキストは `aria-describedby` で入力コントロールに関連付ける

### 5.3 パフォーマンス要件
- 設定画面の描画速度に影響を与えない

## 6. UI/UX要件

### 6.1 レイアウト構造

変更前:
```
[ラベル]
[入力コントロール]
[ヒント（範囲情報）]
```

変更後:
```
[ラベル]
[説明テキスト]      ← 新規追加
[入力コントロール]
[ヒント（範囲情報）]
```

### 6.2 説明テキストのスタイル
- フォントサイズ: 12px（MD3 Body Small）
- 行の高さ: 16px
- 色: on-surface-variant
- 字間: 0.4px

### 6.3 トグル・キーバインド行のレイアウト

トグル行は横並びレイアウト（ラベル + スイッチ）のため、説明テキストはラベルの直下に配置し、スイッチは行の右端に維持する。

## 7. 制約条件

### 7.1 技術的制約
- 既存のレンダリングメソッド（renderNumberInput, renderTextInput, renderSelect, renderToggle, renderSlider）を拡張する
- 既存の hint システムとは別の CSS クラスを使用する
- 説明テキストはオプショナルパラメータとして追加する

### 7.2 デザイン制約
- Material Design 3 のガイドラインに準拠
- 既存のレイアウトを大きく変更しない
