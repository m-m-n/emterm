# 要件定義書: 基本PTY接続機能

## 1. 概要

### 1.1 目的
eMtermターミナルエミュレータの核心機能として、PTY（擬似端末）を介したシェルプロセスとの双方向通信を実現する。この機能は全てのターミナル操作の基盤となる。

### 1.2 スコープ
- PTYプロセスの生成・管理（Rust/Tauri側）
- デフォルトシェルの検出と起動
- stdin/stdout/stderrの処理
- フロントエンド・バックエンド間のIPC通信
- ウィンドウリサイズ時のPTYサイズ同期
- プロセス終了検出とリソースクリーンアップ

### 1.3 対象プラットフォーム
- Linux
- macOS
- Windows

---

## 2. 機能要件

### 2.1 PTYプロセス管理

#### 2.1.1 PTY生成
- **FR-PTY-001**: アプリケーション起動時にPTYスレーブ/マスターペアを作成できること
- **FR-PTY-002**: PTYに対してシェルプロセスを子プロセスとして起動できること
- **FR-PTY-003**: 複数のPTYセッションを同時に管理できる設計とすること（将来のタブ機能対応）

#### 2.1.2 デフォルトシェル検出
- **FR-SHELL-001**: Linux/macOSでは`SHELL`環境変数を優先的に参照すること
- **FR-SHELL-002**: Windowsでは PowerShell を使用すること
- **FR-SHELL-003**: 環境変数が未設定の場合、OS固有のフォールバックを提供すること
  - Linux: `/bin/sh`
  - macOS: `/bin/zsh`
  - Windows: `powershell.exe`

#### 2.1.3 プロセスライフサイクル
- **FR-LIFE-001**: シェルプロセスの正常終了を検出できること
- **FR-LIFE-002**: シェルプロセスの異常終了（シグナル受信等）を検出できること
- **FR-LIFE-003**: プロセス終了時に関連リソース（ファイルディスクリプタ等）を解放すること
- **FR-LIFE-004**: アプリケーション終了時に全PTYセッションを適切にクリーンアップすること

### 2.2 入出力処理

#### 2.2.1 入力処理（Frontend -> PTY）
- **FR-IN-001**: フロントエンドからのキー入力をPTYに送信できること
- **FR-IN-002**: 特殊キー（Ctrl+C, Ctrl+D, 矢印キー等）を正しいエスケープシーケンスに変換すること
- **FR-IN-003**: 入力はバッファリングせず、低遅延で送信すること

#### 2.2.2 出力処理（PTY -> Frontend）
- **FR-OUT-001**: PTYからの出力データをフロントエンドに配信できること
- **FR-OUT-002**: バイナリデータ（制御シーケンス含む）を正確に転送できること
- **FR-OUT-003**: 大量出力時もUIをブロックしない非同期処理とすること

### 2.3 IPC通信

#### 2.3.1 通信チャネル
- **FR-IPC-001**: Tauri 2.x のイベントシステムを使用してバックエンド・フロントエンド間を接続すること
- **FR-IPC-002**: 入力用コマンド（invoke）を定義すること
- **FR-IPC-003**: 出力用イベント（emit）を定義すること

#### 2.3.2 データフォーマット
- **FR-IPC-004**: PTY出力はバイナリ対応のため、Base64エンコードまたはバイト配列として転送すること
- **FR-IPC-005**: セッションIDによる複数PTYの識別に対応すること

### 2.4 ウィンドウリサイズ

- **FR-RESIZE-001**: ウィンドウサイズ変更時にPTYのウィンドウサイズ（行数・列数）を更新できること
- **FR-RESIZE-002**: フロントエンドから行数・列数を計算してバックエンドに通知すること
- **FR-RESIZE-003**: PTYへのSIGWINCH相当の処理を実行すること

## 3. 非機能要件

### 3.1 パフォーマンス

- **NFR-PERF-001**: キー入力から画面反映までの遅延は50ms以下を目標とすること
- **NFR-PERF-002**: 大量データ出力（例: `cat` 大容量ファイル）時もUIがフリーズしないこと
- **NFR-PERF-003**: メモリ使用量は1セッションあたり50MB以下を目標とすること

### 3.2 セキュリティ

- **NFR-SEC-001**: PTYプロセスはユーザー権限で実行すること（root権限不要）
- **NFR-SEC-002**: Tauriのcapabilities設定で必要最小限の権限のみ付与すること
- **NFR-SEC-003**: シェルコマンドのサニタイズは不要（ターミナルの本質的機能）だが、IPC経路での不正データ注入は防止すること

### 3.3 信頼性

- **NFR-REL-001**: シェルプロセスのクラッシュがアプリケーション全体をクラッシュさせないこと
- **NFR-REL-002**: PTY接続エラー時に適切なエラーメッセージを表示すること
- **NFR-REL-003**: 予期しない切断時に再接続または新規セッション開始の選択肢を提示すること

### 3.4 互換性

- **NFR-COMPAT-001**: 各プラットフォームのネイティブPTY実装を使用すること
  - Linux/macOS: POSIX PTY (`openpty`, `forkpty`)
  - Windows: ConPTY API
- **NFR-COMPAT-002**: UTF-8エンコーディングをデフォルトとすること

## 4. インターフェース定義

### 4.1 Tauri Commands（Rust -> Frontend呼び出し可能）

| コマンド名 | 引数 | 戻り値 | 説明 |
|-----------|------|--------|------|
| `pty_spawn` | `shell?: string, cols?: number, rows?: number` | `{ session_id: string }` | PTYセッション開始 |
| `pty_write` | `session_id: string, data: number[]` | `void` | PTYへデータ送信 |
| `pty_resize` | `session_id: string, cols: number, rows: number` | `void` | PTYサイズ変更 |
| `pty_kill` | `session_id: string` | `void` | PTYセッション終了 |

### 4.2 Tauri Events（Rust -> Frontend通知）

| イベント名 | ペイロード | 説明 |
|-----------|-----------|------|
| `pty_output` | `{ session_id: string, data: number[] }` | PTY出力データ |
| `pty_exit` | `{ session_id: string, code: number }` | プロセス終了通知 |
| `pty_error` | `{ session_id: string, message: string }` | エラー通知 |

## 5. 制約事項

### 5.1 技術的制約
- Tauri 2.x APIのみ使用（1.x APIは使用不可）
- Rust edition 2024、rust-version 1.85以上
- フロントエンドはVanilla TypeScript（フレームワーク不使用）

### 5.2 設計制約
- 将来のタブ・分割機能を見据えた複数セッション対応設計
- ANSI制御シーケンスのパースは本機能のスコープ外（後続タスク）
- 画像・Markdown表示は本機能のスコープ外（後続タスク）
- 切断時の再接続/新規セッション選択UIは本機能のスコープ外（後続タスク、NFR-REL-003）

### 5.3 プラットフォーム固有制約
- WindowsではPowerShellのみサポート（cmd.exeはサポート対象外）

## 7. 受け入れ基準

### 7.1 基本動作
- [ ] Linux, macOS, Windowsでシェルが起動すること
- [ ] キーボード入力がシェルに送信されること
- [ ] シェルの出力が画面に表示されること
- [ ] `exit`コマンドでセッションが正常終了すること

### 7.2 リサイズ
- [ ] ウィンドウリサイズ時に`stty size`の出力が更新されること（Linux/macOS）
- [ ] ウィンドウリサイズ時に`$Host.UI.RawUI.WindowSize`の出力が更新されること（Windows/PowerShell）

### 7.3 エラーハンドリング
- [ ] 存在しないシェルパス指定時にエラーが表示されること
- [ ] Ctrl+Cでプロセス中断できること

## 8. 用語集

| 用語 | 説明 |
|-----|------|
| PTY | Pseudo Terminal (擬似端末)。ターミナルエミュレータとシェル間の通信を仲介する仮想デバイス |
| Master/Slave | PTYの2つの端点。Masterはターミナルエミュレータ側、Slaveはシェル側 |
| ConPTY | Windows 10以降で導入されたPseudo Console API |
| SIGWINCH | ウィンドウサイズ変更を通知するUnixシグナル |
| IPC | Inter-Process Communication（プロセス間通信） |
