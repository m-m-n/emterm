# JSON/YAMLビューアー - 要件定義書

## 1. 概要

### 1.1 背景
eMtermはMarkdownビューアーによるリッチコンテンツ表示を既にサポートしている。構造化データ（JSON/YAML）もターミナル上でインタラクティブに閲覧できる機能を追加し、AI時代のターミナルとしての利便性を高める。

### 1.2 目的
- JSON/YAMLファイルをターミナル上でアウトライン付きで構造的に閲覧可能にする
- RAW表示とアウトライン表示の切り替えにより、全体像と詳細の両方を効率的に確認できるようにする

### 1.3 スコープ
- `emterm json` / `emterm yaml` CLIコマンドの追加
- OSC 777シーケンスによるデータ伝送（Markdownビューアーと同じパターン）
- フルスクリーンオーバーレイでのビューアーUI
- アウトライン（ツリー）表示とRAW表示の切り替え

## 2. ビジネス要件

### 2.1 ビジネス目標
構造化データのインタラクティブな閲覧機能により、AI出力やAPI応答、設定ファイルの確認を効率化する。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 開発者 | JSON/YAML設定ファイルや API レスポンスを確認する |
| AIツールユーザー | AI出力の構造化データを閲覧する |

### 2.3 期待される効果
- 構造化データの視認性向上
- キー構造のアウトライン把握による迅速なナビゲーション
- RAW/整形表示の切り替えによる柔軟な確認

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | JSONファイルをアウトライン表示で閲覧 | 開発者 | 高 |
| UC02 | YAMLファイルをアウトライン表示で閲覧 | 開発者 | 高 |
| UC03 | RAW表示に切り替えて全体を確認 | 開発者 | 高 |
| UC04 | JSON RAW表示を整形表示に切り替え | 開発者 | 中 |
| UC05 | 不正なJSON/YAMLを開く | 開発者 | 中 |

### 3.2 ユースケース詳細

#### UC01: JSONファイルをアウトライン表示で閲覧

**アクター**: 開発者

**事前条件**:
- 有効なJSONファイルが存在する

**基本フロー**:
1. `emterm json <file>` を実行
2. ビューアーがアウトライン表示で開く
3. 左ペインにキーのツリーが全階層展開で表示される
4. ルートレベルが初期選択される
5. ツリーのキーを選択すると右ペインにその項目の内容がJSON形式で表示される

**事後条件**:
- Escapeキーでビューアーを閉じ、ターミナルに戻る

#### UC03: RAW表示に切り替えて全体を確認

**アクター**: 開発者

**事前条件**:
- ビューアーがアウトライン表示で開いている

**基本フロー**:
1. `r` キーを押す
2. アウトライン表示からRAW表示に切り替わる
3. ファイル全体がシンタックスハイライト付きで表示される
4. 再度 `r` キーを押すとアウトライン表示に戻る

#### UC04: JSON RAW表示を整形表示に切り替え

**アクター**: 開発者

**事前条件**:
- JSON ビューアーがRAW表示になっている

**基本フロー**:
1. RAW表示中に `p` キーを押す
2. JSONが整形（pretty-print）された形で表示される
3. 再度 `p` キーを押すと元の形式に戻る

**注意**: `p` キーはJSONのRAW表示時のみ有効。YAMLには適用されない。

#### UC05: 不正なJSON/YAMLを開く

**アクター**: 開発者

**事前条件**:
- パースできないJSON/YAMLファイルが存在する

**基本フロー**:
1. `emterm json <file>` を実行
2. ビューアーが開き、上部にエラーメッセージが表示される
3. ファイル内容はRAWテキストとして確認可能
4. アウトライン表示は利用不可（ツリーを構築できないため）

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | CLIコマンド | `emterm json` / `emterm yaml` コマンド | 高 |
| F02 | OSCシーケンス伝送 | OSC 777によるチャンク伝送 | 高 |
| F03 | アウトライン表示 | 左ペインにツリー、右ペインに選択項目の内容 | 高 |
| F04 | RAW表示 | ファイル全体をシンタックスハイライト付きで表示 | 高 |
| F05 | 表示切り替え | `r` キーでアウトライン/RAW切り替え | 高 |
| F06 | JSON整形表示 | `p` キーでJSONのpretty-print切り替え（RAW表示時のみ） | 中 |
| F07 | シンタックスハイライト | キー・文字列・数値・真偽値・nullの色分け | 高 |
| F08 | エラー表示 | パース失敗時のエラーメッセージ + RAWテキスト表示 | 中 |
| F09 | コピー機能 | RAW表示内容のクリップボードコピー | 中 |

### 4.2 機能詳細

#### F01: CLIコマンド

**説明**: Markdownコマンドと同じパターンで、ファイルを読み込みOSCシーケンスとして出力

**入力**:
- file: ファイルパス（必須）

**処理フロー**:
1. ファイルの存在・読み取り可能を検証
2. ファイル内容を読み込む
3. Base64エンコード → 128KBチャンク分割
4. OSC 777シーケンスを生成・出力
5. tmux内の場合はDCSパススルーでラップ

**エラーケース**:
| エラー | 条件 | 対応 |
|--------|------|------|
| FileNotFound | ファイルが存在しない | エラーメッセージを表示して終了 |
| NotAFile | パスがディレクトリ | エラーメッセージを表示して終了 |
| FileReadError | 読み取り不可 | エラーメッセージを表示して終了 |

#### F03: アウトライン表示

**説明**: 2ペインレイアウトでJSON/YAMLの構造を表示

- 左ペイン: キーのツリー表示（全階層展開、折りたたみなし）
- 右ペイン: 選択されたキーの値をJSON/YAML形式でシンタックスハイライト付き表示
- 初期状態: ルートレベルが選択され、ルートの内容が右ペインに表示

#### F07: シンタックスハイライト

**説明**: JSON/YAMLの要素を色分けして表示

対象要素:
- キー名
- 文字列値
- 数値
- 真偽値（true/false）
- null

## 5. 非機能要件

### 5.1 パフォーマンス要件
- ファイルサイズ制限なし（Markdownビューアーと同様）
- アウトライン表示の描画は大規模ファイルでも1秒以内

### 5.2 セキュリティ要件
- XSS防止: DOMPurifyによるサニタイズ（Markdownビューアーと同様）
- 外部リンクなし（データビューアーのため不要）

### 5.3 互換性要件
- Linux / Windows対応
- tmux DCSパススルー対応

## 6. UI/UX要件

### 6.1 画面設計要件

**アウトライン表示**:
```
┌─────────────────────────────────────────┐
│ [Outline]  ← 表示モード表示            │
├──────────────┬──────────────────────────┤
│ ツリー(左)    │ 詳細(右)                │
│ ├─ key1      │ {                        │
│ ├─ key2 ◀    │   "sub1": "value",      │
│ │  ├─ sub1   │   "sub2": 42            │
│ │  └─ sub2   │ }                        │
│ └─ key3      │                          │
├──────────────┴──────────────────────────┤
│ [r] Toggle  [Esc] Close                 │
└─────────────────────────────────────────┘
```

**RAW表示**:
```
┌─────────────────────────────────────────┐
│ [RAW]  ← 表示モード表示                │
├─────────────────────────────────────────┤
│ {                                       │
│   "key1": "value1",                     │
│   "key2": {                             │
│     "sub1": "value",                    │
│     "sub2": 42                          │
│   },                                    │
│   "key3": [1, 2, 3]                     │
│ }                                [Copy] │
├─────────────────────────────────────────┤
│ [r] Toggle  [p] Pretty  [Esc] Close    │
└─────────────────────────────────────────┘
```

### 6.2 キーバインド
| キー | アウトライン表示 | RAW表示 |
|------|-----------------|---------|
| Escape | ビューアーを閉じる | ビューアーを閉じる |
| r | RAW表示に切り替え | アウトライン表示に切り替え |
| p | - | JSON: pretty-print切り替え |
| ↑/↓ | ツリー項目の選択移動 | スクロール |
| Page Up/Down | ツリーのページスクロール | ページスクロール |
| Home/End | ツリーの先頭/末尾 | 先頭/末尾 |
| Space | - | ページダウン |

## 7. データ要件

### 7.1 OSCシーケンスフォーマット

**JSON**:
```
ESC ] 777 ; emterm ; json ; begin ; id={uuid} ; version=1.0 ESC \
ESC ] 777 ; emterm ; json ; chunk ; id={uuid} ; seq=N ; data={base64} ESC \
ESC ] 777 ; emterm ; json ; end ; id={uuid} ESC \
```

**YAML**:
```
ESC ] 777 ; emterm ; yaml ; begin ; id={uuid} ; version=1.0 ESC \
ESC ] 777 ; emterm ; yaml ; chunk ; id={uuid} ; seq=N ; data={base64} ESC \
ESC ] 777 ; emterm ; yaml ; end ; id={uuid} ESC \
```

## 8. 制約条件

### 8.1 技術的制約
- Markdownビューアーと同じアーキテクチャ（OSC 777 + セッション管理 + フルスクリーンオーバーレイ）を踏襲
- フロントエンド側でのJSON/YAMLパース（Rustバックエンドではパースしない）
- チャンクサイズはMarkdownと同じ128KB

## 9. 想定される課題とリスク

### 9.1 技術的課題
| 課題 | 影響度 | 対応策 |
|------|--------|--------|
| 大規模JSONのアウトラインツリー描画性能 | 中 | 仮想スクロールまたは遅延レンダリングの検討 |
| YAML参照（アンカー/エイリアス）の処理 | 低 | ライブラリ側で解決済みのものを選定 |
