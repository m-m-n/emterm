# 設定パネル - 要件定義書

## 1. 概要

### 1.1 背景
eMterm の設定パネルは現在 `font_size` のみ実装されている。ターミナルエミュレータとして必要な設定項目（フォント、テーマ、カーソル、シェル、キーバインド等）を追加する。

### 1.2 目的
設定パネルに全設定項目を実装し、ユーザーが GUI から設定を変更できるようにする。

### 1.3 スコープ
- 3カテゴリ（Appearance、Terminal、Keybinds）の設定項目の実装
- TypeScript / Rust の型定義拡張
- JSON 設定ファイルの構造拡張
- 設定変更のリアルタイムプレビューと永続化
- 3フェーズに分けた段階的実装

## 2. ビジネス要件

### 2.1 ビジネス目標
ユーザーが GUI から全ての設定を変更できるターミナルエミュレータを実現する。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 一般ユーザー | ターミナルの外観やカーソル動作をカスタマイズしたいユーザー |
| パワーユーザー | キーバインドやシェル設定を細かく調整したいユーザー |

### 2.3 期待される効果
- 設定変更が GUI で完結する
- 設定がリアルタイムにプレビューされる
- 設定が JSON ファイルに永続化される

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | 外観設定の変更 | ユーザー | 高 |
| UC02 | UI テーマの切り替え | ユーザー | 高 |
| UC03 | カーソルスタイルの変更 | ユーザー | 高 |
| UC04 | シェルパスの変更 | ユーザー | 中 |
| UC05 | キーバインドのカスタマイズ | ユーザー | 中 |

### 3.2 ユースケース詳細

#### UC01: 外観設定の変更

**アクター**: ユーザー

**事前条件**:
- 設定パネルが開いている
- Appearance カテゴリが選択されている

**基本フロー**:
1. ユーザーが設定項目の値を変更する
2. 変更がリアルタイムにターミナルに反映される
3. フォーカスが外れた時点で設定が保存される

**事後条件**:
- 設定が JSON ファイルに保存されている
- ターミナル表示が設定に従って更新されている

#### UC02: UI テーマの切り替え

**アクター**: ユーザー

**事前条件**:
- 設定パネルが開いている

**基本フロー**:
1. ユーザーが UI Theme で Light / Dark / System を選択する
2. MD3 カラートークンが即座に切り替わる
3. 設定が保存される

**代替フロー**:
- System 選択時: OS の設定に追従する

**事後条件**:
- UI 全体のテーマが切り替わっている

#### UC03: カーソルスタイルの変更

**アクター**: ユーザー

**基本フロー**:
1. ユーザーがカーソルスタイル（Block / Underline / Bar）を選択する
2. ターミナルのカーソル表示が即座に変更される
3. 設定が保存される

#### UC04: シェルパスの変更

**アクター**: ユーザー

**基本フロー**:
1. ユーザーがシェルパスを入力する
2. 次回タブ作成時から新しいシェルが使用される
3. 設定が保存される

**代替フロー**:
- 空文字列の場合: システムデフォルトシェルを使用する

#### UC05: キーバインドのカスタマイズ

**アクター**: ユーザー

**基本フロー**:
1. ユーザーがキーバインド入力フィールドをクリックする
2. キーコンビネーションを押す
3. キーバインドが記録・保存される

### 4.2 UI 要素タイプ

| UI 要素 | 説明 | 使用箇所 |
|---------|------|----------|
| number input | 数値入力フィールド + 単位ラベル | font_size, line_height, padding, scrollback_lines |
| text input | テキスト入力フィールド | font_family, shell_path, shell_args |
| select dropdown | ドロップダウン選択 | ui_theme, terminal_color_scheme, show_scrollbar, cursor_style, bell_action |
| toggle switch | ON/OFF スイッチ | cursor_blink, url_detection, copy_on_select, inline_images_enabled, markdown_rendering |
| slider | スライダー + 数値表示 | opacity, scroll_speed |
| keybind input | キーバインドキャプチャフィールド | 全 keybind 項目 |

### 4.3 バリデーションルール

二重バリデーション方式を採用する:
- **フロントエンド**: UI レベルで入力を制限（数値はクランプ、enum は select で有効値のみ提示）
- **バックエンド**: `save_settings` で最終バリデーション、無効値はエラーを返して保存を拒否

| 設定項目 | ルール | フロントエンド | バックエンド |
|----------|--------|---------------|-------------|
| font_size | 8 <= value <= 32, 整数 | 範囲にクランプ | Return error |
| font_family | 任意文字列 | そのまま送信 | そのまま保存 |
| line_height | 0.8 <= value <= 3.0 | 範囲にクランプ | Return error |
| ui_theme | `"light"` / `"dark"` / `"system"` | select で有効値のみ | Return error |
| terminal_color_scheme | 有効なプリセット名 | select で有効値のみ | Return error |
| opacity | 0.3 <= value <= 1.0 | 範囲にクランプ | Return error |
| padding | 0 <= value <= 32, 整数 | 範囲にクランプ | Return error |
| scrollback_lines | 0 <= value <= 100000, 整数 | 範囲にクランプ | Return error |
| shell_path | 任意文字列（空文字列可） | そのまま送信 | そのまま保存 |
| scroll_speed | 1 <= value <= 10, 整数 | 範囲にクランプ | Return error |
| bell_action | `"sound"` / `"visual"` / `"none"` | select で有効値のみ | Return error |
| show_scrollbar | `"auto"` / `"always"` / `"never"` | select で有効値のみ | Return error |
| keybinds.* | `"Modifier+Key"` 形式 | キャプチャで有効値のみ | 無効な場合は変更を拒否 |

### 4.4 設定の適用タイミング

| 適用タイミング | 対象設定項目 |
|---------------|-------------|
| リアルタイム（入力中） | font_size, font_family, line_height, ui_theme, terminal_color_scheme, opacity, padding, show_scrollbar, cursor_style, cursor_blink |
| 保存時（blur / Enter） | 全項目の永続化 |
| 次回タブ作成時 | shell_path, shell_args |

## 5. 非機能要件

### 5.1 パフォーマンス要件
- 設定変更のリアルタイムプレビュー: 16ms 以内（60fps）
- 設定ファイルの読み込み: 10ms 以内
- 設定ファイルの書き込み: 50ms 以内

### 5.2 セキュリティ要件
- shell_path のバリデーションはバックエンド側で行う
- キーバインド入力時に任意コード実行を防止する

### 5.3 可用性要件
- 設定ファイルが破損した場合、デフォルト値にフォールバックする
- 未知のフィールドは無視して読み込む（前方互換性）
- 欠落フィールドはデフォルト値で補完する（後方互換性）

### 5.4 アクセシビリティ要件
- ARIA tablist / tab / tabpanel パターンによるカテゴリナビゲーション（実装済）
- 全入力要素に適切な label を設定
- キーボードのみでの操作を保証
- フォーカスインジケーターの表示

## 6. UI/UX 要件

### 6.1 画面構成
- 左ペイン: カテゴリナビゲーション（200px 固定幅）
- 右ペイン: 設定コンテンツ（残り幅）
- Material Design 3 準拠のスタイリング

### 6.2 カテゴリナビゲーション
- Appearance（外観）-- Phase 1 で有効化
- Terminal（ターミナル動作）-- Phase 1 で有効化
- Keybinds（キーバインド）-- Phase 1 で有効化

### 6.3 設定行のレイアウト
- 縦配置: ラベル -> 入力要素 -> ヒントテキスト
- Appearance 内のセクション分け: Font / Theme & Color / Layout / Rich Content
- Terminal 内のセクション分け: Shell / Cursor / Behavior
- Keybinds 内のセクション分け: Basic / Tab Management / Display / Settings

### 6.4 設定変更のフィードバック
- 数値入力: 入力中にリアルタイムプレビュー
- ドロップダウン: 選択即反映
- トグル: 切り替え即反映
- 保存は自動（明示的な保存ボタンなし）

## 7. データ要件

### 7.1 JSON 設定ファイル構造

保存先: `~/.config/emterm/settings.json`

```json
{
  "font_size": 13,
  "font_family": "",
  "line_height": 1.2,
  "ui_theme": "system",
  "terminal_color_scheme": "default",
  "opacity": 1.0,
  "padding": 4,
  "scrollback_lines": 10000,
  "show_scrollbar": "auto",
  "inline_images_enabled": true,
  "markdown_rendering": true,
  "shell_path": "",
  "shell_args": [],
  "cursor_style": "block",
  "cursor_blink": true,
  "scroll_speed": 3,
  "bell_action": "visual",
  "url_detection": true,
  "copy_on_select": false,
  "keybinds": {
    "copy": "Ctrl+Shift+C",
    "paste": "Ctrl+Shift+V",
    "select_all": "Ctrl+Shift+A",
    "search": "Ctrl+Shift+F",
    "new_tab": "Ctrl+Shift+T",
    "close_tab": "Ctrl+Shift+W",
    "next_tab": "Ctrl+Tab",
    "prev_tab": "Ctrl+Shift+Tab",
    "zoom_in": "Ctrl+Plus",
    "zoom_out": "Ctrl+Minus",
    "zoom_reset": "Ctrl+0",
    "toggle_fullscreen": "F11",
    "open_settings": "Ctrl+Comma"
  }
}
```

### 7.2 デフォルト値の管理
- 全フィールドは `#[serde(default)]` で欠落時にデフォルト値を適用する
- `null` 値はカスタムデシリアライザ `deserialize_null_default` で型のデフォルト値に変換する（フィールド欠落と同じ挙動）
- デフォルト値の管理は Rust バックエンド側で行う

## 8. 制約条件

### 8.1 技術的制約
- UI テーマはターミナルのカラースキームから独立している
- フロントエンドは Vanilla TypeScript（フレームワーク不使用）
- スタイリングは Material Design 3 準拠
- バンドラーは Bun

### 8.2 既存実装との整合性
- `font_size` の既存実装（型、バリデーション、UI）との一貫性を維持する
- `SettingsService.load()` / `SettingsService.save()` のインターフェースを維持する
- `applySettings()` のパターンを拡張する
