# 特殊キーマッピングの包括的対応 - 要件定義書

## 1. 概要

### 1.1 背景

emtermのキーボードハンドラ (`keyEventToBytes`) は、基本的なキー入力（a-z、特殊キー単体、Ctrl+a-z）は正しく処理するが、以下の重要なキー入力パターンに対応していない:

1. **Ctrl+記号キー** (`Ctrl+[`, `Ctrl+]`, `Ctrl+\`, `Ctrl+Space`等) - ターミナルの基本的な制御文字
2. **修飾付き特殊キー** (`Ctrl+Arrow`, `Shift+Tab`, `Ctrl+Home/End`等) - xterm標準の修飾シーケンス
3. **WebKitGTK互換性** - Chromiumとの `event.key` 報告値の差異

特に `Ctrl+[` (ESC) はtmuxのコピーモード等で多用されるが、WebKitGTK環境では `key="["` + `ctrlKey=true` として報告されるため、Chromium向けの修正だけでは不十分。

### 1.2 目的

- ターミナルエミュレータとして標準的なキー入力を網羅的にサポートする
- WebKitGTK/Chromium両環境で正しく動作するキーハンドリングを実現する
- Ctrl+Jのブロックを設定可能にする

### 1.3 スコープ

- `keyEventToBytes` 関数の拡張
- SPECIAL_KEYSテーブルへのエントリ追加
- xterm modifier parameter計算ヘルパーの導入
- Ctrl+Jブロックの設定化
- テストの追加

## 3. 機能要件

### 3.1 機能一覧

| ID | 機能名 | 優先度 |
|----|--------|--------|
| F01 | Ctrl+記号キーの制御文字マッピング | 高 |
| F02 | Shift+Tab (Back-Tab) | 高 |
| F03 | 修飾付きカーソルキー | 高 |
| F04 | 修飾付きナビゲーションキー | 高 |
| F05 | 修飾付きFunctionキー | 低 |
| F06 | Ctrl+Alt組み合わせ | 低 |
| F07 | Ctrl+Jブロックの設定化 | 中 |

### 3.2 機能詳細

#### F01: Ctrl+記号キーの制御文字マッピング

Ctrl+letterハンドラーを拡張し、`@[\]^_` (0x40-0x5F) の範囲および Space (0x20) に対して `charCode & 0x1F` で制御文字を計算する。

| キー | 生成バイト | 用途 |
|------|-----------|------|
| Ctrl+@ | 0x00 (NUL) | emacsのmark set |
| Ctrl+[ | 0x1B (ESC) | tmuxコピーモード、vi escape |
| Ctrl+\ | 0x1C (FS) | SIGQUIT |
| Ctrl+] | 0x1D (GS) | telnet escape、vim ctag |
| Ctrl+^ | 0x1E (RS) | vim alternate file |
| Ctrl+_ | 0x1F (US) | emacs undo |
| Ctrl+Space | 0x00 (NUL) | emacsのmark set |

WebKitGTK互換: `key="["` + `ctrlKey=true` として報告されるケースに対応。

#### F02: Shift+Tab (Back-Tab)

SPECIAL_KEYSに `{ key: "Tab", shift: true, sequence: [0x1b, 0x5b, 0x5a] }` を追加。ESC [ Z (CSI Z) を送信する。

#### F03: 修飾付きカーソルキー

xterm標準のmodifier parameter方式を導入する。

**modifier code計算:**
```
modifier = 1 + (shift ? 1 : 0) + (alt ? 2 : 0) + (ctrl ? 4 : 0)
```

**送信シーケンス:** `ESC [1;{modifier}{letter}`

| キー | シーケンス |
|------|-----------|
| Ctrl+ArrowUp | ESC [1;5A |
| Ctrl+ArrowDown | ESC [1;5B |
| Ctrl+ArrowRight | ESC [1;5C |
| Ctrl+ArrowLeft | ESC [1;5D |
| Shift+ArrowUp | ESC [1;2A |
| Shift+ArrowRight | ESC [1;2C |
| Alt+ArrowUp | ESC [1;3A |
| Ctrl+Shift+ArrowUp | ESC [1;6A |

**注意:** Ctrl+Shift+ArrowUp/Downはemtermのプロンプトジャンプショートカットとして使用されているため、PTYには送信されない（既存の動作を維持）。

#### F04: 修飾付きナビゲーションキー

**Home/End (letter形式):** `ESC [1;{modifier}{letter}`

| キー | シーケンス |
|------|-----------|
| Ctrl+Home | ESC [1;5H |
| Ctrl+End | ESC [1;5F |
| Shift+Home | ESC [1;2H |
| Shift+End | ESC [1;2F |

**Delete/Insert/PageUp/PageDown (tilde形式):** `ESC [{number};{modifier}~`

| キー | シーケンス |
|------|-----------|
| Ctrl+Delete | ESC [3;5~ |
| Ctrl+Insert | ESC [2;5~ |
| Ctrl+PageUp | ESC [5;5~ |
| Ctrl+PageDown | ESC [6;5~ |
| Shift+Insert | ESC [2;2~ |

#### F05: 修飾付きFunctionキー

**F1-F4 (SS3形式):** `ESC [1;{modifier}{letter}`

| キー | シーケンス |
|------|-----------|
| Shift+F1 | ESC [1;2P |
| Ctrl+F1 | ESC [1;5P |

**F5-F12 (tilde形式):** `ESC [{number};{modifier}~`

| キー | シーケンス |
|------|-----------|
| Shift+F5 | ESC [15;2~ |
| Ctrl+F5 | ESC [15;5~ |

#### F06: Ctrl+Alt組み合わせ

ESCプレフィックス + 制御文字を送信する。

例: Ctrl+Alt+C → ESC 0x03

#### F07: Ctrl+Jブロックの設定化

現在は無条件でCtrl+Jをブロックしている（SKK IME対策）。設定で切り替え可能にする。

- 設定名: `ime.skk_mode` (boolean)
- デフォルト: `true`（後方互換性のため）
- `false` の場合: Ctrl+Jは 0x0A (LF) をPTYに送信する

## 4. 非機能要件

### 4.1 パフォーマンス

- キー入力の遅延が増加しないこと（既存のhotpath維持）

### 4.2 互換性

- WebKitGTK (Linux) とChromium系WebView (Windows/macOS) の両方で動作すること
- 既存のキーバインド（Ctrl+Shift+C/V等）との干渉がないこと
- emtermのプロンプトジャンプ（Ctrl+Shift+Arrow）との共存

## 5. 確認済み事項

- [x] Ctrl+z Ctrl+[がリビルド後も動作しない: WebKitGTKが `key="["` + `ctrlKey=true` として報告するため
- [x] WezTermでは同じtmux設定で動作する: WezTermはネイティブ実装のためWebView非依存
- [x] Ctrl+Jは設定可能にする: fzfのacceptキーとしても使われるため
- [x] 対応範囲: 全ての特殊キーマッピング（高・中・低優先度すべて）
