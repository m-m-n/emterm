# 設定画面カテゴリ再編成 - 要件定義書

## 1. 概要

### 1.1 背景
現在の設定画面は「外観」「ターミナル」「キーバインド」の3カテゴリで構成されているが、「外観」カテゴリに設定項目が集中しており、UI関連の設定とターミナル固有の設定が混在している。

### 1.2 目的
設定項目を論理的に整理し、ユーザーが目的の設定を見つけやすくする。また、UIフォント設定を新規追加する。

### 1.3 スコープ
- 設定カテゴリの再編成（3→4カテゴリ）
- UIフォントファミリー設定の新規追加
- 既存設定項目の移動
- i18n対応（日本語・英語）

## 2. ビジネス要件

### 2.1 ビジネス目標
設定画面のユーザビリティ向上

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| 一般ユーザー | ターミナルエミュレータを使用するユーザー |

### 2.3 期待される効果
- 設定項目の発見性向上
- 論理的なカテゴリ分けによる理解しやすさの向上
- UIフォントのカスタマイズ機能提供

## 3. 機能要件

### 3.1 新カテゴリ構成

| カテゴリID | カテゴリ名（日本語） | カテゴリ名（英語） |
|------------|---------------------|-------------------|
| `ui` | UI設定 | UI Settings |
| `keybinds` | キーバインド | Keybinds |
| `terminal-appearance` | ターミナル表示 | Terminal Appearance |
| `terminal-behavior` | ターミナル動作 | Terminal Behavior |

### 3.2 設定項目の配置

#### UI設定 (ui)
| 設定項目 | キー | 移動元 | 備考 |
|----------|------|--------|------|
| 言語 | `language` | 外観 | 既存 |
| UIテーマ | `ui_theme` | 外観 | 既存 |
| UIテーマプリセット | `ui_theme_preset` | 外観 | 既存 |
| UIフォントファミリー | `ui_font_family` | - | **新規追加** |

#### キーバインド (keybinds)
変更なし（既存のまま）

#### ターミナル表示 (terminal-appearance)
| 設定項目 | キー | 移動元 |
|----------|------|--------|
| フォントサイズ | `font_size` | 外観 |
| プライマリフォント | `font_family_primary` | 外観 |
| セカンダリフォント | `font_family_secondary` | 外観 |
| 絵文字フォント | `font_family_emoji` | 外観 |
| 行間 | `line_height` | 外観 |
| ターミナル配色 | `terminal_color_scheme` | 外観 |
| パディング | `padding` | 外観 |
| スクロールバック行数 | `scrollback_lines` | 外観 |
| スクロールバー表示 | `show_scrollbar` | 外観 |

#### ターミナル動作 (terminal-behavior)
| 設定項目 | キー | 移動元 |
|----------|------|--------|
| カーソルスタイル | `cursor_style` | ターミナル |
| カーソル点滅 | `cursor_blink` | ターミナル |
| シェルパス | `shell_path` | ターミナル |
| シェル引数 | `shell_args` | ターミナル |
| スクロール速度 | `scroll_speed` | ターミナル |
| ベルアクション | `bell_action` | ターミナル |
| URL検出 | `url_detection` | ターミナル |
| 選択時コピー | `copy_on_select` | ターミナル |

### 3.3 新規設定項目: UIフォントファミリー

**説明**: 設定画面やメニューなど、アプリケーションUI全体で使用するフォントファミリー

**入力**:
- フォントファミリー名（文字列）

**デフォルト値**:
- `"Roboto"` (CSSフォールバック: system-ui, sans-serif)

**適用範囲**:
- 設定画面
- 将来的にはメニュー、ダイアログなど

**バリデーション**:
- 空文字の場合はデフォルトフォントを使用

## 4. 非機能要件

### 4.1 パフォーマンス要件
- カテゴリ切り替え時のレンダリング: 即座に完了すること

### 4.2 互換性要件
- 既存の設定ファイルとの後方互換性を維持
- 新しい設定項目（`ui_font_family`）はデフォルト値で動作

### 4.3 アクセシビリティ要件
- キーボードナビゲーション対応を維持
- ARIA属性を適切に設定

## 5. UI/UX要件

### 5.1 ナビゲーション
- 4つのカテゴリボタンを縦に配置
- 現在の選択状態を視覚的に表示（MD3 secondary-container）

### 5.2 カテゴリ表示順序
1. UI設定
2. キーバインド
3. ターミナル表示
4. ターミナル動作

## 6. データ要件

### 6.1 設定ファイル変更

`AppSettings` 型に追加:
```typescript
ui_font_family: string;  // 新規
```

### 6.2 デフォルト値
```typescript
ui_font_family: "Roboto"
```

## 7. 制約条件

### 7.1 技術的制約
- 既存のMaterial Design 3スタイリングを維持
- TypeScript型定義の更新が必要

### 7.2 設計制約
- UIフォントサイズは追加しない（MD3タイポグラフィスケールに準拠）
