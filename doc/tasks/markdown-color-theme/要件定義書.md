# マークダウンビューアー カラーテーマ設定 - 要件定義書

## 1. 概要

### 1.1 背景
マークダウンビューアーのカラーテーマは現在、ターミナルの背景色・前景色から自動生成されるのみで、UIテーマ（light/dark + preset）との連動やユーザーによる個別選択ができない。

### 1.2 目的
マークダウンビューアーのカラーテーマをUI設定のカラーテーマと連動させる機能を提供し、必要に応じて独立したテーマ選択も可能にする。

### 1.3 スコープ
- マークダウンビューアー用カラーパレットの定義（light/dark x purple/blue/green/orange = 8パターン）
- UI設定との連動トグル
- マークダウンビューアー独自のテーマ選択UI
- フルスクリーン表示へのカラーテーマ適用
- CSS変数の統一（`--md-*` に一本化）と死コード整理

## 2. ビジネス要件

### 2.1 ビジネス目標
マークダウンビューアーの見た目をUIテーマと統一し、視覚的な一貫性を高める。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| eMterm利用者 | ターミナル内でマークダウンを表示するユーザー |

### 2.3 期待される効果
- UIテーマとマークダウンビューアーの見た目が統一される
- ユーザーが好みのカラーテーマを選択できる

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | UIテーマ連動モードの有効化 | ユーザー | 高 |
| UC02 | マークダウン独自テーマの選択 | ユーザー | 高 |
| UC03 | UIテーマ変更時の自動追従 | システム | 高 |

### 3.2 ユースケース詳細

#### UC01: UIテーマ連動モードの有効化

**アクター**: ユーザー

**事前条件**:
- 設定画面のマークダウンビューアーセクションを開いている

**基本フロー**:
1. ユーザーが「UIテーマに合わせる」トグルをONにする
2. マークダウンビューアーのカラーテーマがUI設定のlight/dark + presetに追従する
3. マークダウン独自のテーマ/プリセット選択UIが非表示になる

**事後条件**:
- マークダウンビューアーがUIテーマと同じテーマ・プリセットの組み合わせで表示される

#### UC02: マークダウン独自テーマの選択

**アクター**: ユーザー

**事前条件**:
- 「UIテーマに合わせる」トグルがOFF

**基本フロー**:
1. ユーザーがテーマ（system/light/dark）を選択する
2. ユーザーがプリセット（purple/blue/green/orange）を選択する
3. マークダウンビューアーに選択した組み合わせのカラーパレットが適用される

**事後条件**:
- マークダウンビューアーが選択されたテーマ・プリセットの組み合わせで表示される

#### UC03: UIテーマ変更時の自動追従

**アクター**: システム

**事前条件**:
- 「UIテーマに合わせる」トグルがON

**基本フロー**:
1. ユーザーがUI設定でテーマまたはプリセットを変更する
2. マークダウンビューアーのカラーテーマが自動的にUI設定に追従する

**事後条件**:
- マークダウンビューアーがUI設定と同じテーマ・プリセットで表示される

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | マークダウン用カラーパレット定義 | light/dark x 4プリセット = 8パターン、各11色の定義 | 高 |
| F02 | UIテーマ連動トグル | ONでUI設定に追従、OFFで独自選択 | 高 |
| F03 | マークダウン独自テーマ選択 | トグルOFF時のテーマ・プリセット選択UI | 高 |
| F04 | カラーテーマ適用 | CSS変数（`--md-*`）への適用 | 高 |
| F05 | 設定の永続化 | Rust AppSettings構造体への追加と保存 | 高 |
| F06 | CSS変数統一・死コード整理 | `--markdown-*` を `--md-*` に統一、未使用コード削除 | 高 |

### 4.2 機能詳細

#### F01: マークダウン用カラーパレット定義

**説明**: UIテーマプリセットと同様に、マークダウンビューアー用のカラーパレットを定義する。

**カラーパレット構成**: 各組み合わせ（light/dark x purple/blue/green/orange）ごとに以下の11色を定義:
- `bg`: 背景色
- `fg`: 前景色/テキスト色
- `heading`: 見出し色
- `link`: リンク色
- `border`: ボーダー色
- `blockquote`: 引用テキスト色
- `codeBg`: インラインコード背景色
- `codeFg`: コード文字色
- `preBg`: コードブロック背景色
- `tableBg`: テーブル背景色
- `tableStripe`: テーブルストライプ（交互行）背景色

**定義数**: 8パターン（dark-purple, dark-blue, dark-green, dark-orange, light-purple, light-blue, light-green, light-orange）

#### F02: UIテーマ連動トグル

**説明**: トグルスイッチでUI設定のカラーテーマへの連動ON/OFFを切り替える。

**デフォルト値**: ON（UI設定に連動）

**動作**:
- ON: UI設定のui_theme + ui_theme_presetに連動してマークダウンのカラーテーマが決定される
- OFF: マークダウンビューアー独自のテーマ・プリセットを選択可能

#### F03: マークダウン独自テーマ選択

**説明**: トグルOFF時にマークダウンビューアー独自のテーマ/プリセットを選択するUI。

**設定項目**:
- テーマ: system / light / dark（セレクトボックス）
- プリセット: purple / blue / green / orange（セレクトボックス）

**UI表示条件**: 「UIテーマに合わせる」トグルがOFFの場合のみ表示

#### F04: カラーテーマ適用

**説明**: 選択されたテーマ設定に基づき、CSS変数にカラーパレットの値を適用する。

**適用先CSS変数（`--md-*`）**:
- `--md-bg`, `--md-fg`, `--md-heading`, `--md-link`
- `--md-border`, `--md-blockquote`, `--md-code-bg`, `--md-code-fg`
- `--md-pre-bg`, `--md-table-bg`, `--md-table-stripe`

**system テーマの場合**: `prefers-color-scheme` メディアクエリでlight/darkを判定し、システムテーマ変更時に自動切り替え

#### F05: 設定の永続化

**説明**: 新しい設定項目をRust AppSettings構造体とTypeScript AppSettingsインターフェースに追加する。

**追加フィールド**:
| フィールド名 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `markdown_theme_follow_ui` | bool | true | UIテーマ連動トグル |
| `markdown_theme` | UiTheme | system | マークダウン独自テーマ（light/dark/system） |
| `markdown_theme_preset` | UiThemePreset | purple | マークダウン独自プリセット |

#### F06: CSS変数統一・死コード整理

**説明**: 現在2系統あるCSS変数を `--md-*` に統一し、未使用コードを削除する。

**削除対象**:
- `styles.css`: `.markdown-block` クラス（未使用）
- `styles.css`: `.markdown-content` のスタイル（`--markdown-*` CSS変数を使用） → `fullscreen.css` に `--md-*` で統合
- `theme.ts`: `generateMarkdownTheme()`, `applyMarkdownTheme()`, `getDarkTheme()`, `getLightTheme()` （未使用）
- `theme.ts`: `MarkdownTheme` インターフェース、`DARK_THEME`/`LIGHT_THEME` 定数、ヘルパー関数（新プリセットシステムに置換）

**移行**:
- `styles.css` の `.markdown-content` 子要素スタイルのうち、`fullscreen.css` で未定義のもの（リスト、画像、テーブルストライプ等）を `fullscreen.css` に `--md-*` 変数で移植
- カラー変数を追加: `--md-code-fg`, `--md-pre-bg`, `--md-table-bg`, `--md-table-stripe`
- フォント変数を改名: `--markdown-body-font-family` -> `--md-body-font-family`, `--markdown-code-font-family` -> `--md-code-font-family`, `--markdown-body-font-size` -> `--md-body-font-size`（`settings-applier.ts`, `fullscreen.css`, テストファイルを更新）

## 5. 非機能要件

### 5.1 パフォーマンス要件
- テーマ切り替え時のCSS変数適用は即座に反映されること（既存のUIテーマ切り替えと同等）

### 5.2 後方互換性要件
- 設定ファイルに新しいフィールドが存在しない場合はデフォルト値が使用されること
- 設定ファイルの新しいフィールドがnullの場合もデフォルト値が使用されること

## 6. UI/UX要件

### 6.1 設定画面構成
マークダウンビューアーセクション内に以下を追加:

```
[既存] フォント サブセクション
  - 本文フォント
  - コードフォント
  - フォントサイズ

[新規] カラーテーマ サブセクション
  - UIテーマに合わせる（トグル）
  - テーマ（セレクト）      ← トグルOFF時のみ表示
  - プリセット（セレクト）   ← トグルOFF時のみ表示
```

### 6.2 トグルON/OFF時の表示切り替え
- トグルON: テーマ・プリセットの選択UIは非表示
- トグルOFF: テーマ・プリセットの選択UIを表示

## 7. データ要件

### 7.1 設定データ

| フィールド | 型 | 必須 | デフォルト | 説明 |
|---|---|---|---|---|
| markdown_theme_follow_ui | bool | - | true | UIテーマ連動 |
| markdown_theme | string (enum) | - | "system" | light/dark/system |
| markdown_theme_preset | string (enum) | - | "purple" | purple/blue/green/orange |

### 7.2 カラーパレットデータ

コード内にハードコードされる定数データ。8パターン x 11色 = 88色。

## 8. 制約条件

### 8.1 技術的制約
- CSS変数は `--md-*` 命名規則に統一
- Rust側の設定パターン（`serde(default)` + `deserialize_null_with!`）に従う
- TypeScript側の型定義はRust構造体と一致させる

## 11. 用語定義

| 用語 | 定義 |
|------|------|
| フルスクリーン表示 | 全画面オーバーレイでのマークダウン表示（`fullscreen.css`, `--md-*` CSS変数） |
