# Markdownビューアー設定 - 要件定義書

## 1. 概要

### 1.1 背景

Markdownビューアー（フルスクリーンオーバーレイ）のフォントファミリーとフォントサイズがCSSにハードコードされており、ユーザーが変更できない。

### 1.2 目的

設定画面に「Markdownビューアー」カテゴリを新設し、フォントファミリーとフォントサイズをユーザーが設定できるようにする。

### 1.3 スコープ

- 設定画面への新規カテゴリ追加
- Rust バックエンドの設定構造体への項目追加
- TypeScript フロントエンドの設定UIレンダリング
- Markdownフルスクリーンオーバーレイへの設定値適用
- 対象外: Markdownの色テーマ設定（既にCSS変数で動的管理済み）

## 2. ユースケース

### 2.1 ユースケース一覧

| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | Markdown本文フォントの変更 | ユーザー | 高 |
| UC02 | コードブロックフォントの変更 | ユーザー | 高 |
| UC03 | 本文フォントサイズの変更 | ユーザー | 高 |

### 2.2 ユースケース詳細

#### UC01: Markdown本文フォントの変更

**アクター**: ユーザー

**事前条件**:
- 設定画面が開かれている
- 「Markdownビューアー」カテゴリが選択されている

**基本フロー**:
1. ユーザーが「本文フォントファミリー」のフォントピッカーボタンをクリック
2. フォントピッカーダイアログが表示される
3. ユーザーがフォントを選択する
4. 設定が自動保存される
5. Markdownオーバーレイに即時反映される

**代替フロー**:
- フォントが未選択（空文字列）の場合、CSSのフォールバックチェーンが使用される

#### UC02: コードブロックフォントの変更

**アクター**: ユーザー

**基本フロー**: UC01と同様。「コードブロックフォントファミリー」のフォントピッカーを使用。

#### UC03: 本文フォントサイズの変更

**アクター**: ユーザー

**基本フロー**:
1. ユーザーが「本文フォントサイズ」の数値入力フィールドを変更
2. 値が8-32ptの範囲でバリデーションされる
3. 設定が自動保存される
4. Markdownオーバーレイに即時反映される

## 3. 機能要件

### 3.1 機能一覧

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 設定カテゴリ追加 | 「Markdownビューアー」を5番目のカテゴリとして追加 | 高 |
| F02 | 本文フォントファミリー設定 | sans-serif系フォントの選択 | 高 |
| F03 | コードブロックフォントファミリー設定 | monospace系フォントの選択 | 高 |
| F04 | 本文フォントサイズ設定 | pt単位でのサイズ指定 | 高 |
| F05 | 設定値のCSS適用 | 設定値をCSS変数経由でオーバーレイに適用 | 高 |

### 3.2 機能詳細

#### F01: 設定カテゴリ追加

**説明**: 設定画面のナビゲーションに「Markdownビューアー」カテゴリを追加する。

**カテゴリID**: `markdown-viewer`

**配置順序**: 5番目（UI設定、キーバインド、ターミナル外観、ターミナル動作の後）

#### F02: 本文フォントファミリー設定

**説明**: Markdown本文（段落、見出し、リスト等）のフォントファミリーを指定する。

**入力**: フォントピッカーダイアログ（既存コンポーネント再利用）

**デフォルト値**: 空文字列（CSSフォールバック: `-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", Helvetica, Arial, sans-serif`）

**バリデーション**: 文字列（任意のフォント名、空文字列許可）

#### F03: コードブロックフォントファミリー設定

**説明**: Markdownコードブロック（`<code>`, `<pre>`）のフォントファミリーを指定する。

**入力**: フォントピッカーダイアログ（既存コンポーネント再利用）

**デフォルト値**: 空文字列（CSSフォールバック: `"Inconsolata", "Noto Sans JP", "Noto Color Emoji", monospace`）

**バリデーション**: 文字列（任意のフォント名、空文字列許可）

#### F04: 本文フォントサイズ設定

**説明**: Markdown本文の基準フォントサイズをpt単位で指定する。見出し（h1: 2em, h2: 1.5em, h3: 1.25em等）やコードブロック（85%）のサイズはこの値からの相対値として自動計算される。

**入力**: 数値入力（renderNumberInputコンポーネント再利用）

**デフォルト値**: 14pt

**範囲**: 8-32pt

**ステップ**: 1

**単位表示**: pt

**バリデーション**: 整数、8以上32以下

#### F05: 設定値のCSS適用

**説明**: 設定値をCSS変数としてMarkdownフルスクリーンオーバーレイに適用する。

**CSS変数**:
- `--markdown-body-font-family`: 本文フォントファミリー
- `--markdown-code-font-family`: コードブロックフォントファミリー
- `--markdown-body-font-size`: 本文フォントサイズ

**適用対象**: `.markdown-fullscreen-content` および内部の `.markdown-content`

**適用タイミング**:
- 設定変更時に即時適用
- アプリ起動時に保存済み設定から適用

## 4. 非機能要件

### 4.1 パフォーマンス要件

- 設定変更時のCSS適用は即時（体感遅延なし）

### 4.2 互換性要件

- 既存の設定ファイル（settings.json）との後方互換性を維持
- 新規フィールドが存在しない場合はデフォルト値を使用（serde(default)で対応）

### 4.3 保守性要件

- 既存の設定管理パターン（load/save/validate/apply）に準拠

## 5. データ要件

### 5.1 AppSettings構造体への追加フィールド

| フィールド名 | 型 | デフォルト値 | 説明 |
|-------------|-----|-------------|------|
| `markdown_body_font_family` | `String` | `""` | 本文フォントファミリー |
| `markdown_code_font_family` | `String` | `""` | コードブロックフォントファミリー |
| `markdown_font_size` | `u32` | `14` | 本文フォントサイズ (pt) |

### 5.2 バリデーション

| フィールド | ルール |
|-----------|--------|
| `markdown_font_size` | 8以上32以下の整数 |

## 6. UI/UX要件

### 6.1 設定画面レイアウト

「Markdownビューアー」カテゴリのコンテンツ:

```
Markdownビューアー
├── フォント
│   ├── 本文フォントファミリー [フォントピッカー]
│   ├── コードブロックフォントファミリー [フォントピッカー]
│   └── 本文フォントサイズ [数値入力] pt
```

### 6.2 UIコンポーネント

- フォントピッカー: 既存の `FontPicker` コンポーネントを再利用
- 数値入力: 既存の `renderNumberInput` コンポーネントを再利用
- サブセクションヘッダー: 既存の `renderSubsectionHeader` を再利用

## 7. 制約条件

### 7.1 技術的制約

- 単位はpt（ターミナル設定と統一）
- 見出しサイズはユーザー設定項目にしない（本文サイズからの相対値として内部固定）
- コードブロックサイズはユーザー設定項目にしない（本文サイズの85%として内部固定）
- フォントが空文字列の場合、CSSのフォールバックチェーンが適用される
