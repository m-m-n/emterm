# 右クリックコンテキストメニュー - 要件定義書

## 1. 概要

### 1.1 背景
eMtermにはテキスト選択のコピーやURLを開く機能が存在するが、これらの操作はキーボードショートカットやCtrl+クリックに限定されている。右クリックメニューを提供することで、一般的なターミナルエミュレータと同等の操作性を実現する。

### 1.2 目的
ターミナル領域、タブ、タブバーの各領域に適切なコンテキストメニューを提供し、基本操作をマウスから実行可能にする。

### 1.3 スコープ
- ターミナル領域のコンテキストメニュー（コピー、貼り付け、URL操作）
- タブのコンテキストメニュー（閉じる）
- タブバー空き領域のコンテキストメニュー（新規、プロファイル）
- Tauriネイティブメニュー（OS標準のメニューUI）を使用

## 2. ビジネス要件

### 2.1 ビジネス目標
一般的なターミナルエミュレータ（GNOME Terminal、Windows Terminal等）と同等の右クリック操作を提供する。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| ターミナルユーザー | マウス操作でコピー・ペースト・URL操作を行いたいユーザー |

### 2.3 期待される効果
- マウスによるコピー・ペースト操作の実現
- URL操作の発見性向上
- タブ管理操作の効率化

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | ターミナルでテキストをコピー | ユーザー | 高 |
| UC02 | ターミナルでテキストを貼り付け | ユーザー | 高 |
| UC03 | URLをコピー | ユーザー | 高 |
| UC04 | URLをブラウザで開く | ユーザー | 高 |
| UC05 | タブを閉じる | ユーザー | 高 |
| UC06 | 新規タブを作成 | ユーザー | 高 |
| UC07 | プロファイルでタブを作成 | ユーザー | 高 |

### 3.2 ユースケース詳細

#### UC01: ターミナルでテキストをコピー
**アクター**: ユーザー
**事前条件**: テキストが選択されている
**基本フロー**:
1. ターミナル領域で右クリック
2. コンテキストメニューが表示される
3. 「コピー」をクリック
4. 選択テキストがクリップボードにコピーされる
**代替フロー**: テキスト未選択の場合、「コピー」はdisable（グレーアウト）

#### UC02: ターミナルでテキストを貼り付け
**アクター**: ユーザー
**事前条件**: なし
**基本フロー**:
1. ターミナル領域で右クリック
2. コンテキストメニューが表示される
3. 「貼り付け」をクリック
4. クリップボードのテキストがPTYに送信される
**代替フロー**: 複数行テキストの場合、確認ダイアログを表示（既存のPaste Dialog）

#### UC03: URLをコピー
**アクター**: ユーザー
**事前条件**: 右クリック位置にURLが存在する
**基本フロー**:
1. URL上で右クリック
2. コンテキストメニューが表示される
3. 「URLをコピー」をクリック
4. URLテキストがクリップボードにコピーされる
**代替フロー**: URL上でない場合、「URLをコピー」はdisable

#### UC04: URLをブラウザで開く
**アクター**: ユーザー
**事前条件**: 右クリック位置にURLが存在する
**基本フロー**:
1. URL上で右クリック
2. コンテキストメニューが表示される
3. 「URLを開く」をクリック
4. デフォルトブラウザでURLが開かれる
**代替フロー**: URL上でない場合、「URLを開く」はdisable

#### UC05: タブを閉じる
**アクター**: ユーザー
**事前条件**: タブが存在する
**基本フロー**:
1. タブ上で右クリック
2. コンテキストメニューが表示される
3. 「閉じる」をクリック
4. 対象タブが閉じられる

#### UC06: 新規タブを作成
**アクター**: ユーザー
**基本フロー**:
1. タブバーの空き領域で右クリック
2. コンテキストメニューが表示される
3. 「新規」をクリック
4. 新しいターミナルタブが作成される

#### UC07: プロファイルでタブを作成
**アクター**: ユーザー
**事前条件**: プロファイルが1件以上設定されている
**基本フロー**:
1. タブバーの空き領域で右クリック
2. コンテキストメニューが表示される
3. 「プロファイルを開く」をクリック
4. プロファイル選択UIが表示される
5. プロファイルを選択
6. 選択したプロファイルで新しいタブが作成される
**代替フロー**: プロファイルが0件の場合、「プロファイルを開く」はdisable

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | ターミナルコンテキストメニュー | コピー、貼り付け、URLコピー、URL開く | 高 |
| F02 | タブコンテキストメニュー | 閉じる | 高 |
| F03 | タブバーコンテキストメニュー | 新規、プロファイルを開く | 高 |

### 4.2 機能詳細

#### F01: ターミナルコンテキストメニュー

**メニュー項目:**

| 項目 | 有効条件 | 動作 |
|------|---------|------|
| コピー | テキスト選択あり | 選択テキストをクリップボードにコピー |
| 貼り付け | 常に有効 | クリップボードからPTYに送信 |
| （セパレーター） | - | - |
| URLをコピー | 右クリック位置にURL | URLをクリップボードにコピー |
| URLを開く | 右クリック位置にURL | デフォルトブラウザで開く |

**マウストラッキング中の動作**: メニューを表示する。PTYへのマウスイベント送信は行わない。

#### F02: タブコンテキストメニュー

**メニュー項目:**

| 項目 | 有効条件 | 動作 |
|------|---------|------|
| 閉じる | 常に有効 | 対象タブを閉じる |

#### F03: タブバーコンテキストメニュー

**メニュー項目:**

| 項目 | 有効条件 | 動作 |
|------|---------|------|
| 新規 | 常に有効 | デフォルトシェルで新規タブ作成 |
| プロファイルを開く | プロファイル1件以上 | プロファイル選択UIを表示 |

## 5. 非機能要件

### 5.1 パフォーマンス要件
- メニュー表示: 右クリックから即時表示（ネイティブメニューのため遅延なし）

### 5.2 プラットフォーム要件
- Linux: GTKネイティブメニュー
- Windows: Win32ネイティブメニュー

### 5.3 保守性要件
- メニュー項目の追加が容易な構造
- i18nによるメニュー項目名のローカライズ対応

## 6. UI/UX要件

### 6.1 メニュー外観
- Tauriネイティブメニュー（OS標準）を使用
- カスタムスタイリングは不要

### 6.2 メニュー項目のローカライズ
- 日本語/英語のi18n対応（既存のi18nシステムを利用）

## 7. 制約条件

### 7.1 技術的制約
- Tauri v2の Menu API を使用（`tauri::menu::Menu`, `popup_menu()`）
- フロントエンドからは `@tauri-apps/api/menu` を使用
- Tauri capabilities に menu 関連パーミッションの追加が必要
