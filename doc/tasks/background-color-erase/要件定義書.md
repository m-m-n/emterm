# Background Color Erase (BCE) - 要件定義書

## 1. 概要

### 1.1 背景
eMtermのターミナルグリッドにおいて、消去操作（EL, ED, ECH等）で生成される空セルは常にデフォルト背景色を持つ。VT100/xterm仕様では、消去操作はカーソルの現在のSGR背景色を継承すべきと定められている（Background Color Erase = BCE）。

### 1.2 目的
消去操作で生成される空セルがカーソルの現在の背景色を継承するようにし、diff表示等での背景色ブロック塗りつぶしを正しく描画する。

### 1.3 スコープ
- WASMモジュール内のセル消去・生成処理
- 対象: EL, ED, ECH, ICH, DCH, スクロール, 行挿入/削除

## 2. ビジネス要件

### 2.1 ビジネス目標
ターミナルエミュレータとしての標準的な描画互換性を確保する。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| ターミナルユーザー | diff表示、カラー出力を行うCLIツールを使用するユーザー |

### 2.3 期待される効果
- diff表示（Claude Code等）で背景色が行末までブロック単位で塗りつぶされる
- SGR背景色を使用するアプリケーション全般の表示互換性が向上する

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | diff表示の背景色塗りつぶし | ターミナルユーザー | 高 |
| UC02 | カラー背景付きスクロール | ターミナルユーザー | 高 |
| UC03 | SGRリセット後の消去 | ターミナルユーザー | 高 |

### 3.2 ユースケース詳細

#### UC01: diff表示の背景色塗りつぶし

**アクター**: ターミナルユーザー

**事前条件**:
- ターミナルでdiff出力を表示するアプリケーション（Claude Code等）を使用

**基本フロー**:
1. アプリケーションがSGR背景色を設定（例: `ESC[42m` 緑背景）
2. テキストを出力
3. `ESC[K`（行末まで消去）を発行
4. 消去されたセルがカーソルの背景色（緑）で塗りつぶされる

**事後条件**:
- 行全体が統一された背景色で表示される

#### UC02: カラー背景付きスクロール

**アクター**: ターミナルユーザー

**事前条件**:
- SGR背景色が設定された状態でスクロールが発生

**基本フロー**:
1. アプリケーションがSGR背景色を設定
2. スクロール操作（改行、`ESC[S`等）が発生
3. 新しく生成される空行がカーソルの背景色を継承する

**事後条件**:
- スクロールで生成された空行が現在の背景色で表示される

#### UC03: SGRリセット後の消去

**アクター**: ターミナルユーザー

**事前条件**:
- SGRリセット（`ESC[0m`）後

**基本フロー**:
1. アプリケーションが`ESC[0m`で属性をリセット
2. `ESC[K`（行末まで消去）を発行
3. 消去されたセルがデフォルト背景色になる

**事後条件**:
- リセット後の消去ではデフォルト背景色が使われる

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 消去操作のBCE | EL/ED/ECHでカーソル背景色を継承 | 高 |
| F02 | 文字挿入/削除のBCE | ICH/DCHで生成される空セルがカーソル背景色を継承 | 高 |
| F03 | スクロールのBCE | スクロール・行挿入/削除で生成される空行がカーソル背景色を継承 | 高 |

### 4.2 機能詳細

#### F01: 消去操作のBCE

**説明**: EL（Erase in Line）、ED（Erase in Display）、ECH（Erase Characters）の消去操作で、消去されるセルにカーソルの現在のSGR背景色を設定する。

**対象CSIシーケンス**:
- `CSI K` / `CSI 0 K` (EL: 行末まで消去)
- `CSI 1 K` (EL: 行頭まで消去)
- `CSI 2 K` (EL: 行全体消去)
- `CSI J` / `CSI 0 J` (ED: カーソル以下消去)
- `CSI 1 J` (ED: カーソル以上消去)
- `CSI 2 J` (ED: 画面全体消去)
- `CSI X` (ECH: N文字消去)

**処理**: 消去されるセルの`bg`フィールドを`cursor.bg`の値に設定する。

#### F02: 文字挿入/削除のBCE

**説明**: ICH（Insert Characters）、DCH（Delete Characters）で新しく生成される空セルにカーソルの現在のSGR背景色を設定する。

**対象CSIシーケンス**:
- `CSI @` (ICH: N文字挿入)
- `CSI P` (DCH: N文字削除)

**処理**: 挿入/削除操作で生まれる空セルの`bg`フィールドを`cursor.bg`の値に設定する。

#### F03: スクロールのBCE

**説明**: スクロール操作および行挿入/削除で新しく生成される空行にカーソルの現在のSGR背景色を設定する。

**対象操作**:
- `CSI S` (SU: 上スクロール)
- `CSI T` (SD: 下スクロール)
- `CSI L` (IL: 行挿入)
- `CSI M` (DL: 行削除)
- 改行によるスクロール（ring_push_blank）

**処理**: 生成される空行の全セルの`bg`フィールドを`cursor.bg`の値に設定する。

## 5. 非機能要件

### 5.1 パフォーマンス要件
- BCE適用による描画遅延の増加はなし（既存のセル代入処理に背景色フィールドを追加するだけ）

### 5.2 互換性要件
- xterm互換: xterm, kitty, alacritty等と同等のBCE動作
- 常時BCE有効（DECBKM モード切替は不要）

## 6. データ要件

### 6.1 データモデル
既存の`Cell`構造体の`bg`フィールドを活用。新しいデータ構造は不要。

**消去用セル生成パターン**:
- 現在: `Cell::EMPTY`（`bg: PackedColor::DEFAULT`固定）
- 変更後: `Cell::EMPTY`をベースに`bg`を`cursor.bg`に設定

## 7. 制約条件

### 7.1 技術的制約
- `Cell::EMPTY`定数は変更不可（constのため実行時にcursor.bgを反映できない）
- 消去用セルは実行時に生成する必要がある
- リサイズ・リセット操作は引き続き`Cell::EMPTY`（デフォルト背景）を使用する

## 10. 用語定義

| 用語 | 定義 |
|------|------|
| BCE | Background Color Erase。消去操作がカーソルの現在のSGR背景色を継承する仕様 |
| SGR | Select Graphic Rendition。文字属性（色、スタイル等）を設定するCSIシーケンス |
| EL | Erase in Line (`CSI K`)。行内の文字を消去する |
| ED | Erase in Display (`CSI J`)。画面内の文字を消去する |
| ECH | Erase Characters (`CSI X`)。N文字を消去する |
| ICH | Insert Characters (`CSI @`)。N文字を挿入する |
| DCH | Delete Characters (`CSI P`)。N文字を削除する |
