# 多言語対応 (i18n) - 要件定義書

## 1. 概要

### 1.1 背景

eMtermのUI文字列が英語および日本語でハードコードされている。

### 1.2 目的

アプリケーション全体の文字列を外部翻訳ファイルで管理し、複数言語に対応する。

### 1.3 スコープ

- フロントエンド (TypeScript) のUI文字列の多言語対応
- バックエンド (Rust) のCLIメッセージ・エラーメッセージの多言語対応
- 言語設定の保存・切り替え機構
- フロントエンド・バックエンド間の言語同期

## 2. 機能要件

### 2.1 フロントエンド多言語対応

| ID | 機能 | 説明 |
|----|------|------|
| F01 | 翻訳関数 | `t()` 関数によるドット区切りキーでの文字列取得 |
| F02 | 翻訳ファイル読み込み | JSON翻訳ファイルの読み込みと言語切り替え |
| F03 | フォールバック | キーが現在の言語に存在しない場合、英語にフォールバック |
| F04 | パラメータ置換 | `t("key", { name: "value" })` 形式のプレースホルダ置換 |

#### F01: 翻訳関数

**入力**: ドット区切りキー文字列 (例: `"settings.appearance.fontFamily"`)

**出力**: 翻訳済み文字列。キーが見つからない場合はキー文字列をそのまま返す。

#### F02: 翻訳ファイル読み込み

- `src/i18n/locales/en.json` と `src/i18n/locales/ja.json` からネスト型JSONを読み込む
- アプリ起動時に初期化、言語切り替え時に再読み込み

#### F03: フォールバック

1. 指定言語の翻訳を検索
2. 見つからない場合、英語 (en) の翻訳を検索
3. 英語にも見つからない場合、キー文字列をそのまま返す

#### F04: パラメータ置換

- `{paramName}` 形式のプレースホルダを引数の値で置換
- 例: `t("paste.confirm", { count: 5 })` → `"You are about to paste 5 lines"`

### 2.2 バックエンド多言語対応

| ID | 機能 | 説明 |
|----|------|------|
| F05 | rust-i18n連携 | `rust-i18n` クレートによる翻訳管理 |
| F06 | CLIメッセージ翻訳 | clap のコマンド説明文の翻訳 |
| F07 | エラーメッセージ翻訳 | CommandError のエラーメッセージの翻訳 |
| F08 | バリデーションメッセージ翻訳 | 設定値バリデーションのメッセージ翻訳 |

#### F05: rust-i18n連携

- `rust-i18n` クレートの `t!()` マクロで翻訳を取得
- 翻訳ファイル: `src-tauri/locales/en.json`, `src-tauri/locales/ja.json`

#### F06: CLIメッセージ翻訳

対象文字列:
- `main.rs`: コマンド説明 (`about`), サブコマンド説明, 引数ヘルプ

#### F07: エラーメッセージ翻訳

対象文字列:
- `error.rs`: `CommandError` の各バリアントの `#[error("...")]` メッセージ

#### F08: バリデーションメッセージ翻訳

対象文字列:
- `config.rs`: `validate_settings()` のエラーメッセージ

### 2.3 言語設定機能

| ID | 機能 | 説明 |
|----|------|------|
| F09 | デフォルト言語検出 | OS言語設定を検出しデフォルト言語とする |
| F10 | 言語オーバーライド | 設定画面から言語を手動選択できる |
| F11 | 設定永続化 | `AppSettings.language` フィールドで設定ファイルに保存 |

#### F09: デフォルト言語検出

- `language` が `"auto"` の場合、`navigator.language` (フロントエンド) またはシステムロケール (バックエンド) からOS言語を取得
- サポート外の言語の場合は英語 (`"en"`) にフォールバック

#### F10: 言語オーバーライド

- 設定画面にLanguageセレクトボックスを追加
- 選択肢: Auto (System), English, 日本語

#### F11: 設定永続化

- `AppSettings` に `language: string` フィールドを追加
- 値: `"auto"`, `"en"`, `"ja"`
- デフォルト値: `"auto"`
- 既存の設定ファイルとの後方互換性を維持 (フィールド未存在時は `"auto"`)

### 2.4 言語同期機構

| ID | 機能 | 説明 |
|----|------|------|
| F12 | 起動時同期 | アプリ起動時にフロントエンド・バックエンドの言語を同期 |
| F13 | 変更時同期 | 設定画面での言語変更をバックエンドに通知 |
| F14 | Tauriコマンド | `set_language` コマンドでバックエンドの言語を設定 |
| F15 | CLIモード言語解決 | CLIサブコマンド起動時にOS言語からロケールを自動解決 |

#### F12: 起動時同期

1. 設定ファイルから `language` を読み込む
2. フロントエンドの言語を設定
3. `set_language` コマンドでバックエンドの言語を設定

#### F13: 変更時同期

1. 設定画面でLanguageを変更
2. 設定を保存
3. フロントエンドの言語を即座に切り替え
4. `set_language` コマンドでバックエンドに通知

#### F14: Tauriコマンド

- コマンド名: `set_language`
- 引数: `language: String` (言語コード。`"en"`, `"ja"` のいずれか)
- バックエンドで `rust_i18n::set_locale()` を呼び出す

#### F15: CLIモード言語解決

- CLIサブコマンド (`emterm markdown`, `emterm image`) 起動時、フロントエンドが存在しない
- `sys-locale` クレートでOSの言語設定を取得
- サポート対象ロケール (`"en"`, `"ja"`) に含まれる場合はそのロケールを使用
- サポート外の場合は英語 (`"en"`) にフォールバック
- `main()` の冒頭、clap引数解析前に `rust_i18n::set_locale()` を呼び出す

## 3. 非機能要件

### 3.1 パフォーマンス

- 翻訳ファイルはアプリ起動時に一度だけ読み込む
- `t()` 関数はオブジェクトプロパティアクセスのみで動作する (ネットワーク通信なし)
- 言語切り替え時のUI再描画はSettings Panelの再レンダリングのみ

### 3.2 拡張性

- 新しい言語の追加は翻訳JSONファイルの追加のみで対応可能
- 翻訳キーの追加はJSONファイルへのエントリ追加のみ
- フロントエンドとバックエンドの翻訳は独立して管理

### 3.3 後方互換性

- 既存の `settings.json` に `language` フィールドがない場合、`"auto"` として扱う
- `serde(default)` によるフィールド未存在時のデフォルト値適用 (既存パターンと同一)

## 4. 対応言語

| 言語コード | 言語名 | 状態 |
|-----------|--------|------|
| en | English | ベース言語・フォールバック |
| ja | 日本語 | 初期対応 |

## 5. 対象範囲

### 5.1 翻訳対象

| コンポーネント | ファイル | 概算文字列数 |
|---------------|---------|-------------|
| Settings Panel | `src/settings/settings-panel.ts` | ~50 |
| Paste Dialog | `src/clipboard/dialog.ts` | ~5 |
| Link Dialog | `src/markdown/link-dialog.ts` | ~5 |
| Image Viewer | `src/image-viewer/index.ts` | ~5 |
| Tab Bar | `src/tab-bar/tab-bar-ui.ts` | ~5 |
| Markdown Fullscreen | `src/markdown/fullscreen.ts` | ~5 |
| Zoom Controller | `src/shared/zoom-controller.ts` | ~5 |
| CLI (clap) | `src-tauri/src/main.rs` | ~10 |
| Error Messages | `src-tauri/src/error.rs` | ~7 |
| Validation | `src-tauri/src/commands/config.rs` | ~6 |

### 5.2 翻訳非対象

- ログメッセージ (`console.log`, `log::debug!` 等) - 開発者向けのため英語固定
- ANSI制御シーケンス関連の文字列
- コード内部のエラーハンドリング用文字列 (ユーザーに表示されないもの)
- CSSクラス名、HTMLタグ属性
- 設定ファイルのキー名・列挙値 (`"system"`, `"block"`, `"visual"` 等)
