# eMterm設定画面 - 要件定義書

## 1. 概要

### 1.1 背景
eMtermにはユーザーがフォントサイズなどの設定を変更する機能がない。

### 1.2 目的
設定画面を実装し、フォントサイズの変更と永続化を可能にする。

### 1.3 スコープ
- 設定タブUIの実装
- フォントサイズ設定（8-32pt）
- JSON形式での設定永続化

## 2. ユースケース

### 2.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | 設定画面を開く | ユーザー | 高 |
| UC02 | フォントサイズを変更する | ユーザー | 高 |
| UC03 | 設定を保存する | システム | 高 |
| UC04 | 設定を読み込む | システム | 高 |

### 2.2 ユースケース詳細

#### UC01: 設定画面を開く

**アクター**: ユーザー

**事前条件**:
- アプリケーションが起動している

**基本フロー**:
1. ユーザーがタブバーの歯車ボタンをクリックする
2. 設定タブが開く（シングルトン）
3. 設定画面が表示される

**事後条件**:
- 設定タブがアクティブになっている

#### UC02: フォントサイズを変更する

**アクター**: ユーザー

**事前条件**:
- 設定画面が開いている

**基本フロー**:
1. ユーザーがFont Size入力欄で数値を変更する
2. ターミナルタブに即時反映される
3. 値確定時（blur/Enter）に自動保存される

**バリデーション**:
| 項目 | ルール | エラー時の動作 |
|------|--------|----------------|
| フォントサイズ | 8-32の整数 | 範囲外の値は受け付けない |

**事後条件**:
- フォントサイズが変更されている
- 設定がファイルに保存されている

#### UC03: 設定を保存する

**アクター**: システム

**基本フロー**:
1. 設定値が変更される
2. JSONファイルに書き込む

**保存場所**: `~/.config/emterm/settings.json`

#### UC04: 設定を読み込む

**アクター**: システム

**基本フロー**:
1. アプリケーション起動時に設定ファイルを読み込む
2. 設定をUIに適用する

**代替フロー**:
- ファイルが存在しない場合: デフォルト値を使用

## 3. 機能要件

### 3.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 設定タブ表示 | 歯車ボタンで設定タブを開く | 高 |
| F02 | フォントサイズ設定 | 8-32ptの範囲で設定可能 | 高 |
| F03 | リアルタイム反映 | 変更を即時ターミナルに反映 | 高 |
| F04 | 自動保存 | 値確定時に自動保存 | 高 |
| F05 | 起動時読み込み | 起動時に設定を読み込み適用 | 高 |

### 3.2 機能詳細

#### F01: 設定タブ表示

**説明**: タブバーの歯車ボタンをクリックすると設定タブが開く

**動作**:
- シングルトン（既に開いている場合はそのタブをアクティブにする）
- 他のタブと同様に閉じることができる

#### F02: フォントサイズ設定

**入力**:
- フォントサイズ: number (8-32)

**UI**:
- 数値入力欄（type="number"）
- 単位表示「pt」
- min="8", max="32"

#### F03: リアルタイム反映

**説明**: 入力値変更時に即座にターミナルのフォントサイズを更新

**対象**:
- 全てのターミナルタブ

#### F04: 自動保存

**トリガー**:
- 入力欄からフォーカスが外れた時（blur）
- Enterキー押下時

#### F05: 起動時読み込み

**説明**: アプリケーション起動時に設定ファイルを読み込み、CSS変数に適用

### 4.2 サイズ・スペーシング

| 要素 | サイズ |
|------|--------|
| カテゴリナビ幅 | 160px（固定） |
| コンテンツ領域 | flex: 1 |
| パディング | 24px |
| セクション間隔 | 24px |
| ラベル-入力間隔 | 8px |
| 数値入力幅 | 80px |

### 4.3 カテゴリ

| カテゴリ | 状態 | 設定項目 |
|---------|------|----------|
| Appearance | アクティブ | フォントサイズ |
| Terminal | グレーアウト | （将来実装） |
| Keybinds | グレーアウト | （将来実装） |

### 4.4 数値入力

```
┌──────┐
│  16  │ pt
└──────┘
```

- type="number"
- min="8", max="32"
- 右側に単位「pt」表示
- フォーカス時: 青枠線（#007acc）

## 5. 非機能要件

### 5.1 パフォーマンス要件
- フォントサイズ変更の反映: 即時（16ms以内）

### 5.2 保守性要件
- 設定項目の追加が容易な構造

## 6. データ要件

### 6.1 設定ファイル形式

```json
{
  "font_size": 16
}
```

### 6.2 設定ファイル保存場所

| OS | パス |
|----|------|
| Linux | `~/.config/emterm/settings.json` |

### 6.3 デフォルト値

| 項目 | デフォルト値 |
|------|-------------|
| font_size | 16 |

## 7. 将来の拡張
